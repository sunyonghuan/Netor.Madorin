# Netor.Madorin —— 一人公司的 AI 团队

> **面向创业者、独立开发者、自由职业者和小团队的一站式 AI 协作平台**
> 
> 版本：v1.3.8 | 文档类型：产品营销介绍 | 日期：2026年1月

---

## 一、一句话定位

**Madorin 不是又一个聊天窗口。它把 AI 智能体组织成岗位，把插件和技能变成工具，把会议结论推进到工作流 —— 你负责定目标，它负责调团队。**

---

## 二、产品核心卖点（八大优势）

### 卖点 1：一人团队 —— 一套软件，多岗位协同

你不是一个人在战斗。Madorin 内置了可独立配置的智能体岗位体系：

| 岗位 | 职责 |
|---|---|
| 技术智能体 | 开发、服务器维护、日志排查、脚本编写 |
| 市场智能体 | 内容创作、视频脚本、获客方案、发布节奏 |
| 客服智能体 | 问题整理、话术生成、反馈沉淀 |
| 策划智能体 | 产品策划、风险分析、路线设计、文档输出 |
| 运营智能体 | 任务拆解、优先级排序、进度追踪 |

每个岗位可以配置**不同的 AI 模型**、**不同的工具权限**、**不同的系统提示词**。这不是一个 AI 在硬撑，而是一组岗位在协作。

> **客户感知**：「以前我要分别打开 5 个 AI 工具，现在一个软件全搞定，而且它们之间还能互相协作。」

---

### 卖点 2：多模型自由 —— 不被单一平台锁死

Madorin 的核心设计哲学是「模型选择权归你」：

- **已支持厂商**：OpenAI、DeepSeek、Anthropic Claude、Google Gemini、智谱 GLM、Azure OpenAI、Ollama 本地模型
- **一键切换**：不同岗位可以用不同模型（比如总经理用 GPT-4，员工用本地小模型省钱）
- **Ollama 兼容代理**：内置本地协议代理，外部工具（VS Code、Cursor 等）以为在调 Ollama，实际走你配置的企业网关或私有模型

> **客户感知**：「不绑定任何一家 AI 厂商，模型升级了随时换，成本自己说了算。」

---

### 卖点 3：插件即工具 —— AI 真正能干活的底层能力

Madorin 的智能体不是只会聊天的顾问，而是能用工具的真员工。当前支持三种插件通道：

| 通道 | 技术栈 | 典型场景 |
|---|---|---|
| Native | C/C++/Rust/C# AOT | 高性能本地工具、崩溃隔离 |
| Process | 任意语言可执行程序 | 把现有脚本/工具直接变成 AI 能力 |
| MCP | Model Context Protocol | 对接外部工具服务生态 |

**已交付的插件清单**：

- 宝塔面板运维工具 —— 服务器管理一条龙
- Google 搜索 —— 实时联网获取信息
- 记忆引擎 —— 跨会话知识沉淀
- Office 文档工具 —— Word / Excel / PPT 读写
- 定时提醒 —— 任务时间管理
- C# 脚本运行器 —— 动态代码执行
- 窗口管理 / 应用启动器 —— 本地桌面自动化
- WebSocket 桥接 —— 对接外部系统

> **客户感知**：「AI 不只是回消息，它能直接操作我的服务器、写我的文档、管理我的文件。」

---

### 卖点 4：工作流交付 —— 从聊到做，一步到位

对话给你灵感，会议给你方案，工作流负责落地。Madorin 的工作模式实现了一条完整闭环：

```
用户提出目标 → AI 补齐需求 → AI 生成计划 → 用户确认 →
系统按计划分步执行 → 每步实时展示 → 高风险操作需授权 →
完成后写入总结 → 回到对话继续下一件事
```

每一步都有**可追溯的执行记录**、**步骤卡片**、**时间线视图**。任务杀进程了能恢复，执行失败了能重试。不是把执行结果塞回一段 Markdown 文本，而是结构化的持久化交付。

> **客户感知**：「我说『帮我上线一个新功能』，它自己拆任务、调工具、写脚本、检查结果，我只负责审批。」

---

### 卖点 5：会议模式 —— 多专家会诊，降低决策风险

面对复杂决策（技术选型、营销方案、危机应对），一个人的判断容易出现盲区。

会议模式让多个专家智能体围绕同一议题**讨论、反驳、补充风险、投票表决**，最终输出结构化的会议纪要和执行方案。每个智能体从自己的岗位视角发言，模拟真实团队的碰撞过程。

> **客户感知**：「就像同时拉了技术、市场、法务三个人开会，但它们从不嫌烦，而且会议记录自动生成。」

---

### 卖点 6：长期记忆 —— AI 越用越懂你

Madorin 内置记忆引擎，跨会话积累你的业务知识：

- 你的偏好、你的客户、你的项目背景
- 自动注入到每次对话的上下文中
- 不会因为新建会话就丢失积累的经验

> **客户感知**：「用了三个月后，AI 已经知道我的产品叫什么、用户画像是什么，不用每次都重新交代背景。」

---

### 卖点 7：数据主权 —— 本地优先，安全可控

- **SQLite 本地数据库**：会话、配置、历史消息全部存在本地
- **不依赖云端**：可以完全离线使用 Ollama 本地模型
- **AI Trace 诊断**：完整的请求/响应/异常日志，调试排错不黑盒
- **WebSocket 接入**：内置本地 WebSocket 服务（端口 52841），其他程序可以接入 AI 能力

> **客户感知**：「我的对话记录、业务数据全在自己电脑上，不经过任何第三方服务器。」

---

### 卖点 8：语音交互（已内置）

基于 Sherpa-ONNX 的本地语音能力：

- **KWS 关键词唤醒**：喊一声就能启动
- **STT 语音识别**：说话转文字输入
- **TTS 语音合成**：AI 回复可以读出来

全本地运行，不依赖云端语音服务。

## 三、未来规划（核心卖点前瞻）

以下功能处于设计/开发阶段，是你向客户展示「产品天花板」的关键素材：

### 3.1 企业级工作流引擎（开发中，worktree 已有大量代码）

基于 Microsoft Agent Framework v1.6.0 构建的完整多智能体编排系统：

```
老板(你) → 总经理智能体(规划拆解) → 
  ├─ 技术部(代码生成 + 审查 + 测试)
  ├─ 运营部(内容撰写 + 文案审核)  
  ├─ 市场部(方案策划 + 风险评估)
  └─ 跨进程部(视觉模型 + 语音服务)
```

核心能力规划：

| 能力 | 说明 |
|---|---|
| Magentic 自动编排 | 总经理智能体自动拆解任务、分配部门、汇总验收 |
| Writer-Critic 质量闭环 | 每个部门的产出自动审核，不达标退回重做 |
| 工具授权与沙盒 | 高风险操作必须人工审批，代码在隔离环境执行 |
| 检查点持久化 | 任务即使杀进程，重启后从断点继续 |
| A2A 跨进程协作 | 视觉、语音等独立服务以远程 Agent 接入 |

这套系统让一个人真正拥有「技术总监 + 运营总监 + 市场总监」的团队能力，而且永不疲倦、不懂推诿。

### 3.2 视觉模型接入

让智能体「看」得见：截图分析、UI 审查、图表解读、设计稿比对。当 AI 不仅能读文字还能看图，它的应用边界将大幅扩展。

### 3.3 运营平台与资源市场

- **资源市场**：智能体、插件、技能、提示词模板的交易/分享平台
- **订阅与授权**：商业化分发体系
- **创作者中心**：第三方开发者可以发布插件并获得收益

这意味着 Madorin 不只是工具，而是生态平台。

### 3.4 语音服务独立进程

将语音能力拆分为独立进程，通过 A2A 协议与主程序通信。崩溃不影响主程序，可独立部署、独立扩展。
