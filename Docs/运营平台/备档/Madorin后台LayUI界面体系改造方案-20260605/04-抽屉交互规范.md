# 04. 抽屉交互规范

## 右侧抽屉

所有新增、修改、查看都在右侧抽屉完成：

| 操作 | 打开方式 |
|---|---|
| 新增用户/资源/分类/设置 | 右侧抽屉 |
| 编辑用户/分类/设置 | 右侧抽屉 |
| 查看用户/资源/订单/订阅/交易/结算 | 右侧抽屉 |
| 用户充值、修改密码 | 右侧抽屉 |
| 审核通过/拒绝、结算处理 | 右侧抽屉或确认弹层 |

公共方法：

```js
window.adminDrawer = {
  openRight(options) {
    return layui.layer.open({
      type: 2,
      title: options.title,
      content: options.url,
      area: [options.width || "760px", "100%"],
      offset: "r",
      anim: 5,
      shade: 0.25,
      shadeClose: true,
      resize: false
    });
  }
};
```

Razor 页面约定：

```text
/Accounts/Details?id=1&mode=drawer
/Accounts/Edit?id=1&mode=drawer
/Accounts/Recharge?id=1&mode=drawer
/Assets/Create?mode=drawer
/Settings/Edit?id=1&mode=drawer
```

如果 LayUI 2.12.0 的 `offset: "r"` 表现不满足实际抽屉效果，在 `site.css` 增加统一 drawer class 修正位置和动画。

## 底部抽屉

关联列表、子页面、明细流水统一从底部抽屉打开。

公共方法：

```js
window.adminDrawer.openBottom = function (options) {
  return layui.layer.open({
    type: 2,
    title: options.title,
    content: options.url,
    area: ["100%", options.height || "72%"],
    offset: "b",
    anim: 2,
    shade: 0.2,
    shadeClose: true,
    resize: false
  });
};
```

底部抽屉内部仍然是 Razor + LayUI：

```text
筛选表单
LayUI table
批量操作
导出
刷新
```

典型入口：

| 主列表 | 底部抽屉 |
|---|---|
| 用户列表 | 交易记录、订单记录、订阅记录、下载记录、钱包流水 |
| 资源列表 | 版本记录、价格计划、审核记录、订阅用户、下载记录 |
| 创作者列表 | 名下资源、结算记录、订单收益 |
| 订单列表 | 交易流水 |
| 订阅列表 | 下载记录 |

## 表单提交

抽屉表单成功后：

```js
parent.layui.table.reload("accountTable");
parent.layui.layer.close(parent.layer.getFrameIndex(window.name));
parent.layui.layer.msg("保存成功");
```

危险操作统一使用：

```js
layui.layer.confirm("确定执行该操作吗？", function (index) {
  // POST with anti-forgery token
  layui.layer.close(index);
});
```
