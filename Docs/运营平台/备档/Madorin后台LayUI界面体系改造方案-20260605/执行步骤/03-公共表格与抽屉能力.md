# 03. 公共表格与抽屉能力

## 文件

```text
wwwroot/js/site.js
wwwroot/css/site.css
```

## 任务

1. 编写 `adminDrawer.openRight()`。
2. 编写 `adminDrawer.openBottom()`。
3. 编写 `adminTable.render()` 约定封装。
4. 编写 `adminTable.reload()`。
5. 编写筛选表单提交、重置、展开高级筛选逻辑。
6. 编写右侧抽屉表单提交成功后的父页面刷新逻辑。
7. 编写统一 POST 确认和防伪 token 处理。

## 验收

1. 右侧抽屉可打开 Razor 页面。
2. 底部抽屉可打开 Razor 子列表页面。
3. LayUI table 可分页、排序、刷新。
4. 筛选表单可驱动 table reload。
5. 表单保存成功后关闭抽屉并刷新父表格。
