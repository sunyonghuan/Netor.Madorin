# 01. 资源与约束确认

## 目标

先确认技术边界，避免后续实现时反复改变方向。

## 任务

1. 确认本地 LayUI 版本。
2. 确认是否升级 LayUI 2.x 静态资源。
3. 排除 `Netor.Operates.LayuiHelpers` 作为控件生成依赖。
4. 明确所有页面、表单、控件都使用 Razor 编写。
5. 确认 LayUI 标准样式和组件作为唯一前端 UI 基础。

## 验收

1. 文档和代码不再把 helper 库作为基础方案。
2. 后续页面改造都有明确 Razor 模板。
3. 不引入 Bootstrap 新样式。
4. 不引入 SPA 或前端组件框架。
