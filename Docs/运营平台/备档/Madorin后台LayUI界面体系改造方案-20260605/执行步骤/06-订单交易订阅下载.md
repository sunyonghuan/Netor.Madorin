# 06. 订单、交易、订阅、下载

## 文件

```text
Controllers/OrdersController.cs
Controllers/SubscriptionsController.cs
Views/Orders/*.cshtml
Views/Subscriptions/*.cshtml
```

## 任务

1. 订单列表 LayUI table。
2. 交易流水列表 LayUI table。
3. 订阅列表 LayUI table。
4. 下载记录 LayUI table。
5. 订单详情右侧抽屉。
6. 订单交易流水底部抽屉。
7. 订阅下载记录底部抽屉。

## 验收

1. 订单筛选覆盖订单号、用户、资源、状态、支付、金额、时间、交易流水、结算。
2. 交易筛选覆盖交易号、第三方流水、支付状态、支付方式、金额、异常交易。
3. 订阅筛选覆盖用户、资源、价格计划、状态、开始/到期/取消时间。
4. 下载筛选覆盖用户、资源、版本、IP、UserAgent、时间、订阅状态。
