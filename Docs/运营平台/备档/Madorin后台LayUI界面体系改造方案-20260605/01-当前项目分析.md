# 01. 当前项目分析

## Admin 项目

后台项目路径：

```text
Src/Netor.Cortana.Platform/Netor.Cortana.Platform.Admin
```

目标框架为 `net10.0`，引用了：

- `Netor.Cortana.Platform.Services`
- `Netor.Cortana.Platform.Entitys`
- `Netor.Cortana.Platform.Core`

现有布局已经引用：

```text
wwwroot/lib/layui/css/layui.css
wwwroot/lib/layui/layui.js
wwwroot/css/site.css
wwwroot/js/site.js
```

## 当前界面问题

1. 多个页面仍混用 Bootstrap 风格，例如 `form-control`、`form-select`、`table`、`table-responsive`、`d-flex`。
2. 列表页多为 Razor 静态表格，分页能力弱，无法发挥 LayUI table 能力。
3. 筛选项过少，没有覆盖实体字段、枚举和关联表。
4. 新增、编辑、查看多为普通跳转，操作上下文容易丢失。
5. 用户、订单、交易、订阅、下载等关联信息没有形成统一的主列表和子列表抽屉工作流。
6. `Netor.Operates.LayuiHelpers` 不完善，不能作为控件生成方案。

## 当前控制器功能

| 控制器 | 现有功能 | 改造重点 |
|---|---|---|
| `HomeController` | 控制台指标、快捷入口 | 改造成真实运营工作台 |
| `AccountsController` | 用户列表、详情、编辑、状态、充值、密码、批量状态 | 用户 table、右侧详情/编辑/充值/改密、底部交易/订单/订阅/下载 |
| `AssetsController` | 资源列表、上传创建、详情、发布、下架、隐藏、草稿、推荐 | 资源 table、右侧创建/查看/编辑、底部版本/价格/审核/下载 |
| `ReviewsController` | 审核列表、通过、拒绝、撤销 | 审核 table、右侧审核详情、风险与包校验 |
| `CategoriesController` | 分类列表、创建、编辑、显隐、批量、删除 | 分类 table、右侧表单、资源数量筛选 |
| `CreatorsController` | 创作者列表、通过、暂停、资产数、待结算金额 | 创作者 table、右侧详情、底部资产/结算 |
| `SubscriptionsController` | 订阅列表、下载记录、取消、恢复、批量 | 订阅 table、下载记录底部抽屉 |
| `OrdersController` | 订单列表、详情、批量、交易流水列表、交易批量 | 订单 table、交易 table、右侧详情、底部交易 |
| `SettlementsController` | 结算列表、结算、冻结、拒绝 | 结算 table、右侧处理表单 |
| `SettingsController` | 设置列表、创建、编辑、批量保存、测试包存储、重置、删除 | 设置 table、右侧表单、批量编辑 |
