# 02. 数据库结构分析

## 核心 DbSet

后台功能应围绕 `PlatformDbContext` 已有实体设计：

```text
Accounts
AccountWallets
Orders
Transactions
Assets
AssetVersions
Categories
PricingPlans
Subscriptions
DownloadRecords
CreatorProfiles
AssetReviews
CreatorSettlements
SystemSettings
```

## 核心关系

| 主体 | 关联 |
|---|---|
| 用户 `Account` | 钱包、订单、交易、订阅、下载、创作者资料、审核提交 |
| 资源 `Asset` | 分类、拥有者、版本、价格计划、订阅、下载、审核、结算 |
| 订单 `Order` | 用户、资源、价格计划、交易流水、创作者结算 |
| 交易 `Transaction` | 用户、订单、支付状态、支付方式、实际支付金额 |
| 订阅 `Subscription` | 用户、资源、价格计划、订单、下载记录 |
| 创作者 `CreatorProfile` | 用户、资源、待结算金额、结算记录 |
| 审核 `AssetReview` | 资源、版本、提交人、审核人、审核状态 |

## 关键字段

### 用户与钱包

```text
Accounts:
ID, No, LoginUserName, NickName, RealName, Phone, Email,
PhoneConfirmed, EmailConfirmed, Status, AccountType,
LoginTimes, LastLoginTime, LoginIP, RegestorIP, Refer,
Sex, SingleLoginEnabled, TimeStamp

AccountWallets:
AccountID, Name, Money, Type, Status, TimeStamp
```

### 订单与交易

```text
Orders:
AccountID, AssetId, PricingPlanId, No, Title, Content,
Money, Numbers, PayStatus, PayMethod, Status, PayTime, TimeStamp

Transactions:
AccountID, OrderId, No, OrderNo, ThirdNo, Title, Content,
Money, RealMoney, Type, PayStatus, PayMethod, PayTime, TimeStamp
```

### 资源、版本、价格

```text
Assets:
Name, Slug, DeveloperName, OwnerAccountId, ShortDescription,
Description, Tags, IconUrl, CoverUrl, Type, Status, CategoryId,
CurrentVersionId, IsFeatured, DownloadCount, PublishedAtUtc

AssetVersions:
AssetId, VersionName, ReleaseNotes, ManifestJson, PackageHash,
StorageProvider, PackageSize, FilePath

PricingPlans:
AssetId, Name, PlanType, Price, Currency, DurationDays, IsActive
```

### 订阅与下载

```text
Subscriptions:
AccountId, AssetId, PricingPlanId, OrderId, Status,
StartedAtUtc, ExpiresAtUtc, CanceledAtUtc

DownloadRecords:
AccountId, AssetId, AssetVersionId, SubscriptionId,
IpAddress, UserAgent, TimeStamp
```

### 审核、创作者、结算、设置

```text
AssetReviews:
AssetId, AssetVersionId, SubmitterAccountId, Status,
Notes, ReviewerId, ReviewedAtUtc, TimeStamp

CreatorProfiles:
AccountId, DisplayName, Bio, Status, ApprovedAtUtc, TimeStamp

CreatorSettlements:
CreatorAccountId, AssetId, OrderId, GrossAmount,
PlatformFeeAmount, NetAmount, Currency, Status, Notes,
SettledAtUtc, TimeStamp

SystemSettings:
Key, Name, Display, Value, Type, Group, IsProtection
```

## 枚举筛选维度

| 枚举 | 值 |
|---|---|
| `AssetType` | `Plugin`, `Skill`, `Agent`, `Solution` |
| `AssetStatus` | `Draft`, `Published`, `Hidden`, `Offline` |
| `PricingPlanType` | `Free`, `Monthly`, `Yearly` |
| `SubscriptionStatus` | `Active`, `Expired`, `Canceled` |
| `AssetReviewStatus` | `Pending`, `Approved`, `Rejected`, `Revoked` |
| `CreatorStatus` | `Pending`, `Approved`, `Suspended` |
| `SettlementStatus` | `Pending`, `Settled`, `Frozen`, `Rejected` |
| 订单状态 | 当前 `Order` 使用 `Status`、`PayStatus`、`PayMethod` 字段 |
