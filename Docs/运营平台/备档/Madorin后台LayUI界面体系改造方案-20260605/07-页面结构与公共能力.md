# 07. 页面结构与公共能力

## 列表页 Razor 模板

每个列表页统一结构：

```text
页面标题区
筛选表单
表格工具栏
LayUI table 容器
行操作模板
页面脚本区
```

示例：

```html
@{
    ViewData["Title"] = "用户账户";
}

<div class="admin-page">
  <div class="admin-page-header">
    <h1>用户账户</h1>
  </div>

  <form class="layui-form layui-form-pane admin-filter-form" lay-filter="accountFilter">
    <!-- Razor 输出 LayUI 标准筛选控件 -->
  </form>

  <table id="accountTable" lay-filter="accountTable"></table>
</div>

<script type="text/html" id="accountToolbar">
  <button class="layui-btn layui-btn-sm" lay-event="create">新增</button>
  <button class="layui-btn layui-btn-primary layui-btn-sm" lay-event="refresh">刷新</button>
  <button class="layui-btn layui-btn-primary layui-btn-sm" lay-event="export">导出</button>
</script>

<script type="text/html" id="accountRowActions">
  <a class="layui-btn layui-btn-xs" lay-event="view">查看</a>
  <a class="layui-btn layui-btn-xs layui-btn-normal" lay-event="edit">编辑</a>
  <a class="layui-btn layui-btn-xs layui-btn-primary" lay-event="transactions">交易</a>
</script>
```

## 右侧表单页 Razor 模板

```html
@model AccountEditViewModel

<div class="admin-drawer-page">
  <form class="layui-form layui-form-pane" asp-action="Edit" method="post" lay-filter="accountEditForm">
    @Html.AntiForgeryToken()

    <div class="layui-form-item">
      <label class="layui-form-label">昵称</label>
      <div class="layui-input-block">
        <input asp-for="NickName" class="layui-input" lay-verify="required">
      </div>
    </div>

    <div class="admin-drawer-footer">
      <button class="layui-btn" lay-submit lay-filter="drawerSubmit">保存</button>
      <button type="button" class="layui-btn layui-btn-primary" data-drawer-close>取消</button>
    </div>
  </form>
</div>
```

## 公共 JS

文件：

```text
wwwroot/js/site.js
```

新增统一能力：

```text
adminTable.render
adminTable.reload
adminDrawer.openRight
adminDrawer.openBottom
adminForm.bindDrawerSubmit
adminAction.confirmPost
adminFilter.collect
adminFilter.reset
```

这些能力只负责通用行为，不负责生成业务控件。业务控件仍然写在 Razor 页面中。

## 公共 CSS

文件：

```text
wwwroot/css/site.css
```

样式层级：

```text
后台布局
顶部栏
侧边栏
内容区
筛选区
表格工具栏
右侧抽屉
底部抽屉
状态标签
移动端适配
```

原则：

1. 保留 LayUI 原生视觉和交互。
2. 只补充后台业务需要的布局样式。
3. 不大面积覆盖 LayUI 核心组件。
4. 不继续引入 Bootstrap 表格和表单样式。

## 禁止项

- 不使用 `Netor.Operates.LayuiHelpers` 生成界面控件。
- 不使用 Bootstrap 表格和表单 class。
- 不把新增、编辑、查看做成普通页面跳转。
- 不只做基础筛选。
- 不手写静态分页替代 LayUI table 分页。
- 不引入 React/Vue/SPA。
