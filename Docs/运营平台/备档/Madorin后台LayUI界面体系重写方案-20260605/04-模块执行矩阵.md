# 04. 模块执行矩阵

## 控制台

| 项 | 要求 |
| --- | --- |
| 首页指标 | 资源、待审核、用户、订阅、订单、收入、待结算 |
| 页面区域 | 运营概览、审核队列、热门资源、最新订单 |
| 快捷入口 | 待审核、待支付、待结算、新增资源、存储配置 |
| 验收 | 所有数据来自当前数据库 |

## 用户账户

| 项 | 要求 |
| --- | --- |
| 主列表 | 用户基础信息、状态、类型、登录、钱包、订单、订阅 |
| 右侧抽屉 | 查看、编辑、改状态、充值、改密 |
| 底部抽屉 | 用户交易记录 |
| 批量 | 批量启用、停用、冻结等状态操作 |
| 筛选 | 关键词、编号、状态、类型、手机/邮箱确认、创作者、钱包、订单、订阅、下载、登录次数、登录时间、登录 IP、注册 IP |

## 资源市场

| 项 | 要求 |
| --- | --- |
| 主列表 | 资源名、类型、状态、分类、开发者、拥有者、推荐、下载、版本、价格、审核 |
| 右侧抽屉 | 新增、查看 |
| 操作 | 发布、下架、推荐、批量发布、批量下架 |
| 筛选 | 关键词、类型、状态、分类、推荐、拥有者、开发者、价格类型、价格范围、包文件、存储方式、下载、版本数、最新审核状态 |

## 资源审核

| 项 | 要求 |
| --- | --- |
| 主列表 | 资源、版本、提交人、资源状态、审核状态、备注、风险、审核人、审核时间 |
| 操作 | 通过、驳回、撤回 |
| 关联 | 行操作可跳转资源详情抽屉 |
| 筛选 | 关键词、审核状态、资源类型、资源状态、提交人、审核人、审核时间 |

## 分类配置

| 项 | 要求 |
| --- | --- |
| 主列表 | 名称、Slug、显示、排序、资源数、已发布资源数 |
| 右侧抽屉 | 新增、编辑、查看 |
| 操作 | 显示/隐藏、删除空分类、批量显示、批量隐藏 |
| 筛选 | 关键词、Slug、显示状态、排序范围、资源数量、已发布资源数量 |

## 创作者经营

| 项 | 要求 |
| --- | --- |
| 主列表 | 显示名、账号、状态、通过时间、资源数量、待结算、已结算、待审资源 |
| 右侧抽屉 | 查看 |
| 底部抽屉 | 名下资源、结算记录 |
| 操作 | 通过、暂停 |
| 筛选 | 关键词、显示名、用户、状态、通过时间、资产数量、待结算、已结算、是否有待审核资源 |

## 订单与权益

| 项 | 要求 |
| --- | --- |
| 订单列表 | 订单号、标题、用户、资源、方案、金额、支付、状态、流水数量 |
| 交易流水 | 流水号、订单号、三方单号、交易类型、支付方式、支付状态、金额 |
| 订阅列表 | 用户、资源、方案、状态、开始、到期、取消、下载次数 |
| 下载记录 | 用户、资源、版本、IP、客户端、订阅关联 |
| 右侧抽屉 | 订单详情 |
| 底部抽屉 | 订单流水、订阅下载 |
| 筛选 | 订单、支付、金额、数量、资源、方案、时间、订阅状态、下载 IP、客户端 |

## 收益结算

| 项 | 要求 |

| 筛选 | 关键词、创作者、资源、订单号、状态、币种、总额、平台费、净额、结算时间、备注 |
