# 01. 当前项目能力映射

## Admin 控制器能力

| 模块 | 控制器 | 已有能力 |
| --- | --- | --- |
| 控制台 | `HomeController` | 首页指标、热门资源、最新订单、审核队列 |
| 用户账户 | `AccountsController` | 列表、表格数据、查看、编辑、状态、充值、改密、用户交易记录、批量状态 |
| 资源市场 | `AssetsController` | 列表、表格数据、新增、查看、发布、下架、推荐、批量操作 |
| 资源审核 | `ReviewsController` | 审核列表、表格数据、通过、驳回、撤回、风险预检展示 |
| 分类配置 | `CategoriesController` | 列表、表格数据、新增、编辑、查看、显示隐藏、批量、删除空分类 |
| 创作者 | `CreatorsController` | 列表、表格数据、查看、名下资源、结算记录、通过、暂停 |
| 订阅下载 | `SubscriptionsController` | 订阅列表、下载记录、表格数据、取消、恢复、批量 |
| 订单流水 | `OrdersController` | 订单列表、订单详情、交易流水、表格数据、批量状态 |
| 收益结算 | `SettlementsController` | 列表、表格数据、查看、结算、冻结、驳回 |
| 系统设置 | `SettingsController` | 列表、表格数据、新增、编辑、查看、批量保存、检测包存储、重置、删除 |
| 登录退出 | `AuthController` | 登录、退出 |

## 数据实体与后台模块关系

| 业务域 | 主要实体 | 后台页面 |
| --- | --- | --- |
| 账户 | `Account`、`AccountWallet`、`AccountRolePair`、`AccountProperty` | 用户账户、用户交易记录 |
| 资源 | `Asset`、`AssetVersion`、`Category`、`PricingPlan` | 资源库、资源详情、分类配置、资源审核 |
| 审核 | `AssetReview` | 审核队列、资源最新审核筛选 |
| 创作者 | `CreatorProfile`、`CreatorSettlement` | 创作者档案、创作者资源、创作者结算、收益结算 |
| 订阅下载 | `Subscription`、`DownloadRecord` | 订阅权益、下载记录 |
| 订单交易 | `Order`、`Transaction` | 订单列表、订单详情、支付流水、用户交易记录 |
| 系统配置 | `SystemSetting` | 设置中心、包存储配置、风控配置 |

## 视图层现状

1. 已有 Razor 视图覆盖账户、资源、分类、创作者、订单、审核、设置、结算、订阅下载。
2. `_ViewStart.cshtml` 已支持 `mode=drawer` 切换抽屉布局。
3. `_DrawerLayout.cshtml` 已作为右侧和底部抽屉页面布局。
4. `_Layout.cshtml`、`_NavPartial.cshtml`、`_WorkspacePartial.cshtml` 是后台外壳和菜单体系核心。
5. `site.js` 已提供 LayUI table、drawer、filter、confirm 等公共能力。
6. `site.css` 已统一后台外壳、菜单、卡片、筛选、表格、抽屉样式。

## 缺口

1. 菜单和工作台还缺少真实业务数量提示，用户无法从外壳直接看到待办压力。
2. 方案文档需要把每个菜单入口映射到真实控制器、筛选参数或抽屉操作。
3. 快捷入口需要按角色和场景分层，避免所有页面顶部都是同一组按钮。
4. 需要形成“列表页筛选参数 -> URL query -> 表单回填 -> table 请求”的统一约束。
5. 需要补充视觉验收标准，避免只用构建通过作为界面验收。
