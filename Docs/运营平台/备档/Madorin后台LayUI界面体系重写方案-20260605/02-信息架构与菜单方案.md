# 02. 信息架构与菜单方案

## 设计原则

1. 左侧菜单表达业务，不表达代码目录。
2. 一级导航数量控制在 6 到 7 个业务区。
3. 二级入口必须能落到真实页面、真实 query 筛选或真实抽屉。
4. 待办类入口显示数量提示，减少进入页面后再筛选的成本。
5. 新增、查看、编辑等操作从右侧抽屉打开；关联明细从底部抽屉打开。

## 菜单结构

### 运营总览

| 入口 | 路由 | 说明 |
| --- | --- | --- |
| 运营总览 | `/` | 首页指标、审核队列、热门资源、最新订单 |

### 待办队列

| 入口 | 路由或筛选 | 数据来源 |
| --- | --- | --- |
| 资源待审核 | `/Reviews?status=1` | `AssetReview.Status = Pending` |
| 资源最新审核 | `/Assets?reviewStatus=1` | 最新 `AssetReview.Status = Pending` |
| 创作者待审核 | `/Creators?status=1` | `CreatorProfile.Status = Pending` |
| 待结算收益 | `/Settlements?status=1` | `CreatorSettlement.Status = Pending` |

### 用户与钱包

| 入口 | 路由或筛选 | 数据来源 |
| --- | --- | --- |
| 用户列表 | `/Accounts` | `Account` |
| 有余额用户 | `/Accounts?walletMin=1` | `AccountWallet.Money` 汇总 |
| 创作者账户 | `/Accounts?hasCreator=true` | `CreatorProfile.AccountId` |
| 异常/停用账户 | `/Accounts?status=1` | `Account.Status` |

### 资源市场

| 入口 | 路由或筛选 | 数据来源 |
| --- | --- | --- |
| 资源库 | `/Assets` | `Asset` |
| 已发布资源 | `/Assets?status=2` | `Asset.Status = Published` |
| 推荐资源 | `/Assets?featured=true` | `Asset.IsFeatured` |
| 新增资源 | `/Assets/Create?mode=drawer` | 右侧抽屉 |
| 分类配置 | `/Categories` | `Category` |
| 新增分类 | `/Categories/Create?mode=drawer` | 右侧抽屉 |

### 订单与权益

| 入口 | 路由或筛选 | 数据来源 |
| --- | --- | --- |
| 订单列表 | `/Orders` | `Order` |
| 待支付订单 | `/Orders?payStatus=1` | `Order.PayStatus` |
| 支付流水 | `/Orders/Transactions` | `Transaction` |
| 待确认流水 | `/Orders/Transactions?payStatus=1` | `Transaction.PayStatus` |
| 订阅权益 | `/Subscriptions` | `Subscription` |
| 有效订阅 | `/Subscriptions?status=1` | `Subscription.Status = Active` |
| 下载记录 | `/Subscriptions/Downloads` | `DownloadRecord` |

### 创作者经营

| 入口 | 路由或筛选 | 数据来源 |
| --- | --- | --- |
| 创作者档案 | `/Creators` | `CreatorProfile` |
| 有待审资源 | `/Creators?hasPendingReviewAssets=true` | 创作者资源的待审记录 |
| 收益结算 | `/Settlements` | `CreatorSettlement` |
| 有备注结算 | `/Settlements?hasNotes=true` | `CreatorSettlement.Notes` |

### 系统运维

| 入口 | 路由或筛选 | 数据来源 |
| --- | --- | --- |
| 设置中心 | `/Settings` | `SystemSetting` |
| 包存储配置 | `/Settings?group=包存储` | `SystemSetting.Group` |
| 风控配置 | `/Settings?keyPrefix=Risk` | `SystemSetting.Key` |
| 新增设置 | `/Settings/Create?mode=drawer` | 右侧抽屉 |

## 工作台快捷入口

工作台快捷入口不是固定装饰，应根据真实待办显示：

1. 待审核：资源审核待办数。
2. 创作者：创作者待审核数。
3. 待支付：订单待支付数。
4. 待结算：收益待结算数和金额。
5. 新增资源：右侧抽屉。
6. 存储配置：系统设置筛选。

## 验收要求

1. 菜单入口不出现空链接。
2. 带 query 参数的入口进入页面后，筛选控件必须回填。
3. 初始 table 请求必须带上 query 筛选值。
4. 有待办数量的入口必须来自数据库实时查询或明确的缓存服务。
