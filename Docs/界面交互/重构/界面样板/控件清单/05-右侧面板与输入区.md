# 05 · 右侧面板与输入区

`#content-row` 里主内容右侧有两个面板：常驻的**项目上下文面板**，
以及按需滑入的**对话面板**。此外全局复用一套**输入区组件** `.ia-wrap`。

---

## 1. 项目上下文面板 `#ctx-panel`（右侧常驻）

- **位置** — `#content-row` 最右列，宽 `280px`，`--s0` 底 + 左分隔线
- **风格** — 纵向 flex，静态展示（不做实时渲染）
- **结构**：

### 头部 `.ctx-head`
- `.ctx-proj-name` 项目名（14px 粗体）+ 打开对话按钮（点 `openConversation()`）
- `.ctx-proj-sub` 副说明"工作任务 · 3 步骤进行中 · Claude-3.7"

### 标签 `.ctx-tabs` > `.ctx-tab`（选中 `.on` 变强调色 + 底线，点 `ctxTab()`）
三个标签切换三个 `.ctx-body`：摘要 / Agent / 文件

### 摘要 `#ctx-summary`
- **执行状态** — 进度条（步骤 3/6，橙填充 38%）、耗时 `#ctx-elapsed`（JS 每秒走）、待审批数
- **运行中 Agent** — `.ctx-agent-row`：橙呼吸点 + "Claude-3.7 #1" + 当前步骤 `#ctx-agent-step`（JS 动画）
- **最近活动** — `.ctx-activity-row` 若干行时间流，`#ctx-feed-1` 由 JS 更新
- **CTA** `.ctx-cta` — 底部蓝色大按钮"继续工作对话"（`openConversation()`）

### Agent `#ctx-agents`
- 本项目 Agent 实例（带"对话"按钮）+ 可用 Agent 定义（`.ctx-agent-row` 带"分配"按钮）
- 底部 CTA"在本项目新建任务"（`openNewDialog()`）

### 文件 `#ctx-files`
- `.ctx-file-row` 项目文件行（修改中的标橙色）+ 产物输出 + "打开项目目录"按钮

---

## 2. 对话面板 `#conv-panel`（抽屉，滑入）

- **位置** — 绝对定位贴右边，宽 `340px`，默认 `translateX(100%)` 藏在屏外
- **交互** — 加 `.open` 类滑入（`transition:transform .2s`）；`openConversation()` 开、`closeConversation()` 关
- **结构**：
  - `.cp-head` — 标题"对话" + 关闭按钮 + `.cp-sub` 副标题 + `.cp-tags` 上下文标签（可 × 移除）
  - `.cp-tabs` > `.cpt` — 三模式标签（专家/工作/会议），工作标签带 `.cpt-dot` 未读点，点 `convTab()`
  - `.cp-msgs`（三个 `#cv-expert`/`#cv-work`/`#cv-meeting`）— 消息流：
    - `.cpb-user` 用户气泡（右）、`.cpb-agent` Agent 气泡（左，含 `.cpb-sender` + `.cpb-body`）
    - `.cpb-action` — 气泡内的工具动作小条
    - 工作流里嵌了**内联审批**：`.cpchip` 三色按钮（允许/本任务/拒绝），点 `handleApprInline()`
  - `.cp-chips` — 智能建议芯片 `.cpchip`（点 `insertChip()` 填入输入框）
  - 底部通用输入区 `.ia-wrap`

---

## 3. 通用输入区 `.ia-wrap`（全局复用组件）

对应实际代码里的 `InputAreaView.axaml`。工作/会议/专家/对话面板底部都用它，
只有发送键颜色和占位文字随场景变。**这是复用度最高的控件，改一处影响多处。**

### 结构（从上到下）
1. `.ia-agents`（仅会议模式）— 参会 Agent 芯片管理行：`.ia-agent-chip`（带 `.ia-rm` 移除 ×）+ `.ia-add-agent` 添加按钮
2. `.ia-selrow` — 选择器行：`.ia-sel` 三个胶囊按钮 = Provider / Model / Agent 选择（点弹 `showProviderPicker()` 等），右侧 token 计数"8.2k / 64k"
3. `.ia-chips` — 快捷指令芯片 `.ia-chip`（选中 `.on` 变强调，点 `selectChip()`），如"暂停并保存进度"
4. `.ia-box` — 输入框主体（`--s1` 底 + 圆角，聚焦时强调边 + 光晕）：
   - `.ia-ta` — 多行 textarea，`oninput="onInputArea()"` 检测 `@`/`/`/`#` 触发补全，`onkeydown="onInputKeydown()"`（Enter 发送，Shift+Enter 换行）
   - `.cp-popup` — 补全浮层（`@` 选 Agent / `/`、`#` 选命令与文件），`.cp-popup-item` 条目（选中 `.selected`）
   - `.ia-bar` — 底部工具条：附件 paperclip、@提及、/技能命令（`.iatool2` 按钮）+ `.ia-hint`"Enter 发送" + `.ia-send` 发送键
5. `.ia-send` — 32px 圆角发送按钮，**颜色随模式**（工作橙 / 会议紫 / 专家绿 / 对话强调蓝），点 `sendMsg()`

### 关键交互函数
- `onInputArea(el, uid)` — 监听末字符，`@` 弹 Agent 浮层、`/` `#` 弹命令浮层
- `toggleInputPopup(id, char)` — 开关指定浮层并插入触发符
- `sendMsg(btn)` — 取最近的消息滚动区，追加用户气泡并清空输入
- 全局：点浮层/工具按钮外的地方自动关闭所有 `.cp-popup`
