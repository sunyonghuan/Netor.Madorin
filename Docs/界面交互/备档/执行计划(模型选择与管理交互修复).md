# 执行计划：模型选择与管理交互修复

## 目标

修复模型管理页状态操作和三种输入模式模型选择 Popup 的交互问题，保持现有 `AiModelService` 与模型状态数据契约不变。

## 阶段一：设置页模型开关

- [x] 将模型列表中的状态文本按钮替换为 `ToggleSwitch`。
- [x] 使用 `IsChecked` 映射 `AiModelEntity.IsEnabled`。
- [x] 默认模型开关禁用且保持开启。
- [x] 开关变更调用 `AiModelService.SetEnabled`，成功后发布 `OnAiModelChange` 并刷新列表。
- [x] 服务层异常后重新读取数据库状态，恢复界面实际状态。

验收条件：普通模型切换后状态立即保存；默认模型不可关闭；刷新设置页后状态与数据库一致。

## 阶段二：模型选择 Popup

- [x] 搜索框设置为无边框并固定在 Popup 顶部，列表独立滚动。
- [x] Popup 打开时清空搜索内容并自动聚焦搜索框。
- [x] 实时按 `DisplayName` 或 `Name` 过滤，忽略大小写。
- [x] 维护当前过滤结果和键盘高亮索引。
- [x] `Up`/`Down` 在过滤结果中循环移动高亮，`Enter` 确认高亮模型，`Escape` 关闭 Popup。
- [x] 空结果时忽略 `Enter`，清空搜索后恢复全部启用模型。
- [x] 鼠标点击继续复用现有模型选择逻辑。

验收条件：对话、会议、工作模式均可通过搜索框完成搜索、上下键选择和 Enter 确认，且鼠标选择行为不回归。

## 阶段三：测试与验证

- [x] 编译 `Netor.Cortana.UI`。
- [x] 运行实体服务测试和 AI 模型测试。
- [ ] 手动验证默认模型、普通模型、无结果搜索、清空搜索及 Popup 关闭行为。

验收条件：构建和相关测试通过，交互检查项全部满足方案设计规则。
