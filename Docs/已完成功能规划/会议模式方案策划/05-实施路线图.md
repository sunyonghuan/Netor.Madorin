### 2.B IPromptProvider 接入（**新增**）

> **背景**：当前工作模式提示词以 EmbeddedResource 烧进 DLL（[GeneralManagerAgentBuilder.LoadEmbeddedPrompt](Src/Netor.Cortana.AI/WorkMode/GeneralManagerAgentBuilder.cs#L144)），用户无法在不重新编译的情况下修改。会议模式的主持人提示词、压缩提示词都需要"用户随时可改、不重新编译"的能力，所以这一步必须先做。
>
> 已有现成基础设施：[IPromptProvider](Src/Netor.Cortana.AI/WorkMode/Prompts/IPromptProvider.cs) / [LocalFilePromptProvider](Src/Netor.Cortana.AI/WorkMode/Prompts/LocalFilePromptProvider.cs) / [DatabasePromptProvider](Src/Netor.Cortana.AI/WorkMode/Prompts/DatabasePromptProvider.cs) / [CompositePromptProvider](Src/Netor.Cortana.AI/WorkMode/Prompts/CompositePromptProvider.cs) / [IAppPaths.PromptsDirectory](Src/Netor.Cortana.Entitys/Interfaces/IAppPaths.cs#L38)（解析为 `<UserData>/prompts/`，[AppPaths.cs:37](Src/Netor.Cortana.UI/AppPaths.cs#L37)）—— 接口和实现已写好，只是没接入 DI 也没人用。

#### 2.B.1 新增 EmbeddedResourcePromptProvider

新建 `Src/Netor.Cortana.AI/WorkMode/Prompts/EmbeddedResourcePromptProvider.cs`：

- 接受一个 `Assembly` + 资源命名约定（如 `"Netor.Cortana.AI.prompts.{name}.md"` —— 注意 `.` 是命名空间分隔符）
- `GetPromptAsync(name)` 实现把 `"work_mode.general_manager"` 转成 `"Netor.Cortana.AI.prompts.work_mode.general_manager.md"`，再 `GetManifestResourceStream` 读
- 兼容现有的 [GmPromptResource](Src/Netor.Cortana.AI/WorkMode/GeneralManagerAgentBuilder.cs#L17) 命名

#### 2.B.2 调整查找链路：File → EmbeddedResource

修改 [CompositePromptProvider.CreateDefault](Src/Netor.Cortana.AI/WorkMode/Prompts/CompositePromptProvider.cs#L23)，把链路改为：


  - `FunctionResultContent` → `meeting.tool.result`（同上跳过会议特有工具）
  - `TextContent` → `meeting.message.delta`
- 处理 `AgentResponseEvent` → 写库 `MeetingMessages`（IsPartial=0）+ `meeting.message.completed`
- 处理 `WorkflowOutputEvent` → `meeting.completed` + 写 `ChatMessages` 总结
- **流式期间异常处理**（修复缺陷 14）：try/catch 包裹整个 enumerator，catch 路径调 `MeetingMessageService.AppendPartialAsync` 把累积文本作为 `IsPartial=1` 消息落库 + 发 `meeting.message.partial.saved`

```csharp
try
{
    await foreach (var update in agent.RunStreamingAsync(history, ct))
    {
        // 累积 _currentBubbleBuffer 并发 delta 事件
    }
}
catch (Exception ex) when (ex is not OperationCanceledException)
{
    if (_currentBubbleBuffer.Length > 0)
    {
        await _messageService.AppendPartialAsync(meetingId,
            speakerKind, speakerId, speakerName,
            _currentBubbleBuffer.ToString(), ex.Message, ct);
    }
    throw;    // 让 RetryingAgent 决定是否重试
}
```
