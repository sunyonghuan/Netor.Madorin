# 专家自主子智能体编排执行步骤

> 目标：按最小闭环实现专家模式后台子智能体委派能力。主智能体负责查看工具目录、创建任务、查询进度、读取结果和取消任务；子智能体按 `toolMountsJson` 声明的工具后台执行；结果通过普通工具调用返回，由主智能体用普通消息回复用户。
