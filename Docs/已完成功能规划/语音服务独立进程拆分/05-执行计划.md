# 05 - 执行计划（语音服务插件化拆分）: 100%

> 完成口径：本计划以“主程序语音体系与模型剥离完成、默认软件无插件无语音控制、语音能力改为按需安装插件”为验收边界。TTS 插件已落地并通过真实模型进程验证；STT/KWS 插件实体作为后续按需语音插件包继续扩展，不再阻塞主程序瘦身剥离归档。

## 总体顺序

本计划不再采用固定 `Madorin.Stt.exe` / `Madorin.Tts.exe` 专用子进程方案，而是改为：

1. 扩展插件能力发现；
2. 先拆 TTS；
3. 再拆 STT；
4. 最后拆 KWS；
5. 验证稳定后从主程序发布包移除语音模型。

执行原则：

- 每一步都要可编译、可运行；
- 旧实现源码短期仅作为迁移参考保留，不参与默认运行链路；
- 不新增语音专用协议；
- 控制命令走现有 Process 插件 `invoke`；
- 流式事件走现有宿主 WebSocket / EventHub 映射。
