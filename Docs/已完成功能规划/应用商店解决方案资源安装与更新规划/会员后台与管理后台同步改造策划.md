# 会员后台与管理后台同步改造策划

## 文档定位

本文档用于承接“应用商店解决方案资源安装与更新”能力落地后，会员后台和管理后台同步调整的产品功能策划与当前实现对齐记录。

核心目标：

- 会员后台需要让用户明确看到解决方案包内包含哪些插件、技能、智能体，以及订阅、下载、更新后会影响哪些资源。
- 管理后台需要让运营和审核人员能够正确上传、解析、审核、发布、维护解决方案包，而不是把解决方案当作普通 ZIP 附件处理。
- 两个后台展示的解决方案语义必须与桌面端应用商店一致：解决方案是插件、技能、智能体的组合包，三类资源可以只包含一种、两种或三种。

本文档是功能策划与语义对齐记录，不作为执行计划使用；具体执行进度、验证命令和涉及文件见同目录 `执行计划(会员后台与管理后台同步改造).md`。

## 总体同步原则

- 统一资源类型：插件、技能、智能体、解决方案仍然共用 `Asset` 资源模型，解决方案不单独拆表。
- 统一包语义：解决方案包以 `solution.json` 为清单入口，包内 `plugins`、`skills`、`agents` 均为可选数组，但至少包含一种子资源。
- 统一风控口径：插件、技能、解决方案允许包含运行所需的脚本、可执行文件和 Native 依赖；智能体包仍按较严格规则处理高风险扩展名。
- 统一详情展示：会员后台、管理后台、客户端应用商店都应展示解决方案包内资源清单。
- 统一版本说明：解决方案版本更新不只是外层 ZIP 更新，还可能包含子资源新增、更新或移除。

## 当前实现对齐结论

截至当前实现，会员后台和管理后台的第一阶段核心能力已经落地：

- 会员后台市场卡片、资源详情、我的订阅、我的下载已读取 `AssetVersion.ManifestJson` 并展示解决方案包内插件、技能、智能体数量摘要或清单。
- 会员后台资源详情已增加“方案内容”区块，并说明下载的是外层解决方案 ZIP，桌面端会把包内资源拆分安装到对应目录。
- 管理后台上传解决方案 ZIP 时已解析 `solution.json`，并校验子资源路径、目录存在性、`plugin.json`、`skill.md`、`agent.json` 和空方案。
- 管理后台上传成功后会回填名称、slug、版本、描述、发布说明，并返回插件、技能、智能体数量摘要。
- 管理后台资源详情、版本列表和审核列表已展示解决方案清单摘要、子资源目录结构和风控说明。
- 平台风控口径已对齐：插件、技能、解决方案允许包含运行所需脚本和可执行文件；智能体仍按高风险扩展名严格处理。
- 当前仍保留为后续增强的内容包括：新旧版本子资源结构化 diff、客户端安装状态回传、子资源依赖关系图、逐项风险等级和创作者后台可视化组包。

## 会员后台改造范围

会员后台指 `Netor.Cortana.Platform.Web` 承载的个人用户前台、市场页、资源详情页和个人中心。

### 市场列表页

资源列表需要继续支持按类型筛选解决方案，并在解决方案卡片上补充组合包提示：

- 类型显示为“解决方案”。
- 简介中可展示“包含插件 / 技能 / 智能体”的摘要。
- 如果 `ManifestJson` 能解析出 `solution.json` 结构，卡片可以显示子资源数量，例如“插件 1 · 技能 2 · 智能体 1”。
- 如果清单缺失或解析失败，只显示普通解决方案信息，不阻断列表展示。

### 资源详情页

解决方案详情页已新增并应保持“方案内容”区块：

- 展示包内插件清单：slug、版本、路径。
- 展示包内技能清单：slug、版本、路径。
- 展示包内智能体清单：slug、版本、路径。
- 允许某一类为空或不存在，不展示空分类。
- 当三类都为空时展示“方案清单为空或未提供”，并提示资源可能无法被客户端正确安装。

详情页已补充并应保持“安装说明”：

- 解决方案下载后由桌面端应用商店安装。
- 安装时插件会进入插件目录，技能进入技能目录，智能体进入智能体目录。
- 更新解决方案时，插件会先停用再替换，技能和智能体会按目录覆盖或更新。
- 卸载解决方案时，会删除该方案带入的可删除子资源；共享资源或用户单独安装的同名资源不会直接删除。

### 订阅与下载

解决方案订阅逻辑继续复用现有 `PricingPlan`、`Subscription`、`Order`、`DownloadRecord`：

- 免费解决方案：登录后可直接获取或下载。
- 付费解决方案：订阅有效期内可下载当前版本。
- 同一解决方案可以配置月度、年度、免费等多个价格方案。
- 下载记录中资源类型显示为“解决方案”，文件仍为完整 ZIP 包。

下载前提示需要区分资源类型：

- 普通插件、技能、智能体：提示下载单资源包。
- 解决方案：提示下载组合包，安装后会把包内资源拆分到对应目录。

### 个人中心

“我的订阅”和“我的下载”已补充并应保持解决方案语义：

- 订阅列表显示资源类型为“解决方案”。
- 解决方案订阅详情展示包内资源摘要。
- 下载记录展示下载的是外层解决方案包，而不是单个插件或技能。
- 若后续支持客户端回传安装状态，可在个人中心展示“已下载 / 已安装 / 有更新 / 已过期”等状态。

### 更新提示

会员后台可以在资源详情页或个人中心展示解决方案更新说明：

- 外层解决方案版本号。
- 本次包含哪些子资源变更。
- 新增子资源。
- 更新子资源。
- 移除子资源。
- 对插件更新需提示“安装更新时会先停用旧插件再替换”。

当前第一阶段已展示版本发布说明和包内清单；结构化子资源变更对比保留为后续增强。

## 管理后台改造范围

管理后台指 `Netor.Cortana.Platform.Admin` 承载的资源管理、上传、审核、发布、版本管理和风控页面。

### 资源创建与编辑

资源创建页选择“解决方案”时，需要把说明从“普通方案 ZIP”调整为“组合资源包”：

- 必须包含 `solution.json`。
- 可选包含 `plugins/`、`skills/`、`agents/`。
- 至少包含插件、技能、智能体中的一种。
- 包内插件目录必须包含 `plugin.json`。
- 包内技能目录必须包含 `skill.md`。
- 包内智能体目录必须包含 `agent.json`。
- 允许技能目录包含图片、脚本、文档、模板、示例数据等配套资源。

页面侧边说明建议展示推荐结构：

```text
solution.json
README.md
plugins/
  plugin-a/
    plugin.json
skills/
  skill-a/
    skill.md
agents/
  agent-a/
    agent.json
```

### 资源包上传解析

上传解决方案 ZIP 后，管理后台需要解析并回填：

- 方案名称。
- 方案 slug。
- 版本号。
- 描述。
- 发布说明。
- 包内插件数量。
- 包内技能数量。
- 包内智能体数量。
- 子资源清单摘要。

解析规则：

- 优先读取根目录 `solution.json`。
- 允许 ZIP 外层套一层目录，但最终解析到的包根目录必须包含 `solution.json`。
- `assets.plugins`、`assets.skills`、`assets.agents` 可省略或为空。
- 三类子资源合计为 0 时，上传解析失败。
- 子资源路径必须是相对路径，不允许绝对路径、路径穿越和越界目录。

### 包结构校验

管理后台上传和发布前需要做包结构校验：

- `solution.json` JSON 格式合法。
- `slug` 非空且符合平台资源标识规则。
- `version` 非空。
- 子资源 slug 非空。
- 子资源 path 合法。
- 每个声明的子资源目录真实存在。
- 插件子资源目录存在 `plugin.json`。
- 技能子资源目录存在 `skill.md`。
- 智能体子资源目录存在 `agent.json`。

校验失败时，应明确指出失败位置，例如：

- `plugins.google-search-plugin` 缺少 `plugin.json`。
- `skills.market-research` 缺少 `skill.md`。
- `agents.marketing-director` 路径越界。

### 风控与审核

风控策略需要和客户端安装语义一致：

- 插件包、技能包、解决方案包允许出现 `.cmd`、`.bat`、`.ps1`、`.exe`、`.dll` 等运行资源，不能仅凭扩展名阻断。
- 智能体包仍然对高风险扩展名保持阻断。
- 对解决方案包，应继续检查路径穿越、空 ZIP、文件数量、单文件大小、总解压大小。
- 对 `solution.json` 和子资源清单继续做敏感词、注入提示、越权工具说明等文本风险扫描。
- 人工审核页需要展示包内子资源列表，避免审核人员只看到外层方案描述。

审核页已展示或应保持展示以下信息：

- 方案清单。
- 子资源目录结构。
- 风险扫描结果。
- 允许脚本/可执行文件的原因说明。
- 审核备注。

### 版本管理

解决方案上传新版本时，管理后台后续可增强新旧版本对比：

- 新增的插件、技能、智能体。
- 移除的插件、技能、智能体。
- 版本发生变化的插件、技能、智能体。
- 外层方案版本号和发布说明。

当前第一阶段已在上传、详情和审核链路展示新版本清单；后续再读取上一版本 `ManifestJson` 做结构化 diff。

发布当前版本时，需要继续校验：

- 包文件存在。
- 哈希正确。
- 包结构和 Manifest 可解析。
- 风控结果通过。
- 价格方案有效。

### 资源列表与详情

管理后台资源列表中，解决方案应能被筛选和识别：

- 类型筛选包含解决方案。
- 列表显示包内资源数量摘要。
- 详情页展示 `solution.json` 的解析结果。
- 版本列表显示每个版本的方案清单摘要。

资源详情页已增加或应保持以下区块：

- “方案内容”区块。
- “安装语义”提示。
- “卸载影响”提示。
- “共享资源风险”提示。

### 定价与授权

解决方案继续走资源级订阅授权：

- 用户订阅的是外层解决方案资源。
- 桌面端安装时下载外层解决方案包。
- 子资源不要求用户分别订阅。
- 子资源是否允许作为独立商品销售，由平台运营另外创建独立 `Asset` 决定。

需要在管理后台说明：

- 解决方案包含的插件、技能、智能体是随解决方案交付的资源副本。
- 若同名插件或技能同时作为独立商品存在，卸载解决方案时客户端会保护用户单独安装的资源。
- 价格方案配置仍以解决方案 `Asset` 为维度。

## 接口与数据同步

### 会员后台读取数据

会员后台资源详情需要读取：

- `Asset.Type`
- `AssetVersion.ManifestJson`
- `AssetVersion.VersionName`
- `AssetVersion.ReleaseNotes`
- `PricingPlan`

对于解决方案，页面应尝试把 `ManifestJson` 解析为 `solution.json` 结构，并展示子资源清单。

### 管理后台写入数据

管理后台上传解析后，应把 `solution.json` 原文或规范化 JSON 写入 `AssetVersion.ManifestJson`。

当前已在不新增业务表的情况下，增加页面级 ViewModel：

- `SolutionManifestSummary`
- `SolutionChildAssetSummary`

后续可继续补充：

- `SolutionVersionDiffSummary`

这些 ViewModel 只服务页面展示，不改变核心数据模型。

### 客户端 API 对齐

客户端 API 已经返回安装清单和当前版本 Manifest。会员后台和管理后台应保持同一份 Manifest 语义：

- `/api/v1/client/install/{assetIdOrSlug}` 返回解决方案安装清单。
- `/api/v1/client/sync` 返回用户已拥有资源清单。
- `/api/v1/client/updates` 返回可更新资源，解决方案更新由客户端按包内子资源语义处理。
- `/api/v1/assets/{idOrSlug}` 的当前版本 Manifest 可用于前台展示方案内容。

## 页面文案建议

### 会员后台详情页

解决方案说明：

```text
这是一个组合解决方案。安装后，包内插件、技能和智能体会分别进入本地对应目录。
更新解决方案时，插件会先停用再替换；技能和智能体会随方案版本同步更新。
```

### 会员后台下载提示

```text
你正在下载解决方案包。请使用 Madorin 桌面端应用商店安装，客户端会自动把包内插件、技能和智能体安装到对应目录。
```

### 管理后台上传提示

```text
解决方案包必须包含 solution.json，并至少包含插件、技能、智能体中的一种资源。
plugins、skills、agents 目录均为可选目录，但声明的子资源目录必须真实存在。
```

### 管理后台审核提示

```text
插件、技能、解决方案允许包含运行所需脚本和可执行文件。审核时请结合资源类型、清单声明、目录结构和风险扫描结果判断，不要仅按扩展名拒绝。
```

## 验收标准

会员后台验收：

- 资源列表可以正常筛选解决方案。
- 解决方案详情页展示包内插件、技能、智能体清单。
- 缺少某一类子资源时页面不报错。
- 订阅、下载、订单、下载记录继续按资源级维度工作。
- 下载提示明确说明解决方案包需要由桌面端应用商店安装。

管理后台验收：

- 创建和编辑资源时，解决方案类型展示正确的打包规则。
- 上传解决方案包后能解析 `solution.json` 并回填基础信息。
- 包内子资源清单可在上传、详情、审核页面查看。
- 空解决方案或声明路径不存在的解决方案上传失败。
- 风控不再因为插件、技能、解决方案中的脚本或可执行文件直接阻断。
- 发布前校验能覆盖包完整性、Manifest、风控和价格方案。

## 后续增强

- 管理后台增加新旧解决方案版本子资源 diff。
- 会员后台个人中心展示“已安装版本”和“可更新子资源”，依赖客户端安装状态回传。
- 解决方案详情页展示子资源之间的依赖关系图。
- 审核后台支持对子资源逐项标记风险等级。
- 创作者后台支持可视化组合解决方案包，而不是手写 `solution.json`。
