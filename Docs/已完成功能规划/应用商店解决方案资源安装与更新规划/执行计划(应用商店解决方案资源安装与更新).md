- [√] 插件更新时先标记更新状态，阻止新的插件调用进入。

- [√] 技能更新时允许直接覆盖整个技能目录，覆盖后刷新技能索引。
- [√] 智能体更新时允许直接覆盖整个智能体目录，覆盖后刷新智能体索引。
- [√] 更新记录中写明旧版本、新版本、更新时间、结果和失败原因。
