# 13 - 执行引擎与事件驱动

> 把 AF Workflow 事件流转换为 UI 更新与数据库写入
>
> **核心约束**：AOT 安全、code-behind 直接更新 UI、与现有控件接口对齐

---

## 一、设计原则

### 1.1 AOT 安全（最高优先级）

Cortana 项目要求全流程 AOT 编译。以下做法**严格禁止**：

- ❌ 反射 / 动态代码生成 / Expression.Compile
- ❌ XAML Binding（`{Binding ...}`）
- ❌ `ObservableCollection<T>` + `INotifyPropertyChanged` 自动绑定
- ❌ `JsonSerializer.Serialize(obj)` 不带 Context
- ❌ `Activator.CreateInstance` / `Type.GetType`

允许且推荐：

- ✅ Code-behind 直接调用控件方法（`MessageList.Items.Add(...)` / `timeline.AddMainStep(...)`）
- ✅ `JsonSerializerContext` 源生成
- ✅ `AIFunctionFactory.Create(强类型方法)` —— AF 内部对 AOT 友好的工厂
- ✅ EventHub 的 `IPublisher` / `ISubscriber`（已被全项目使用）

> 现有参考：`RealtimeProcessCard.axaml.cs`（流式更新）、`ChatView.axaml.cs`（消息列表追加）、`AiChatHostedService.cs`（事件发布）。

### 1.2 后端不直接操作 UI

执行引擎 **只发事件 + 写数据库**，UI 自己订阅事件并通过 `Dispatcher.UIThread.Post` 更新控件。这样：

- 后端无 UI 依赖（可独立单测）
- 多个 UI 视图可同时订阅（左侧任务列表 + 主消息流）
- WebSocket 广播可以直接复用同一份事件流（v1.1+ 给插件用）

## 二、执行流程总览

```text
┌──────────────────────────────────────────────────────────────┐
│ WorkModeInputRouter.RouteAsync(userInput)                     │
└──────────────────────────────────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────────┐
│ WorkflowExecutor                                              │
│  ├─ ExecuteAsync(taskId, userInput)         首次启动           │
│  ├─ ResumeAsync(taskId, userResponse?)      HITL 恢复          │
│  └─ EnqueueUserInputAsync(taskId, input)    执行中插话          │
└──────────────────────────────────────────────────────────────┘
                            ↓
        InProcessExecution.RunStreamingAsync / ResumeAsync
                            ↓
                       run.WatchAsync()
                            ↓
┌──────────────────────────────────────────────────────────────┐
│ WorkflowEventDispatcher.HandleAsync(taskId, evt)              │
│  ├─ 写 WorkExecutionLogs（持久化）                              │
│  ├─ Publish 业务事件（EventHub）                               │
│  └─ 检测 RequestInfoEvent / WorkflowOutputEvent → 中断主循环    │
└──────────────────────────────────────────────────────────────┘
                            ↓
                       EventHub 总线
                            ↓
┌──────────────────────────────────────────────────────────────┐
│ WorkModeView (UI)                                             │
│  ├─ 订阅 work.* 事件                                            │
│  ├─ Dispatcher.UIThread.Post 切换到 UI 线程                    │
│  └─ 直接调用控件方法（AddMainStep / AppendDetail / Show ...）   │
└──────────────────────────────────────────────────────────────┘
```

## 三、WorkflowExecutor

### 3.1 接口

```csharp
namespace Netor.Cortana.AI.WorkMode;

public interface IWorkflowExecutor
{
    /// <summary>启动新任务的执行。</summary>
    Task ExecuteAsync(string taskId, string userInput, CancellationToken ct = default);

    /// <summary>从 HITL 暂停点恢复（用户回应了 ask_user / 工具授权）。</summary>
    Task ResumeAsync(string taskId, string userResponse, CancellationToken ct = default);

    /// <summary>执行中追加用户输入到队列（不暂停 Workflow，由 Manager 在下次决策点查看）。</summary>
    Task EnqueueUserInputAsync(string taskId, string userInput, CancellationToken ct = default);
}
```

### 3.2 实现

```csharp
public sealed class WorkflowExecutor : IWorkflowExecutor
{
    private readonly GeneralManagerAgentBuilder _agentBuilder;
    private readonly SqliteCheckpointStore _checkpointStore;
    private readonly WorkflowEventDispatcher _eventDispatcher;
    private readonly HitlService _hitlService;
    private readonly WorkTaskService _taskService;
    private readonly ILogger<WorkflowExecutor> _logger;

    public async Task ExecuteAsync(string taskId, string userInput, CancellationToken ct)
    {
        var task = await _taskService.GetByIdAsync(taskId, ct)
            ?? throw new InvalidOperationException($"Task {taskId} not found");

        var manager = await _agentBuilder.BuildAsync(
            taskId, task.Provider, task.Model, task.Agent, task.Mentions, ct);

        var workflow = AgentWorkflowBuilder.BuildSequential(manager);
        var checkpointManager = new CheckpointManager(_checkpointStore);

        var run = await InProcessExecution.RunStreamingAsync(
            workflow,
            new ChatMessage(ChatRole.User, userInput),
            new RunOptions { CheckpointManager = checkpointManager },
            cancellationToken: ct);

        await _taskService.SetRunIdAsync(taskId, run.RunId, ct);

        await ConsumeEventsAsync(taskId, run, ct);
    }

    public async Task ResumeAsync(string taskId, string userResponse, CancellationToken ct)
    {
        var task = await _taskService.GetByIdAsync(taskId, ct)
            ?? throw new InvalidOperationException($"Task {taskId} not found");
        if (string.IsNullOrEmpty(task.RunId))
            throw new InvalidOperationException($"Task {taskId} has no RunId, cannot resume");

        var manager = await _agentBuilder.BuildAsync(
            taskId, task.Provider, task.Model, task.Agent, task.Mentions, ct);
        var workflow = AgentWorkflowBuilder.BuildSequential(manager);
        var checkpointManager = new CheckpointManager(_checkpointStore);

        var run = await InProcessExecution.ResumeAsync(
            workflow, task.RunId,
            new RunOptions { CheckpointManager = checkpointManager },
            cancellationToken: ct);

        // 把用户响应发给挂起的 RequestInfo
        var pending = await _hitlService.GetPendingRequestAsync(taskId, ct);
        if (pending is not null)
        {
            await run.SendResponseAsync(pending.CreateResponse(userResponse));
            await _hitlService.ClearPendingRequestAsync(taskId, ct);
        }

        await ConsumeEventsAsync(taskId, run, ct);
    }

    public Task EnqueueUserInputAsync(string taskId, string userInput, CancellationToken ct)
        => _taskService.EnqueuePendingInputAsync(taskId, userInput, ct);

    private async Task ConsumeEventsAsync(string taskId, StreamingRun run, CancellationToken ct)
    {
        try
        {
            await foreach (var evt in run.WatchAsync().WithCancellation(ct))
            {
                await _eventDispatcher.HandleAsync(taskId, run, evt, ct);

                // 终止条件：完成 / 失败 / 进入 HITL 等待
                if (evt is WorkflowOutputEvent or WorkflowErrorEvent)
                {
                    await _taskService.SetActiveAsync(taskId, false, ct);
                    return;
                }

                if (evt is RequestInfoEvent reqEvt)
                {
                    await _hitlService.PersistPendingRequestAsync(taskId, run.RunId, reqEvt.Request, ct);
                    return; // Workflow 自然挂起，等下一次 ResumeAsync
                }
            }
        }
        catch (OperationCanceledException)
        {
            _logger.LogInformation("Task {TaskId} event consumption cancelled", taskId);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Task {TaskId} execution failed", taskId);
            await _taskService.MarkFailedAsync(taskId, ex.Message, ct);
        }
    }
}
```

### 3.3 关键点

- `run.RunId` 必须保存，否则无法 Resume（这是上一版文档的漏洞）
- `cts.Cancel()` **不能**用来暂停（会让 Workflow 进入 Failed 状态）。暂停依靠 `RequestInfoEvent` 自然挂起
- 用户插话不进入这个执行器，而是写入 `pending_inputs` 队列（见 §五）

## 四、事件分发

### 4.1 接口

```csharp
public sealed class WorkflowEventDispatcher
{
    private readonly WorkExecutionLogService _logService;
    private readonly WorkTaskService _taskService;
    private readonly ChatHistoryDataProvider _chatHistory;
    private readonly IPublisher _publisher;
    private readonly ILogger<WorkflowEventDispatcher> _logger;

    public async Task HandleAsync(string taskId, StreamingRun run, WorkflowEvent evt, CancellationToken ct)
    {
        switch (evt)
        {
            case AgentResponseUpdateEvent updateEvt:
                await OnAgentDeltaAsync(taskId, updateEvt, ct);
                break;

            case ExecutorInvokedEvent invokedEvt:
                await OnExecutorInvokedAsync(taskId, invokedEvt, ct);
                break;

            case ExecutorCompletedEvent completedEvt:
                await OnExecutorCompletedAsync(taskId, completedEvt, ct);
                break;

            case ExecutorFailedEvent failedEvt:
                await OnExecutorFailedAsync(taskId, failedEvt, ct);
                break;

            case RequestInfoEvent reqEvt:
                await OnRequestInfoAsync(taskId, reqEvt, ct);
                break;

            case WorkflowOutputEvent outputEvt:
                await OnWorkflowOutputAsync(taskId, outputEvt, ct);
                break;

            case WorkflowErrorEvent errorEvt:
                await OnWorkflowErrorAsync(taskId, errorEvt, ct);
                break;
        }
    }

    // 详细处理见 §4.2-4.6
}
```

### 4.2 流式增量（AgentResponseUpdateEvent）

```csharp
private async Task OnAgentDeltaAsync(string taskId, AgentResponseUpdateEvent evt, CancellationToken ct)
{
    var update = evt.Update;
    var seq = await _logService.NextSequenceAsync(taskId, ct);

    foreach (var content in update.Contents)
    {
        switch (content)
        {
            case TextContent text when !string.IsNullOrEmpty(text.Text):
                // 文本流式：不入库（避免膨胀），只发事件给 UI
                _publisher.Publish(Events.OnWorkAssistantDelta,
                    new WorkAssistantDeltaArgs(taskId, text.Text));
                break;

            case TextReasoningContent reasoning when !string.IsNullOrEmpty(reasoning.Text):
                // 思维过程：流式给 UI（可选入库，默认不入）
                _publisher.Publish(Events.OnWorkThinkingDelta,
                    new WorkThinkingDeltaArgs(taskId, reasoning.Text));
                break;

            case FunctionCallContent funcCall:
                // 工具调用开始
                await _logService.AppendAsync(taskId, new WorkExecutionLog
                {
                    Sequence = seq,
                    LogType = WorkExecutionLogType.ToolCall,
                    Content = JsonSerializer.Serialize(
                        new ToolCallRecord(funcCall.CallId, funcCall.Name, funcCall.Arguments?.ToString()),
                        WorkModeJsonContext.Default.ToolCallRecord),
                }, ct);

                _publisher.Publish(Events.OnWorkToolCalled,
                    new WorkToolCalledArgs(taskId, funcCall.CallId!, funcCall.Name, funcCall.Arguments?.ToString() ?? ""));
                break;

            case FunctionResultContent funcResult:
                // 工具调用结果
                var status = funcResult.Exception is null ? "success" : "failed";
                var resultText = funcResult.Exception?.Message ?? funcResult.Result?.ToString() ?? "";
                await _logService.AppendAsync(taskId, new WorkExecutionLog
                {
                    Sequence = seq,
                    LogType = WorkExecutionLogType.ToolResult,
                    Content = JsonSerializer.Serialize(
                        new ToolResultRecord(funcResult.CallId, status, resultText),
                        WorkModeJsonContext.Default.ToolResultRecord),
                }, ct);

                _publisher.Publish(Events.OnWorkToolCompleted,
                    new WorkToolCompletedArgs(taskId, funcResult.CallId!, status, resultText));
                break;
        }
    }
}
```

### 4.3 RequestInfoEvent（HITL 暂停）

```csharp
private async Task OnRequestInfoAsync(string taskId, RequestInfoEvent evt, CancellationToken ct)
{
    var req = evt.Request;

    // 区分两种 HITL 来源：工具授权 / ask_user
    if (req.TryGetDataAs<ToolApprovalRequestContent>(out var approval))
    {
        // 工具授权：弹授权浮窗
        var risk = ResolveRiskLevel(approval.Function.Name);
        var paramText = FormatToolParameters(approval.Function);

        _publisher.Publish(Events.OnWorkApprovalRequested,
            new WorkApprovalRequestedArgs(
                TaskId: taskId,
                RequestId: req.RequestId,
                ToolName: approval.Function.Name,
                ParamText: paramText,
                Risk: risk));
    }
    else if (req.TryGetDataAs<HitlAskUserRequest>(out var ask))
    {
        // ask_user：在消息流追加 AI 提问，等用户在输入框回答
        await _chatHistory.AppendAssistantMessageAsync(
            await GetSessionIdAsync(taskId, ct),
            ask.Question,
            agentName: "总经理",
            ct: ct);

        _publisher.Publish(Events.OnWorkAskUser,
            new WorkAskUserArgs(taskId, req.RequestId, ask.Question));
    }
}
```

### 4.4 WorkflowOutputEvent（任务完成）

```csharp
private async Task OnWorkflowOutputAsync(string taskId, WorkflowOutputEvent evt, CancellationToken ct)
{
    // 注意：final_report 工具内部已经写过 ChatMessages 和标记完成
    // 这里只发布 UI 事件让消息流加 SummaryCard
    var summary = evt.Data?.ToString() ?? "";

    _publisher.Publish(Events.OnWorkTaskCompleted,
        new WorkTaskCompletedArgs(taskId, summary));
}
```

### 4.5 ExecutorEvent（步骤生命周期）

```csharp
private async Task OnExecutorInvokedAsync(string taskId, ExecutorInvokedEvent evt, CancellationToken ct)
{
    // 单 Agent 包装的 Workflow 里，ExecutorInvoked 一般只触发一次（Manager 启动）
    // 真正的"步骤"语义来自工具调用（dispatch_to_<dept> 等），由 §4.2 处理
    _publisher.Publish(Events.OnWorkExecutorInvoked,
        new WorkExecutorInvokedArgs(taskId, evt.ExecutorId));
}
```

> **关键设计点**：工作模式的"主步骤""子步骤"语义来自 **总经理调用工具**（`dispatch_to_<dept>` / `verify_step`），不是来自 AF 的 Executor。`ExecutorInvokedEvent` 在工作模式下用处不大，仅用作 trace。

### 4.6 工具语义到 UI 步骤的映射

UI 端订阅 `WorkToolCalled` / `WorkToolCompleted` 事件，按 **工具名** 分类成不同的卡片：

| 工具名 | UI 表现 |
|--------|---------|
| `set_plan` | 在消息流新增一条 AI 消息（计划 Markdown）|
| `dispatch_to_<dept>` | 时间线添加一个**主步骤**（标题=步骤标题，状态="运行中"）|
| 子智能体内部工具（如 `read_file`） | 当前主步骤下添加一个**工具卡片**（FoldableCard）|
| `verify_step` | 当前主步骤添加一个**验收卡片**，并把主步骤状态改"已完成"或"重试中" |
| `final_report` | 在时间线后追加 `SummaryCard` |
| `ask_user` | 在消息流追加 AI 提问，等输入 |

UI 实现细节见 §六。

## 五、用户插话队列

### 5.1 数据库表

```sql
CREATE TABLE WorkPendingInputs (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    TaskId TEXT NOT NULL,
    Content TEXT NOT NULL,
    EnqueuedAt INTEGER NOT NULL,
    Consumed INTEGER NOT NULL DEFAULT 0,
    FOREIGN KEY (TaskId) REFERENCES WorkTasks(Id) ON DELETE CASCADE
);
CREATE INDEX IX_WorkPendingInputs_Task_Pending
    ON WorkPendingInputs(TaskId, Consumed, EnqueuedAt);
```

### 5.2 服务

```csharp
public sealed class WorkTaskService
{
    public Task EnqueuePendingInputAsync(string taskId, string content, CancellationToken ct)
    {
        _db.Execute(
            "INSERT INTO WorkPendingInputs (TaskId, Content, EnqueuedAt, Consumed) VALUES (@Id, @C, @T, 0)",
            cmd =>
            {
                cmd.Parameters.AddWithValue("@Id", taskId);
                cmd.Parameters.AddWithValue("@C", content);
                cmd.Parameters.AddWithValue("@T", DateTimeOffset.UtcNow.ToUnixTimeMilliseconds());
            });
        return Task.CompletedTask;
    }

    public Task<string?> DequeuePendingInputAsync(string taskId, CancellationToken ct)
    {
        // 取最早未消费的，标记为已消费
        var content = _db.ExecuteScalar<string>("""
            SELECT Content FROM WorkPendingInputs
            WHERE TaskId = @Id AND Consumed = 0
            ORDER BY EnqueuedAt ASC LIMIT 1;
            """, cmd => cmd.Parameters.AddWithValue("@Id", taskId));

        if (!string.IsNullOrEmpty(content))
        {
            _db.Execute("""
                UPDATE WorkPendingInputs SET Consumed = 1
                WHERE Id = (SELECT Id FROM WorkPendingInputs WHERE TaskId = @Id AND Consumed = 0
                            ORDER BY EnqueuedAt ASC LIMIT 1);
                """, cmd => cmd.Parameters.AddWithValue("@Id", taskId));
        }
        return Task.FromResult(content);
    }
}
```

## 六、UI 接入（AOT 安全，code-behind 模式）

### 6.1 WorkModeViewController（新建）

不要把所有逻辑塞在 `WorkModeView.axaml.cs` 里——把"事件订阅 + 控件操作"独立成 Controller，便于测试和替换。

```csharp
namespace Netor.Cortana.UI.Controls.WorkMode;

/// <summary>
/// 工作模式视图控制器。
/// 设计模式：参考 RealtimeProcessCard / ChatView，code-behind 直接更新控件，AOT 安全。
/// </summary>
public sealed class WorkModeViewController
{
    private readonly WorkModeView _view;
    private readonly ISubscriber _subscriber;
    private readonly IWorkflowExecutor _executor;
    private readonly ILogger<WorkModeViewController> _logger;

    // 当前任务上下文（仅 UI 端用，不持久化）
    private string? _currentTaskId;
    private TimelineBlock? _currentTimeline;
    private TimelineStepHandle? _currentStep;       // 当前活跃主步骤
    private SubStepCard? _currentSubStep;            // 当前活跃子步骤
    private AiContent? _currentAiContent;            // 当前流式输出的 AI 消息

    public WorkModeViewController(
        WorkModeView view,
        ISubscriber subscriber,
        IWorkflowExecutor executor,
        ILogger<WorkModeViewController> logger)
    {
        _view = view;
        _subscriber = subscriber;
        _executor = executor;
        _logger = logger;
    }

    public void Subscribe()
    {
        _subscriber.Subscribe<WorkAssistantDeltaArgs>(Events.OnWorkAssistantDelta, OnAssistantDelta);
        _subscriber.Subscribe<WorkThinkingDeltaArgs>(Events.OnWorkThinkingDelta, OnThinkingDelta);
        _subscriber.Subscribe<WorkToolCalledArgs>(Events.OnWorkToolCalled, OnToolCalled);
        _subscriber.Subscribe<WorkToolCompletedArgs>(Events.OnWorkToolCompleted, OnToolCompleted);
        _subscriber.Subscribe<WorkApprovalRequestedArgs>(Events.OnWorkApprovalRequested, OnApprovalRequested);
        _subscriber.Subscribe<WorkAskUserArgs>(Events.OnWorkAskUser, OnAskUser);
        _subscriber.Subscribe<WorkTaskCompletedArgs>(Events.OnWorkTaskCompleted, OnTaskCompleted);

        // 授权浮窗的用户回应 → 转给 Workflow
        _view.ApprovalPopup.DecisionMade += OnApprovalDecisionMade;
        _view.ApprovalPopup.AlternativeSubmitted += OnApprovalAlternative;
    }

    // ──────── 事件处理 ────────

    private Task<bool> OnAssistantDelta(string _, WorkAssistantDeltaArgs args)
    {
        if (args.TaskId != _currentTaskId) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            EnsureCurrentAiContent();
            _currentAiContent!.Markdown = (_currentAiContent.Markdown ?? "") + args.Delta;
            ScrollToBottom();
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnToolCalled(string _, WorkToolCalledArgs args)
    {
        if (args.TaskId != _currentTaskId) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() => HandleToolCalled(args));
        return Task.FromResult(false);
    }

    private void HandleToolCalled(WorkToolCalledArgs args)
    {
        switch (args.ToolName)
        {
            case "set_plan":
                // 计划写入由 final_report / 工具结果触发的 OnWorkPlanUpdated 事件处理
                // 这里不做事
                break;

            case "dispatch_step":
            case var s when s.StartsWith("agent_", StringComparison.Ordinal):  // BuildWithSubAgents 注入的命名约定
                EnsureTimeline();
                var stepTitle = ExtractStepTitle(args.ParamText) ?? args.ToolName;
                _currentStep = _currentTimeline!.AddMainStep(stepTitle, "运行中", expanded: true);
                _currentSubStep = null;
                break;

            case "verify_step":
                if (_currentSubStep is null && _currentStep is not null)
                {
                    var card = new FoldableCard
                    {
                        CardTitle = "验收",
                        StatusText = "运行中",
                        IsExpanded = true,
                        CardContent = MakeContentBlock(args.ParamText),
                    };
                    AppendDetailToCurrentStep(card);
                }
                break;

            case "final_report":
                // 由 OnTaskCompleted 处理总结卡片
                break;

            default:
                // 普通工具：作为子步骤明细
                if (_currentStep is not null)
                {
                    var card = new FoldableCard
                    {
                        CardTitle = $"调用工具 {args.ToolName}",
                        StatusText = "运行中",
                        IsExpanded = false,
                        CardContent = MakeContentBlock(args.ParamText),
                    };
                    // 用 Tag 标记 callId 用于 OnToolCompleted 时定位
                    card.Tag = args.CallId;
                    AppendDetailToCurrentStep(card);
                }
                break;
        }
        ScrollToBottom();
    }

    private Task<bool> OnToolCompleted(string _, WorkToolCompletedArgs args)
    {
        if (args.TaskId != _currentTaskId) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            // 在当前主步骤下找到 callId 对应的卡片，更新状态
            UpdateToolCardStatus(args.CallId, args.Status, args.Result);
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnApprovalRequested(string _, WorkApprovalRequestedArgs args)
    {
        if (args.TaskId != _currentTaskId) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            _pendingApprovalRequestId = args.RequestId;
            _view.ApprovalPopup.Show(args.ToolName, args.ParamText, args.Risk);
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnAskUser(string _, WorkAskUserArgs args)
    {
        if (args.TaskId != _currentTaskId) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            // ask_user 已经写入 ChatMessages，UI 由会话消息加载机制处理
            // 这里只需要标记"等待用户回答"状态（如修改输入框 placeholder）
            _pendingAskRequestId = args.RequestId;
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnTaskCompleted(string _, WorkTaskCompletedArgs args)
    {
        if (args.TaskId != _currentTaskId) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            // 当前主步骤折叠
            if (_currentStep is not null)
            {
                _currentStep.SetStatus("已完成");
                _currentStep.SetExpanded(false);
            }

            // 追加 SummaryCard
            var summary = new SummaryCard { SummaryMarkdown = args.Summary };
            _view.MessageList.Items.Add(summary);

            // 重置当前任务上下文（回到空闲状态）
            _currentTaskId = null;
            _currentTimeline = null;
            _currentStep = null;
            _currentSubStep = null;
            _currentAiContent = null;

            ScrollToBottom();
        });
        return Task.FromResult(false);
    }

    // ──────── 授权浮窗回调 ────────

    private string? _pendingApprovalRequestId;
    private string? _pendingAskRequestId;

    private void OnApprovalDecisionMade(object? sender, ApprovalDecision decision)
    {
        if (string.IsNullOrEmpty(_pendingApprovalRequestId)) return;

        var response = decision switch
        {
            ApprovalDecision.ApproveOnce    => "approve_once",
            ApprovalDecision.ApproveSession => "approve_session",
            ApprovalDecision.ApproveAlways  => "approve_always",
```

### 6.5 软抢占的 UI 反馈

### 6.6 子智能体背景执行 UI

子智能体可能以**两种方式**被主智能体调用，UI 表现不同：

| 调用方式 | 工具名 | UI 表现 |
|---------|-------|--------|
| 同步（短任务） | `agent_<id>(...)` | 当前主步骤下加一张普通工具卡片（FoldableCard），完成后状态切"完成" |
| 背景（长任务） | `[LONG] start_subagent_<id>` + `wait_for_subagent` | 当前主步骤下加一张**子智能体卡片**（特殊样式），实时刷新进度 |

#### 子智能体卡片视觉

```text
┌─────────────────────────────────────────────────────────┐
│ ▶ 🤖 研究员（运行中 · 已运行 8 分 12 秒）                  │
└─────────────────────────────────────────────────────────┘

展开后：
┌─────────────────────────────────────────────────────────┐
│ ▼ 🤖 研究员（运行中 · 已运行 8 分 12 秒）                  │
│   ├─ 进度：正在分析 Q3 销售数据                            │
│   │                                                     │
│   ├─ 子智能体的过程明细（折叠子卡片）：                     │
│   │   ▶ 调用工具 search_docs        完成                 │
│   │   ▶ 调用工具 read_file          完成                 │
│   │   └─ 调用工具 analyze_data      运行中               │
└─────────────────────────────────────────────────────────┘
```

> 这里的 🤖 emoji 仅作为示例占位，实际按 [09 文档](./09-界面交互设计.md) 规范——卡片标题禁用 emoji。生产实现使用图标控件（Avalonia Image）或左侧色块区分子智能体类型。

#### Controller 侧的状态机

`WorkModeViewController` 维护一个字典 `_subAgentCards: Dictionary<subTaskId, SubStepCard>`：

```csharp
private readonly Dictionary<string, SubStepCard> _subAgentCards = new();
private readonly Dictionary<string, DateTime> _subAgentStartTimes = new();

// 工具调用：start_subagent_<id>
private Task<bool> OnSubAgentStarted(string _, WorkSubAgentJobStartedArgs args)
{
    if (args.TaskId != _currentTaskId) return Task.FromResult(false);

    Dispatcher.UIThread.Post(() =>
    {
        var card = new SubStepCard
        {
            CardTitle = $"子智能体：{args.OwnerName}",
            StatusText = "已启动",
            IsExpanded = true,
        };
        AppendDetailToCurrentStep(card);
        _subAgentCards[args.SubTaskId] = card;
        _subAgentStartTimes[args.SubTaskId] = DateTime.UtcNow;
    });
    return Task.FromResult(false);
}

// 进度更新（来自 wait_for_subagent 工具的进度返回，或子智能体后台 Task 的进度推送）
private Task<bool> OnSubAgentProgress(string _, WorkSubAgentProgressArgs args)
{
    if (args.TaskId != _currentTaskId) return Task.FromResult(false);

    Dispatcher.UIThread.Post(() =>
    {
        if (!_subAgentCards.TryGetValue(args.SubTaskId, out var card)) return;
        var elapsed = DateTime.UtcNow - _subAgentStartTimes[args.SubTaskId];
        card.StatusText = $"运行中 · 已运行 {FormatElapsed(elapsed)}";
        // ProgressDescription 作为子明细追加（限频 5 秒一次，避免刷屏）
        UpdateProgressDetail(card, args.ProgressDescription);
    });
    return Task.FromResult(false);
}

private Task<bool> OnSubAgentCompleted(string _, WorkSubAgentJobCompletedArgs args)
{
    if (args.TaskId != _currentTaskId) return Task.FromResult(false);

    Dispatcher.UIThread.Post(() =>
    {
        if (!_subAgentCards.TryGetValue(args.SubTaskId, out var card)) return;
        card.StatusText = "已完成";
        card.IsExpanded = false;  // 完成后默认折叠
        _subAgentCards.Remove(args.SubTaskId);
        _subAgentStartTimes.Remove(args.SubTaskId);
    });
    return Task.FromResult(false);
}

private Task<bool> OnSubAgentFailed(string _, WorkSubAgentJobFailedArgs args)
{
    if (args.TaskId != _currentTaskId) return Task.FromResult(false);

    Dispatcher.UIThread.Post(() =>
    {
        if (!_subAgentCards.TryGetValue(args.SubTaskId, out var card)) return;
        card.StatusText = "失败";
        // 失败明细追加到卡片内，让用户看错误原因
        UpdateProgressDetail(card, $"错误：{args.Error}");
    });
    return Task.FromResult(false);
}
```

#### 与子智能体内部工具调用的关联

子智能体在执行过程中可能调用工具（如 `read_file`、`search_docs`），这些工具调用通过 `WorkExecutionLogs` 写日志（`LogType=SubAgentDelta`）。UI 端：

- 普通工具调用事件 `OnWorkToolCalled` 携带的 `OwnerName` 字段区分主 / 子智能体
- 主智能体的工具调用 → 当前主步骤下追加（已有逻辑）
- 子智能体的工具调用 → 找到对应 `_subAgentCards[subTaskId]`，把工具卡片追加到该子智能体卡片内部

这要求 `WorkToolCalledArgs` 增加可选字段 `OwnerSubTaskId`（[13 文档 §八](./13-执行引擎与事件驱动.md#八事件清单在-eventscs-补充)），由 `WorkflowEventDispatcher` 在构造事件时填入。

#### 取消按钮

子智能体卡片右上角提供一个小"取消"按钮（这是工作模式 UI 的**第三处例外按钮**——前两处是 `ApprovalFloatPopup` 和 `TaskResumePromptCard`）：

- 用户点击 → 触发 `cancel_subagent(subTaskId)` 工具的等价路径
- 实际不通过 AI，直接调 `IBackgroundJobExecutor.CancelAsync`
- 取消后卡片状态切"已取消"

> **破例理由**：用户必须有"立刻停一个跑了 8 小时还没结束的子智能体"的能力，等 AI 自己决定取消太慢。这与"零交互按钮"原则的破例条件一致——必须用户做的硬决策。
