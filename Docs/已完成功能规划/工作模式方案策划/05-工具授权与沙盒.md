# 05 - 工具授权与沙盒（解决问题 #5）

> 解决问题：完成工具调用的授权 + 沙盒机制
> 关键源码：`src\Microsoft.Agents.AI\Harness\ToolApproval\` / `src\Microsoft.Agents.AI.Hyperlight\` / `src\Microsoft.Agents.AI.Tools.Shell\`

## 一、工具调用授权（Approval）

### 1.1 三层防护

```
┌─────────────────────────────────────────┐
│ Layer 1: ApprovalRequiredAIFunction      │ ← 工具级标记（哪些工具需要授权）
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│ Layer 2: ToolApprovalAgent (装饰器)      │ ← 拦截调用 + 弹审批请求
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│ Layer 3: 规则持久化（StateBag）          │ ← "Don't ask again" 规则
└─────────────────────────────────────────┘
```

### 1.2 `ApprovalRequiredAIFunction`

把任意 `AIFunction` 包装为"需要授权"版本：

```csharp
[Description("把消息发送给老板")]
static async Task NotifyBoss(string message) { ... }

// 普通工具
var rawTool = AIFunctionFactory.Create(NotifyBoss);

// 需要授权的工具
AIFunction approvalTool = new ApprovalRequiredAIFunction(rawTool);

// 注册到智能体
var agent = chatClient.AsAIAgent(new ChatClientAgentOptions
{
    ChatOptions = new ChatOptions { Tools = [approvalTool] }
});
```

### 1.3 `ToolApprovalAgent`（中间件）

源码：`src\Microsoft.Agents.AI\Harness\ToolApproval\ToolApprovalAgent.cs`

```csharp
public sealed class ToolApprovalAgent : DelegatingAIAgent
{
    protected override async Task<AgentResponse> RunCoreAsync(...)
    {
        // 1. 检查本次响应中是否有需要授权的工具调用
        var (state, callerMessages, nextQueuedItem) =
            this.PrepareInboundMessages(messages, session);

        if (nextQueuedItem is not null)
        {
            // 2. 暂停 - 返回特殊消息让外部弹审批 UI
            return new AgentResponse(
                new ChatMessage(ChatRole.Assistant, [nextQueuedItem]));
        }

        // 3. 已批准 / 不需要授权 → 透传给内层
        return await this.InnerAgent.RunAsync(...);
    }
}
```

### 1.4 审批规则（"Don't ask again"）

规则存在 `AgentSessionStateBag` 中，**随会话持久化**：

| 规则粒度 | 示例 |
|---------|------|
| 工具级 | "永远允许调用 `SearchWeb`" |
| 工具+参数 | "永远允许调用 `DeleteFile(path='./tmp/*')`" |
| 单次 | 只对本次调用授权 |
| 拒绝 | 永远拒绝 |

### 1.5 在 GroupChat 中的应用

源码示例：`samples\03-workflows\Agents\GroupChatToolApproval\Program.cs`

```csharp
// 不同角色不同的工具与授权策略
var devAgent = chatClient.AsAIAgent(new ChatClientAgentOptions
{
    ChatOptions = new ChatOptions { Tools = [readCode, writeCode] }
});

var opsAgent = chatClient.AsAIAgent(new ChatClientAgentOptions
{
    ChatOptions = new ChatOptions { Tools = [
        new ApprovalRequiredAIFunction(deployToProd),  // 高危必批
        new ApprovalRequiredAIFunction(restartService),
    ] }
});

// GroupChat 工作流
var workflow = AgentWorkflowBuilder
    .CreateGroupChatBuilderWith(agents => new RoundRobinGroupChatManager(agents))
    .AddParticipants(devAgent, opsAgent)
    .Build();

// 处理审批
await foreach (var evt in InProcessExecution.RunStreamingAsync(workflow, input))
{
    if (evt is RequestInfoEvent reqEvt &&
        reqEvt.Request.TryGetDataAs(out ToolApprovalRequestContent? approval))
    {
        // 在 UI 显示：
        // "OpsAgent 想调用 deployToProd(env='production')"
        // 用户点"批准" → CreateResponse(approved: true)
        var userDecision = await PromptUser(approval);
        await run.SendResponseAsync(
            reqEvt.Request.CreateResponse(
                approval.CreateResponse(approved: userDecision)));
    }
}
```

## 二、沙盒机制

### 2.1 三个隔离级别

| 级别 | 方案 | 强度 | 性能开销 | 适用 |
|------|------|------|---------|------|
| 进程内 | `AppDomain` / 反射屏蔽 | 弱 | 低 | 调用受信代码 |
| 进程级 | 子进程 + 受限账户 | 中 | 中 | Shell 命令 |
| 虚拟化 | **Hyperlight**（VM 级） | 强 | 中-高 | 不可信用户代码 |
| 容器 | Docker / k8s | 强 | 高 | 长任务 |

### 2.2 `Microsoft.Agents.AI.Hyperlight`（**关键沙盒包**）

#### 2.2.1 Hyperlight 是什么？
- Microsoft 开源的**轻量级 VM**
- 启动只需毫秒
- 比 Docker 容器更轻，比进程沙盒更安全
- 用 Hypervisor 隔离每次工具调用

#### 2.2.2 用途
为 LLM 生成的代码 / 不可信工具调用提供**毫秒级 VM 隔离**。

#### 2.2.3 用法（概念）

```csharp
// 包装一个会执行不可信代码的工具
var pythonExecutor = new HyperlightFunction(
    name: "execute_python",
    description: "执行 Python 代码（沙盒内）",
    sandboxOptions: new HyperlightSandboxOptions
    {
        MemoryLimitMB = 128,
        CpuTimeLimitMs = 5000,
        AllowNetwork = false,
        AllowFileSystem = false,
    },
    body: async (code) => { /* 在 Hyperlight VM 内执行 */ });

var agent = chatClient.AsAIAgent(new ChatClientAgentOptions
{
    ChatOptions = new ChatOptions { Tools = [pythonExecutor] }
});
```

#### 2.2.4 限制
- 仅支持 Linux 主机（截至 v1.6.0）
- 沙盒内需 Hyperlight 兼容的运行时（受限 .NET / WASM）

#### 2.2.5 关键源码
- `src\Microsoft.Agents.AI.Hyperlight\`

### 2.3 `Microsoft.Agents.AI.Tools.Shell`

#### 2.3.1 用途
提供"在受限 shell 中执行命令"的标准工具。

#### 2.3.2 关键能力
- 命令白名单 / 黑名单
- 工作目录限制
- 超时控制
- 输出捕获 + 截断
- **可与 `ApprovalRequiredAIFunction` 组合**

#### 2.3.3 用法（概念）

```csharp
var shellTool = new ShellCommandTool(new ShellCommandToolOptions
{
    AllowedCommands = ["git", "dotnet", "npm"],
    WorkingDirectory = "/sandbox",
    TimeoutSeconds = 30,
    MaxOutputBytes = 1024 * 1024,
});

// 高危命令仍需用户授权
var approvedShellTool = new ApprovalRequiredAIFunction(shellTool);
```

#### 2.3.4 关键源码
- `src\Microsoft.Agents.AI.Tools.Shell\`

## 四、Cortana 项目沙盒分级建议

### 4.1 风险分级

| 工具类型 | 风险 | 沙盒方案 | 授权方案 |
|---------|------|---------|---------|
| 只读查询（搜索/读取数据库） | 低 | 无 | 自动批准 |
| 修改本地状态（写文件、改设置） | 中 | `FileAccessProvider` | "Don't ask again" 规则 |
| 调用外部 API（发邮件、发消息） | 中-高 | 进程内 + 速率限制 | **必须用户批准** |
| 执行 Shell / 代码 | 高 | `Tools.Shell` + 进程隔离 | **必须用户批准** |
| 执行用户上传的代码 | 极高 | **Hyperlight** | **必须用户批准 + 二次确认** |
| 部署/删库等不可逆操作 | 极高 | Hyperlight / 不允许 | **必须老板二次确认** |

### 4.2 设计草图

```csharp
// 1. 装配全局策略
var agent = chatClient.AsAIAgent(new ChatClientAgentOptions { ... });

// 2. 包装授权中间件
var safeAgent = new AIAgentBuilder(agent)
    .Use(inner => new ToolApprovalAgent(inner))      // 全局工具审批
    .Use(inner => new LoggingAgent(inner))           // 审计日志
    .Build(serviceProvider);

// 3. 工具按风险分类装配
ChatClientAgentOptions options = new()
{
    ChatOptions = new ChatOptions
    {
        Tools = [
            // 低风险（直接给）
            AIFunctionFactory.Create(SearchKnowledgeBase),
            AIFunctionFactory.Create(ReadDocument),

            // 中风险（受限）
            ScopedFileReadTool(allowedRoots: [...]),

            // 高风险（必批）
            new ApprovalRequiredAIFunction(AIFunctionFactory.Create(SendEmail)),
            new ApprovalRequiredAIFunction(AIFunctionFactory.Create(DeleteRecord)),

            // 极高风险（Hyperlight + 必批）
            new ApprovalRequiredAIFunction(
                new HyperlightFunction("execute_user_code", ...)),
        ]
    }
};
```

## 六、HumanInTheLoop 综合示例

源码示例：`samples\03-workflows\HumanInTheLoop\Program.cs`

```csharp
// 主流程
var workflow = AgentWorkflowBuilder.BuildSequential(
    plannerAgent,
    executorAgent  // executor 调用需授权的工具
);

var run = await InProcessExecution.RunStreamingAsync(workflow, userRequest,
    new RunOptions { CheckpointManager = checkpointStore });

await foreach (var evt in run.WatchAsync())
{
    switch (evt)
    {
        case RequestInfoEvent reqEvt
                when reqEvt.Request.TryGetDataAs(out ToolApprovalRequestContent? approval):
            // 1. 持久化状态
            await SaveStateAsync(run.RunId);
            // 2. 通知用户
            await NotifyUserForApprovalAsync(userId, approval);
            return;  // 暂停

        case AgentResponseUpdateEvent updateEvt:
            await PushToClientAsync(updateEvt);
            break;

        case WorkflowOutputEvent outputEvt:
            await DeliverFinalResultAsync(outputEvt.Data);
            break;
    }
}

// 用户批准后另起进程：
var run = await InProcessExecution.ResumeAsync(workflow, runId, checkpointStore);
await run.SendResponseAsync(approval.CreateResponse(approved: true));
// 继续监听...
```

## 八、最佳实践清单

- [ ] **所有外部 API 调用工具用 `ApprovalRequiredAIFunction` 包裹**
- [ ] **所有 Shell / 代码执行工具用 `Tools.Shell` 或 `Hyperlight`**
- [ ] **所有文件访问通过 `FileAccessProvider` 限制路径**
- [ ] **全局装配 `LoggingAgent` 做审计**
- [ ] **审批记录上链 / 写不可篡改日志**
- [ ] **"Don't ask again" 规则有过期时间（如 24 小时）**
- [ ] **极高风险操作需要"二次密码确认"或多签**
- [ ] **审批 UI 显示工具名 + 参数 + 调用方智能体 + 上下文摘要**
- [ ] **拒绝审批后智能体能优雅降级（说明无法完成）**
