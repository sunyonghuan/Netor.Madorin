# 04 - 长任务与持久化（解决"主智能体被卡住"问题）

> 解决问题 #2：通讯无状态，不能让主智能体一直卡着

## 一、问题分析

### 1.1 为什么会卡住？

传统模式：
```
Client ──HTTP──→ MainAgent.RunAsync() ──→ 等待子智能体 ──→ 等待子智能体 ──→ ...
        (HTTP超时通常 30s-5min)
```

子任务可能耗时数小时甚至数天（例如生成视频、爬取大量数据），HTTP/WebSocket 连接撑不住。

### 1.2 解决思路

**把"长任务"从同步调用变成异步任务**：
1. Client 发起任务 → 立即返回 `taskId`
2. MainAgent 把任务派发给后台执行器，立即返回
3. 后台执行器持久化进度到存储（每个步骤都写检查点）
4. 任意进程崩溃后能从检查点恢复
5. Client 通过事件流（SSE/WebSocket）订阅进度
6. 任务完成时通过事件/回调通知 Client

## 二、AF 框架的三层方案

### 2.1 Level 1：内存级别 — `BackgroundAgentsProvider`

**用途**：单进程内把"等待子智能体"变成"异步触发，主线程返回"。

**源码**：`src\Microsoft.Agents.AI\Harness\BackgroundAgents\`

```csharp
// 主智能体 + BackgroundAgentsProvider
var provider = new BackgroundAgentsProvider(...);

var managerAgent = chatClient.AsAIAgent(new ChatClientAgentOptions
{
    AIContextProviders = [provider],
    Tools = [
        // 框架自动注入这两个工具：
        // - StartBackgroundTask(agentName, prompt) → taskId
        // - CheckBackgroundTask(taskId) → status/result
    ],
});
```

**运行时状态**（不会被序列化，进程崩溃即丢）：
```csharp
internal sealed class BackgroundAgentRuntimeState
{
    public Dictionary<int, Task<AgentResponse>> InFlightTasks { get; }
    public Dictionary<int, AgentSession> BackgroundTaskSessions { get; }
}
```

**适用**：
- ✅ 子任务在分钟级
- ✅ 单进程部署
- ❌ 进程重启会丢失进度

---

### 2.2 Level 2：检查点级别 — `Checkpointing`

**用途**：工作流执行期间每个 superstep 后保存状态，支持崩溃恢复。

**源码**：`src\Microsoft.Agents.AI.Workflows\Checkpointing\`

#### 2.2.1 关键接口

```csharp
public interface ICheckpointManager
{
    Task<Checkpoint?> LoadCheckpointAsync(string runId, CancellationToken ct);
    Task SaveCheckpointAsync(Checkpoint checkpoint, CancellationToken ct);
}

public interface ICheckpointStore
{
    Task<JsonElement?> LoadAsync(string key, CancellationToken ct);
    Task SaveAsync(string key, JsonElement value, CancellationToken ct);
}
```

#### 2.2.2 内置实现

| 实现 | 用途 |
|------|------|
| `InMemoryCheckpointManager` | 测试 |
| `FileSystemJsonCheckpointStore` | 单机部署（简单） |
| `JsonCheckpointStore` (abstract) | 自定义存储（DB/Redis/Cosmos） |

#### 2.2.3 用法

```csharp
var checkpointManager = new InMemoryCheckpointManager();

var run = await InProcessExecution.RunStreamingAsync(
    workflow, input,
    new RunOptions { CheckpointManager = checkpointManager });

await foreach (var evt in run.WatchAsync())
{
    // 进程可在此崩溃
    if (evt is RequestInfoEvent reqEvt)
    {
        // 暂停 — 保存 runId 到外部存储
        await SaveRunIdSomewhere(run.RunId, reqEvt.Request);
        return; // 退出进程
    }
}

// === 在另一个进程或时间继续 ===
var resumedRun = await InProcessExecution.ResumeAsync(
    workflow, runId, checkpointManager);
await resumedRun.SendResponseAsync(reqEvt.Request.CreateResponse(...));
```

**适用**：
- ✅ 任务在小时级
- ✅ 需要崩溃恢复
- ⚠️ 需要外部存储（Cosmos/SQL/文件）

### 2.3 Level 3：Durable Task 级别 — `DurableAIAgent`

**用途**：基于 Azure Durable Task Framework，全功能可靠分布式编排。**生产级长任务最优解**。

**源码**：`src\Microsoft.Agents.AI.DurableTask\`

#### 2.3.1 核心架构

#### 2.3.3 与 Azure Functions 集成

```csharp
// Program.cs
using IHost app = FunctionsApplication
    .CreateBuilder(args)
    .ConfigureFunctionsWebApplication()
    .ConfigureDurableAgents(options =>
    {
        options.AddAIAgent(generalManagerAgent, timeToLive: TimeSpan.FromHours(24));
        options.AddAIAgent(workerAgent, timeToLive: TimeSpan.FromHours(2));
    })

app.Run();

// HTTP 触发函数
[Function("StartTask")]
public async Task<HttpResponseData> StartTask(
    [HttpTrigger("post")] HttpRequestData req,
    [DurableClient] DurableTaskClient client)
{
    var input = await req.ReadFromJsonAsync<TaskInput>();

    // 启动 Orchestration（立即返回）
    string instanceId = await client.ScheduleNewOrchestrationInstanceAsync(
        nameof(GeneralManagerOrchestration), input);

    // 返回 202 + 状态查询 URL
    return client.CreateCheckStatusResponse(req, instanceId);
}

// Orchestrator 函数
[Function(nameof(GeneralManagerOrchestration))]
public async Task<TaskResult> GeneralManagerOrchestration(
    [OrchestrationTrigger] TaskOrchestrationContext ctx,
    TaskInput input)
{
    // 这里的代码可以"睡几小时再醒来"
    // 框架自动持久化每一步

    var manager = ctx.GetAIAgent("GeneralManager");
    var session = await manager.CreateSessionAsync();

    // 调用子智能体（每次调用都是一个 Activity）
    var planResponse = await manager.RunAsync(input.Request, session);

    // 等待 24 小时也没问题（Durable Timer）
    await ctx.CreateTimer(TimeSpan.FromMinutes(30));

    var finalResponse = await manager.RunAsync("继续", session);
    return new TaskResult(finalResponse.Messages.Last().Text);
}
```

## 三、HITL（Human-in-the-Loop）暂停机制

### 3.1 用途
任务执行到一半需要：
- 工具调用授权（"是否允许执行 rm -rf?"）
- 业务确认（"金额超过 10 万，需要老板审批"）
- 信息补全（"用户没说交付日期"）

执行流必须**暂停 → 等待外部响应 → 恢复**。

### 3.2 关键事件：`RequestInfoEvent`

```csharp
public sealed class RequestInfoEvent : WorkflowEvent
{
    public RequestInfo Request { get; }
}

public sealed class RequestInfo
{
    public string RequestId { get; }
    public string ExecutorId { get; }
    public object Data { get; }   // 通常是 ToolApprovalRequestContent / 自定义请求

    public bool TryGetDataAs<T>(out T? data);
    public RequestResponse CreateResponse(object responseData);
}
```

### 3.3 暂停-恢复模式

```csharp
StreamingRun run = await InProcessExecution.RunStreamingAsync(workflow, input,
    new RunOptions { CheckpointManager = checkpointManager });

await foreach (var evt in run.WatchAsync())
{
    if (evt is RequestInfoEvent reqEvt)
    {
        // 1. 持久化 runId 到 DB（key: 例如用户ID/会话ID）
        await db.SaveAsync(userId, run.RunId, reqEvt.Request);

        // 2. 通知前端弹审批 UI
        await SendToUser(userId, reqEvt.Request.Data);

        // 3. 退出进程（任务暂停在 Hub 中）
        return;
    }
}

// === 用户审批后，新进程恢复 ===
public async Task ApproveAsync(string userId, bool approved)
{
    var (runId, request) = await db.LoadAsync(userId);
    var resumedRun = await InProcessExecution.ResumeAsync(workflow, runId, checkpointManager);

    await resumedRun.SendResponseAsync(
        request.CreateResponse(new ToolApprovalResponseContent(approved)));

    // 继续监听...
    await foreach (var evt in resumedRun.WatchAsync()) { ... }
}
```

## 四、流式事件订阅（Client 实时获取进度）

### 4.1 服务端流式

```csharp
// Server: 把工作流事件转发为 SSE
[HttpGet("/tasks/{id}/stream")]
public async Task Stream(string id)
{
    Response.ContentType = "text/event-stream";
    var run = await InProcessExecution.ResumeAsync(workflow, id, checkpointManager);

    await foreach (var evt in run.WatchAsync())
    {
        await Response.WriteAsync($"data: {JsonSerializer.Serialize(evt)}\n\n");
        await Response.Body.FlushAsync();
    }
}
```

### 4.2 客户端
```typescript
const es = new EventSource(`/tasks/${id}/stream`);
es.onmessage = e => {
  const evt = JSON.parse(e.data);
  // 显示进度
};
```

## 六、推荐方案矩阵

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 任务 < 30 秒 | 普通 RunAsync | 不需要复杂方案 |
| 任务 30 秒 - 5 分钟 | `BackgroundAgentsProvider` | 主智能体不卡 |
| 任务 5 分钟 - 1 小时 | Workflow + Checkpoint | 支持中断恢复 |
| 任务 > 1 小时或需要可靠性 | **DurableAIAgent + Azure Functions** | 生产级长任务 |
| 需要审批/HITL | Workflow + RequestInfoEvent + Checkpoint | 暂停-恢复 |
| 跨地理区域 / 多实例 | DurableTask + Cosmos / SQL Hub | 分布式 |
