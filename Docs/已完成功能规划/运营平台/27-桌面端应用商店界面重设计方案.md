# 桌面端应用商店界面重设计方案 : 100%

## 目标

当前应用商店界面仍停留在临时工程面板状态：信息层级弱、内容密度低、错误提示不准确，且本地联调时 HTTPS/SSL 失败会干扰体验。本方案用于重做桌面端应用商店的视觉与交互，并同步修正本地 HTTP 联调策略。

新版本定位为 Madorin 的资源中心：用于发现、安装、更新和管理插件、技能、智能体与解决方案。整体气质应当是专业、克制、可靠的运营工具，而不是消费级商城首页。

## 设计原则

- 第一屏明确展示登录状态、资源数量、更新数量和已安装数量。
- 错误在页面内呈现，不用弹窗打断浏览；只有无法创建窗口这类严重错误才弹窗。
- 本地测试默认使用 HTTP，不强制 HTTPS；SSL 错误要给出明确修复动作。
- 资源列表要承载安装决策所需信息：类型、开发者、描述、版本、大小、状态、操作。
- 保持暗色主题，但减少大面积纯黑空白，提升层级与可读性。
- 控件尺寸稳定，按钮、徽标、卡片在内容变化时不应抖动。
- 应用商店不显示平台地址，不提供连接设置入口；连接配置统一放到系统设置面板。

## 信息架构

应用商店保留独立窗口，并从主窗口顶部菜单进入：

`设置 -> 应用商店...`

窗口内包含四个导航项：

- `发现`：资源市场首页，展示可安装资源。
- `我的资源`：当前账号已拥有、可安装或已失效的资源。
- `更新`：已安装资源的可用更新。
- `已安装`：本地安装记录、版本、路径与状态。

  - 已登录：显示登录名与退出按钮。

使用图标占位 + 文本的紧凑导航：

- 发现
- 我的资源

- 已安装

顶部为概览指标：

- 可用资源
- 我的资源
- 可更新
- 已安装

下方按当前导航展示内容。资源市场默认展示分类筛选、排序控件和高密度资源列表。

## 资源列表

未安装资源需要更高信息密度，采用列表型布局，而不是大卡片。

每行资源包含：

- 资源名称
- 类型徽标：`插件` / `技能` / `智能体` / `方案`
- 开发者
- 一行短描述，超出省略
- 当前版本
- 包大小或价格
- 更新时间
- 安装状态：`未安装` / `已安装` / `可更新` / `已失效`
- 操作按钮：`安装` / `更新` / `重新安装` / `打开目录`

视觉要求：

- 列表行背景略亮于页面背景。
- 弱边框，悬停时轻微提亮。
- 右侧操作区固定宽度。
- 圆角 6-8px。
- 禁止使用大面积渐变和装饰光斑。

## 连接与 SSL 策略

默认本地开发地址：

```text
http://localhost:5190
```

规则：

- `localhost`、`127.0.0.1`、`::1` 默认推荐 HTTP。
- 本地联调不使用 HTTPS，避免开发证书和 SSL 握手问题。
- 线上地址默认 HTTPS，例如 `https://platform.netor.me`。
- 用户输入 `https://localhost:*` 且连接失败时，提示改用 `http://localhost:5190`。

错误分类：

- 后端未启动：`无法连接平台服务，请确认 API 已启动。`
- 地址错误：`平台地址不可达，请检查 Platform.BaseUrl。`
- SSL 失败：`SSL 连接失败。本地测试请使用 HTTP 地址。`
- 未登录：`请登录平台账号后安装资源。`
- 401：`登录已过期，请重新登录。`

## 系统设置中的连接配置

应用商店内不显示平台地址，也不显示 `账号与连接` 导航。平台连接配置移动到系统设置面板的 `应用商店` 分组。

系统设置字段与操作：

- 平台地址输入框。
- 环境快捷按钮：`本地开发` / `线上平台` / `自定义`。
- `测试连接` 按钮。
- 最近一次连接错误详情。

该设置分组负责解决本地 HTTP、线上 HTTPS、地址错误问题。登录只在应用商店窗口内处理。

## 交互流程

1. 打开应用商店。
2. 先加载本地安装记录。
3. 使用系统设置中的平台地址请求资源市场。
4. 连接失败时展示错误状态，不显示平台地址，不提供连接设置按钮，只提示前往系统设置调整。
5. 未登录时右上角显示登录按钮。
6. 点击登录后展示账号名和密码登录面板。
7. 登录成功后右上角显示登录名，并自动同步 `我的资源` 与 `更新`。
8. 安装前弹二次确认，安装过程在资源列表行和状态区域展示进度。
