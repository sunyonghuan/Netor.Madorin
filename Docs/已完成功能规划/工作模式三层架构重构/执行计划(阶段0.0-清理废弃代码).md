## 一、本阶段目标

清理 P2 旧动态智能体的残留代码——这套代码在 P4 架构落地时已被 `TaskEngine.OrchestratorAgent` 替代，但残留物未删除。本阶段一次性清理干净，让后续改造在干净的代码基础上进行。

**前置条件**：本阶段独立可上线，**不依赖任何其他子阶段**——既可以单独发版（仅作为代码清理），也可以作为阶段 0.1+ 的前置。

**风险评估**：低。调研明确所有残留代码均为死代码或悬空引用，删除后无编译断裂、无运行时影响。

- 如果 Step 1 删除后**意外发现某个集成测试 / 反射 / 外部插件仍引用** `BuildDynamicSubAgent` → 立即 revert，回到调研补全引用关系再决定
