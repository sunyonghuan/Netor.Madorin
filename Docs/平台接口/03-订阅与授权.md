## 接口说明

### 09 有效授权列表

`GET /api/v1/entitlements`

- 认证：需要；无其他参数、无请求体。
- 成功：`200`，根数组 [`ApiEntitlement[]`](./03-订阅与授权.md#apientitlement)。
- `401` 空体：认证失败。
- 仅返回当前账号 `Active`、尚未到期且资源已发布的订阅，不自动创建免费订阅。
- `pricingPlanName` 允许 null；没有授权返回 `[]`。

### 19 我的订阅

`GET /api/v1/me/subscriptions`

- 认证：需要；无其他参数、无请求体。
- 成功：`200`，根数组 [`ApiSubscriptionItem[]`](./03-订阅与授权.md#apisubscriptionitem)，无分页。
- `401` 空体：认证失败。
- 返回当前账号全部状态的订阅；不同于仅有效授权的 `/entitlements`。
- `isExpired = expiresAtUtc <= 当前时间`；`remainingDays = ceil((expiresAtUtc - 当前时间).TotalDays)`，可以为负数，没有截断为零。

### 20 取消订阅

`POST /api/v1/subscriptions/{subscriptionId}/cancel`

| 参数 | 位置 | C# / 传输类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `subscriptionId` | Path | `string` | 是 | 当前账号拥有的订阅 ID |

- 认证：需要；无请求体、无业务 Query。
- 成功：`200`，[`ApiCancelSubscriptionResponse`](./03-订阅与授权.md#apicancelsubscriptionresponse)，`canceled = true`。
- `401` 空体：认证失败。
- `404` 空体：订阅不存在或不属于当前账号。

仅 `Active` 状态会改为 `Canceled` 并记录取消时间；已取消或其他非 Active 状态只要记录属于当前账号也返回成功。不是支付退款接口。

### 22 订阅指定资源

`POST /api/v1/assets/{assetId}/subscribe`

| 参数 | 位置 | C# / JSON 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `assetId` | Path | `string` | 是 | 资源 ID，此接口不按 slug 查询 |
| `pricingPlanId` | JSON Body | `string` | 是 | 对应启用方案 ID；非空白 |

- 认证：需要；请求模型为 [`ApiCreateSubscriptionRequest`](./03-订阅与授权.md#apicreatesubscriptionrequest)。
- 成功：`200`，[`ApiSubscribeResponse`](./03-订阅与授权.md#apisubscriberesponse)。
- `400 ProblemDetails`：订阅方案空白。
- `401` 空体：认证失败。
- `403 ProblemDetails`：服务层发现账号禁用。
- `404` 空体：资源/方案不存在、方案不属于资源、方案停用或资源未发布。

按方案 **price <= 0** 直接建立免费订阅，返回 `free-subscription-created`；否则创建待支付订单，返回 `pending-order-created`。这里的免费判断与安装/下载中“Free 类型或价格非正”的判断并不完全相同。付费下单不会立即开通授权。

## 数据模型

下表逐项列出请求和响应字段的 C# 类型、JSON 类型、可空性或必填要求，以及实际检查和默认处理。模型嵌套引用及共享模型可通过本页链接查看。

### ApiCreateSubscriptionRequest

| JSON 字段 | C# 类型 | JSON 类型 | 必填 | 检查与处理 |
| --- | --- | --- | --- | --- |
| `pricingPlanId` | `string` | `string` | 是 | 显式拒绝 null/空白，需属于目标资源且启用 |

### ApiSubscribeResponse

同时用于 `/assets/{assetId}/subscribe` 和 `POST /orders`。

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `isFreeSubscription` | `bool` | `boolean` | 否 | true 表示免费订阅分支 |
| `assetId` | `string?` | `string / null` | 是 | 免费分支为资源 ID；付费分支为 null |
| `orderId` | `string?` | `string / null` | 是 | 付费分支为订单 ID；免费分支为 null |
| `status` | `string` | `string` | 否 | 仅 `free-subscription-created` 或 `pending-order-created` |

### ApiSubscriptionItem

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `subscriptionId` | `string` | `string` | 否 | 订阅 ID |
| `assetId` | `string` | `string` | 否 | 资源 ID |
| `assetSlug` | `string?` | `string / null` | 是 | 关联资源存在时返回标识 |
| `assetType` | `AssetType?` | `number (int32 enum) / null` | 是 | 关联资源类型 |
| `assetName` | `string` | `string` | 否 | 资源名称，缺失回退“未知资源” |
| `pricingPlanId` | `string` | `string` | 否 | 方案 ID |
| `pricingPlanName` | `string?` | `string / null` | 是 | 方案名称 |
| `pricingPlanType` | `PricingPlanType?` | `number (int32 enum) / null` | 是 | 方案类型 |
| `status` | `SubscriptionStatus` | `number (int32 enum)` | 否 | 数据库存储状态 |
| `startedAtUtc` | `DateTimeOffset` | `string (date-time)` | 否 | 订阅开始时间 |
| `expiresAtUtc` | `DateTimeOffset` | `string (date-time)` | 否 | 到期时间 |
| `isExpired` | `bool` | `boolean` | 否 | 仅比较到期时间，不等于状态是否可用 |
| `remainingDays` | `int` | `number (int32)` | 否 | 剩余天数向上取整，可以为负 |

### ApiCancelSubscriptionResponse

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `subscriptionId` | `string` | `string` | 否 | 请求中的订阅 ID |
| `canceled` | `bool` | `boolean` | 否 | 成功响应固定 true |

### ApiEntitlement

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `subscriptionId` | `string` | `string` | 否 | 订阅 ID |
| `assetId` | `string` | `string` | 否 | 资源 ID |
| `assetSlug` | `string` | `string` | 否 | 资源标识 |
| `assetType` | `AssetType` | `number (int32 enum)` | 否 | 资源类型 |
| `assetName` | `string` | `string` | 否 | 资源名称 |
| `pricingPlanName` | `string?` | `string / null` | 是 | 方案名称 |
| `startedAtUtc` | `DateTimeOffset` | `string (date-time)` | 否 | 开始时间 |
| `expiresAtUtc` | `DateTimeOffset` | `string (date-time)` | 否 | 到期时间 |

## 请求与响应示例

以下 ID、令牌、哈希和业务数据均为格式示例，不是实际可用凭据；日期是示例值。示例中的 manifest 内容仅展示 JSON 嵌入方式，不声明统一的清单内部字段。

```http
POST /api/v1/assets/asset-example/subscribe HTTP/1.1
Authorization: Bearer example-payload.example-signature
Content-Type: application/json

{
  "pricingPlanId": "plan-free-example"
}
```

免费分支的 `200` 响应：

```json
{
  "isFreeSubscription": true,
  "assetId": "asset-example",
  "orderId": null,
  "status": "free-subscription-created"
}
```
