## 接口说明

### 02 非版本化市场列表

`GET /api/market/assets`

- 认证：不需要。
- 参数：无；无请求体。
- 成功：`200`，根数组 [`MarketAssetListItem[]`](./02-资源市场.md#marketassetlistitem)；无数据返回 `[]`。
- 范围：全部已发布资源，按 `PublishedAtUtc` 倒序，无分页。
- 格式：这里的 `type` 是 `"Plugin"`、`"Skill"`、`"Agent"`、`"Solution"` 字符串，区别于 v1 接口整数枚举。

### 05 分页资源列表

`GET /api/v1/assets`

- 认证：不需要。
- 请求体：无。
- 成功：`200`，[`ApiAssetPageResponse`](./02-资源市场.md#apiassetpageresponse)，其中 `items` 为 [`ApiAssetListItem[]`](./02-资源市场.md#apiassetlistitem)。

| 参数 | 位置 | C# 类型 | 传输类型 | 必填 | 处理规则 |
| --- | --- | --- | --- | --- | --- |
| `page` | Query | `int` | 十进制整数文本 | 是 | `<= 0` 时取 1；其他值最小为 1 |
| `pageSize` | Query | `int` | 十进制整数文本 | 是 | `<= 0` 时取 20；最终限制在 1 至 100 |
| `type` | Query | `AssetType?` | 枚举数值或名称文本 | 否 | 省略表示全部类型；例如 `1` 或 `Plugin` |

示例：`/api/v1/assets?page=1&pageSize=20&type=1`。

仅查询 `Published` 资源，先按 `isFeatured` 倒序，再按实体 `TimeStamp` 倒序。`totalCount` 是过滤后总数，`hasNextPage` 按 `page * pageSize < totalCount` 计算。`minPrice` 是启用方案最低价，没有启用方案时为 null；`hasFreePlan` 按启用方案中的 `Free` 或 `price <= 0` 判断。缺少必填 Query、整数/枚举无法解析时，由框架返回绑定错误。

### 06 资源详情

`GET /api/v1/assets/{idOrSlug}`

| 参数 | 位置 | C# / 传输类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `idOrSlug` | Path | `string` | 是 | 资源 ID 或 slug |

- 认证：不需要；无请求体、无业务 Query。
- 成功：`200`，[`ApiAssetDetail`](./02-资源市场.md#apiassetdetail)。
- `404` 空体：未找到已发布资源。
- 方案仅返回启用项，按价格升序；当前版本可为 null。

## 数据模型

下表逐项列出请求和响应字段的 C# 类型、JSON 类型、可空性或必填要求，以及实际检查和默认处理。模型嵌套引用及共享模型可通过本页链接查看。

### MarketAssetListItem

只用于非版本化 `/api/market/assets`。

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 资源 ID |
| `type` | `string` | `string` | 否 | 枚举名称字符串，正常取值 Plugin/Skill/Agent/Solution |
| `name` | `string` | `string` | 否 | 名称 |
| `shortDescription` | `string` | `string` | 否 | 简介 |
| `iconUrl` | `string?` | `string / null` | 是 | 图标 URL |
| `coverUrl` | `string?` | `string / null` | 是 | 封面 URL |

### ApiAssetPageResponse

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `items` | `IReadOnlyList<ApiAssetListItem>` | `array<ApiAssetListItem>` | 否 | 当前页条目，空页为 [] |
| `page` | `int` | `number (int32)` | 否 | 修正后的页码 |
| `pageSize` | `int` | `number (int32)` | 否 | 修正后的每页数量 |
| `totalCount` | `int` | `number (int32)` | 否 | 过滤后资源总数 |
| `hasNextPage` | `bool` | `boolean` | 否 | 是否还有下一页 |

### ApiAssetListItem

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 资源 ID |
| `slug` | `string` | `string` | 否 | 资源标识 |
| `type` | `AssetType` | `number (int32 enum)` | 否 | 资源类型，1 至 4 |
| `name` | `string` | `string` | 否 | 资源名称 |
| `developerName` | `string` | `string` | 否 | 开发者名称 |
| `shortDescription` | `string` | `string` | 否 | 简介 |
| `iconUrl` | `string?` | `string / null` | 是 | 图标地址 |
| `coverUrl` | `string?` | `string / null` | 是 | 封面地址 |
| `categoryName` | `string?` | `string / null` | 是 | 分类名称 |
| `isFeatured` | `bool` | `boolean` | 否 | 是否推荐 |
| `downloadCount` | `int` | `number (int32)` | 否 | 下载次数 |
| `hasFreePlan` | `bool` | `boolean` | 否 | 是否有启用免费方案 |
| `minPrice` | `decimal?` | `number (decimal) / null` | 是 | 启用方案最低价格；本对象不提供币种字段 |
| `currentVersionId` | `string?` | `string / null` | 是 | 资源记录的 CurrentVersionId 原值 |
| `currentVersionName` | `string?` | `string / null` | 是 | 选定版本名，可回退至最新版本 |

### ApiAssetDetail

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 资源 ID |
| `slug` | `string` | `string` | 否 | 资源标识 |
| `type` | `AssetType` | `number (int32 enum)` | 否 | 资源类型 |
| `name` | `string` | `string` | 否 | 资源名称 |
| `developerName` | `string` | `string` | 否 | 开发者名称 |
| `shortDescription` | `string` | `string` | 否 | 简介 |
| `description` | `string` | `string` | 否 | 详细说明，API 不限定为某种富文本格式 |
| `tags` | `string` | `string` | 否 | 标签文本；不是 string[]，未约定分隔符 |
| `iconUrl` | `string?` | `string / null` | 是 | 图标地址 |
| `coverUrl` | `string?` | `string / null` | 是 | 封面地址 |

### ApiAssetVersion

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 版本 ID；这里字段名为 id，不是 versionId |
| `versionName` | `string` | `string` | 否 | 版本名称，未强制 SemVer |
| `releaseNotes` | `string` | `string` | 否 | 更新说明 |
| `packageHash` | `string` | `string` | 否 | 包 SHA256 文本；旧数据可能为空字符串 |
| `packageSize` | `long` | `number (int64)` | 否 | 包大小，字节 |
| `manifest` | `JsonElement?` | `JsonValue / null` | 是 | 动态 JSON，见 [manifest 类型与结构边界](./00-通用约定.md#25-manifest-的确定类型与结构边界) |

### ApiPricingPlan

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 方案 ID |
| `name` | `string` | `string` | 否 | 方案名称 |
| `planType` | `PricingPlanType` | `number (int32 enum)` | 否 | 1 免费，2 月度，3 年度 |
| `price` | `decimal` | `number (decimal)` | 否 | 方案金额 |
| `currency` | `string` | `string` | 否 | 币种文本，例如 CNY |
| `durationDays` | `int` | `number (int32)` | 否 | 期限天数；<= 0 时订阅服务按 20 年生成/延长到期时间 |
