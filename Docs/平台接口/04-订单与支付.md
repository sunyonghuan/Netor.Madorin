## 接口说明

### 23 创建订单或免费订阅

`POST /api/v1/orders`

- 认证：需要。
- 请求体：[`ApiCreateOrderRequest`](./04-订单与支付.md#apicreateorderrequest)，`assetId: string`、`pricingPlanId: string` 均必填且非空白，assetId 只接受 ID。
- 成功：`200`，[`ApiSubscribeResponse`](./03-订阅与授权.md#apisubscriberesponse)，免费/付费分支与 [订阅指定资源](./03-订阅与授权.md#22-订阅指定资源)一致。
- `400 ProblemDetails`：资源或方案空白。
- `401` 空体、`403 ProblemDetails`、`404` 空体：含义与 [订阅指定资源](./03-订阅与授权.md#22-订阅指定资源)一致。

付费分支重复调用会创建多个待支付订单，当前没有幂等键参数。

### 24 我的订单

`GET /api/v1/me/orders`

- 认证：需要；无其他参数、无请求体。
- 成功：`200`，根数组 [`ApiOrderListItem[]`](./04-订单与支付.md#apiorderlistitem)；仅当前账号订单，按记录时间倒序，无分页。
- `401` 空体：认证失败。

### 25 订单列表别名

`GET /api/v1/orders`

与 [我的订单](./04-订单与支付.md#24-我的订单)相同：需登录，无其他参数和请求体；`200` 返回 [`ApiOrderListItem[]`](./04-订单与支付.md#apiorderlistitem)，认证失败返回 `401` 空体。该接口仍然只查询当前账号订单，不是全平台订单列表。

### 26 订单详情

`GET /api/v1/orders/{orderId}`

| 参数 | 位置 | C# / 传输类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `orderId` | Path | `string` | 是 | 当前账号订单 ID |

- 认证：需要；无请求体、无业务 Query。
- 成功：`200`，[`ApiOrderDetail`](./04-订单与支付.md#apiorderdetail)。
- `401` 空体：认证失败。
- `404` 空体：订单不存在或不属于当前账号。

### 27 支付订单（当前为模拟支付）

`POST /api/v1/orders/{orderId}/pay`

| 参数 | 位置 | C# / 传输类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `orderId` | Path | `string` | 是 | 当前账号订单 ID |

- 认证：需要；无请求体、无业务 Query，没有支付渠道、回调地址或支付凭据参数。
- 成功：`200`，[`ApiPayOrderResponse`](./04-订单与支付.md#apipayorderresponse)。
- `401` 空体：认证失败。
- `403 ProblemDetails`：服务层发现账号不可用。
- `404` 空体：订单不存在/非本人，或未支付订单所需资源/方案关系已无效。

**当前流程直接将订单 `payStatus` 设为 2、`payMethod` 设为 9，新增模拟交易并开通或续期订阅，未对接真实收款。** 已支付订单再次调用直接按已支付返回，不再执行正常续期流程。`orderNo`、`amount` 在响应模型中允许 null；支付信息查询为空时响应仍可能令 `isPaid = true`。

## 数据模型

下表逐项列出请求和响应字段的 C# 类型、JSON 类型、可空性或必填要求，以及实际检查和默认处理。模型嵌套引用及共享模型可通过本页链接查看。

### ApiCreateOrderRequest

| JSON 字段 | C# 类型 | JSON 类型 | 必填 | 检查与处理 |
| --- | --- | --- | --- | --- |
| `assetId` | `string` | `string` | 是 | 显式拒绝 null/空白，必须为资源 ID |
| `pricingPlanId` | `string` | `string` | 是 | 显式拒绝 null/空白，必须为匹配资源的启用方案 ID |

### ApiOrderListItem

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 订单 ID |
| `no` | `string` | `string` | 否 | 订单编号，区别于账号的数字 no |
| `title` | `string` | `string` | 否 | 标题 |
| `assetId` | `string?` | `string / null` | 是 | 资源 ID |
| `pricingPlanId` | `string?` | `string / null` | 是 | 方案 ID |
| `amount` | `decimal` | `number (decimal)` | 否 | 订单金额；本响应没有 currency 字段 |
| `payStatus` | `byte` | `number (byte)` | 否 | 支付状态，当前写入 1/2 |
| `isPaid` | `bool` | `boolean` | 否 | payStatus == 2 |

### ApiOrderDetail

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 订单 ID |
| `no` | `string` | `string` | 否 | 订单编号 |
| `title` | `string` | `string` | 否 | 标题 |
| `content` | `string` | `string` | 否 | 订单说明文本 |
| `assetId` | `string?` | `string / null` | 是 | 资源 ID |
| `pricingPlanId` | `string?` | `string / null` | 是 | 方案 ID |
| `amount` | `decimal` | `number (decimal)` | 否 | 金额；本响应没有 currency 字段 |
| `numbers` | `int` | `number (int32)` | 否 | 数量，当前下单写入 1 |
| `payStatus` | `byte` | `number (byte)` | 否 | 支付状态 |
| `payMethod` | `byte` | `number (byte)` | 否 | 支付方式，当前创建为 0，模拟支付为 9 |
| `isPaid` | `bool` | `boolean` | 否 | payStatus == 2 |

### ApiPayOrderResponse

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `orderId` | `string` | `string` | 否 | 订单 ID |
| `orderNo` | `string?` | `string / null` | 是 | 支付信息查询结果中的订单编号 |
| `amount` | `decimal?` | `number (decimal) / null` | 是 | 支付信息查询结果中的金额 |
| `isPaid` | `bool` | `boolean` | 否 | 查询到的支付状态；支付信息为空时回退 true |

## 请求与响应示例

以下 ID、令牌、哈希和业务数据均为格式示例，不是实际可用凭据；日期是示例值。示例中的 manifest 内容仅展示 JSON 嵌入方式，不声明统一的清单内部字段。

创建付费订单：

```http
POST /api/v1/orders HTTP/1.1
Authorization: Bearer example-payload.example-signature
Content-Type: application/json

{
  "assetId": "asset-paid-example",
  "pricingPlanId": "plan-monthly-example"
}
```

```json
{
  "isFreeSubscription": false,
  "assetId": null,
  "orderId": "order-example",
  "status": "pending-order-created"
}
```

调用 `POST /api/v1/orders/order-example/pay`，只携带 Authorization，不发送 JSON Body。当前模拟支付的 `200` 响应示例：

```json
{
  "orderId": "order-example",
  "orderNo": "WEB202610190800000001234",
  "amount": 29.9,
  "isPaid": true
}
```
