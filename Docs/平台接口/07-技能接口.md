## 接口说明

### 28 技能清单

`GET /api/v1/skills/{assetId}/manifest`

| 参数 | 位置 | C# / 传输类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `assetId` | Path | `string` | 是 | 已发布 Skill 的资源 ID；不接受 slug |

- 认证：需要；无请求体、无业务 Query。
- 成功：`200`，[`ApiSkillManifest`](./07-技能接口.md#apiskillmanifest)。
- `401` 空体：认证失败。
- `403 ProblemDetails`：没有有效订阅且没有启用免费方案。
- `404` 空体：不是已发布 Skill、资源不存在或没有可选版本。

可自动创建免费订阅。响应根部的 `manifest` 与 `version.manifest` 来自同一版本 JSON，当前重复提供；字段类型均为 `JsonValue / null`。

### 29 技能下载

`GET /api/v1/skills/{assetId}/download`

- Path 参数：`assetId: string`，必填，仅接受已发布 Skill 的 ID，不接受 slug。
- 认证：需要；无请求体、无业务 Query。
- 成功：`200 application/zip`，ZIP 文件流。
- `401` 空体：认证失败；`404` 空体：资源不是已发布 Skill 或不存在。
- 通过类型检查后复用 [通用资源下载](./05-资源下载与记录.md#07-通用资源下载)下载逻辑，可能返回相同的 `403` 或 `409 ProblemDetails`，并具有相同的自动订阅、完整性检查与计数副作用。

## 数据模型

下表逐项列出请求和响应字段的 C# 类型、JSON 类型、可空性或必填要求，以及实际检查和默认处理。模型嵌套引用及共享模型可通过本页链接查看。

### ApiSkillManifest

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `assetId` | `string` | `string` | 否 | 技能资源 ID |
| `assetSlug` | `string` | `string` | 否 | 技能资源标识 |
| `assetName` | `string` | `string` | 否 | 技能资源名称 |
| `version` | [`ApiAssetVersion`](./02-资源市场.md#apiassetversion) | `object (ApiAssetVersion)` | 否 | 此处用 ApiAssetVersion，字段为 id，不是 versionId |
| `manifest` | `JsonElement?` | `JsonValue / null` | 是 | 与 version.manifest 为同一版本清单 |
