## 接口说明

### 01 健康检查

`GET /api/health`

- 认证：不需要。
- 参数：无；无请求体。
- 成功：`200`，[`ApiHealthResponse`](./01-健康检查与账号.md#apihealthresponse) 对象；`status = "ok"`，`application = "Netor.Cortana.Platform.Api"`。
- 说明：应用启动完成后的存活响应，端点本身不逐次探测数据库或包存储。

### 03 账号登录

`POST /api/v1/auth/login`

- 认证：不需要。
- 请求体：[`ApiLoginRequest`](./01-健康检查与账号.md#apiloginrequest)，必填 `userName: string`、`password: string`，字段约束见 [本页数据模型](#数据模型)。
- 成功：`200`，[`ApiLoginResponse`](./01-健康检查与账号.md#apiloginresponse)；包含令牌、到期时间和账号对象。
- `400 ProblemDetails`：账号或密码空白，`detail = "账号和密码不能为空。"`。
- `401` 空体：账号/密码不匹配。
- `403 ProblemDetails`：匹配账号已禁用或冻结。

`userName` 可为登录名、邮箱或手机号，服务端先 Trim；`password` 发送原始密码字符串，服务层执行散列比较，客户端不需要预先 MD5。

### 04 当前账号

`GET /api/v1/me`

- 认证：需要。
- 参数：无其他参数；无请求体。
- 成功：`200`，[`ApiAccountResponse`](./01-健康检查与账号.md#apiaccountresponse)。
- `401` 空体：认证失败。

## 数据模型

下表逐项列出请求和响应字段的 C# 类型、JSON 类型、可空性或必填要求，以及实际检查和默认处理。模型嵌套引用及共享模型可通过本页链接查看。

### ApiHealthResponse

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `status` | `string` | `string` | 否 | 固定 `ok` |
| `application` | `string` | `string` | 否 | 固定 `Netor.Cortana.Platform.Api` |

### ApiLoginRequest

| JSON 字段 | C# 类型 | JSON 类型 | 必填 | 检查与处理 |
| --- | --- | --- | --- | --- |
| `userName` | `string` | `string` | 是 | 显式拒绝 null/空白；登录名、邮箱或手机号；服务层 Trim |
| `password` | `string` | `string` | 是 | 显式拒绝 null/空白；不 Trim；提交原始密码字符串 |

### ApiLoginResponse

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `accessToken` | `string` | `string` | 否 | 认证令牌 |
| `expiresAtUtc` | `DateTimeOffset` | `string (date-time)` | 否 | 签发起 30 天后的 UTC 时间 |
| `account` | [`ApiAccountResponse`](./01-健康检查与账号.md#apiaccountresponse) | `object (ApiAccountResponse)` | 否 | 账号资料 |

### ApiAccountResponse

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 账号 ID |
| `no` | `long` | `number (int64)` | 否 | 账号编号；不是字符串 |
| `loginUserName` | `string` | `string` | 否 | 登录名 |
| `nickName` | `string` | `string` | 否 | 昵称，可能为空字符串 |
| `email` | `string` | `string` | 否 | 邮箱，可能为空字符串 |
| `phone` | `string` | `string` | 否 | 手机号，可能为空字符串 |

## 请求与响应示例

以下 ID、令牌、哈希和业务数据均为格式示例，不是实际可用凭据；日期是示例值。示例中的 manifest 内容仅展示 JSON 嵌入方式，不声明统一的清单内部字段。

```http
POST /api/v1/auth/login HTTP/1.1
Content-Type: application/json

{
  "userName": "demo-user",
  "password": "example-password"
}
```

`200` 响应：

```json
{
  "accessToken": "example-payload.example-signature",
  "expiresAtUtc": "2026-11-18T08:00:00+00:00",
  "account": {
    "id": "account-example",
    "no": 900000100001,
    "loginUserName": "demo-user",
    "nickName": "示例用户",
    "email": "demo@example.com",
    "phone": ""
  }
}
```
