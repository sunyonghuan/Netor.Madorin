## 接口说明

### 07 通用资源下载

`GET /api/v1/assets/{assetId}/download`

| 参数 | 位置 | C# / 传输类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `assetId` | Path | `string` | 是 | 参数名为 assetId，服务层实际同时接受资源 ID 或 slug |

- 认证：需要；无请求体、无业务 Query。
- 成功：`200 application/zip`，ZIP 文件流；下载文件名通过 `Content-Disposition` 提供。
- `401` 空体：认证失败。
- `403 ProblemDetails`：无有效订阅且没有启用的免费方案，或服务层发现账号不可用。
- `404` 空体：已发布资源不存在。
- `409 ProblemDetails`：没有可下载版本、文件不存在，或包完整性校验失败。

无有效订阅但有启用免费方案（`Free` 或 `price <= 0`）时，会自动建立订阅。文件分发前验证 SHA256；准备成功后记录下载记录并增加下载次数。该 GET 存在写入副作用；客户端下载被中断不等于服务端没有计数。接口未启用显式 Range 处理，不承诺断点续传。

### 08 POST 方式下载资源

`POST /api/v1/assets/{assetId}/downloads`

参数、认证、成功文件流和业务错误均与 [通用资源下载](./05-资源下载与记录.md#07-通用资源下载)一致。`assetId: string` 位于 Path，必填，同时接受 ID 或 slug。**无请求体**，成功响应不是下载地址或下载记录 JSON。

### 21 我的下载记录

`GET /api/v1/me/downloads`

- 认证：需要；无其他参数、无请求体。
- 成功：`200`，根数组 [`ApiDownloadRecord[]`](./05-资源下载与记录.md#apidownloadrecord)，按记录时间倒序，无分页。
- `401` 空体：认证失败。
- 资源不存在时名称回退为 `"未知资源"`，版本不存在时回退为 `"未知版本"`；`assetSlug`、`ipAddress` 可为 null。

## 数据模型

下表逐项列出请求和响应字段的 C# 类型、JSON 类型、可空性或必填要求，以及实际检查和默认处理。模型嵌套引用及共享模型可通过本页链接查看。

### ApiDownloadRecord

| JSON 字段 | C# 类型 | JSON 类型 | 可空 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `string` | `string` | 否 | 下载记录 ID |
| `assetId` | `string` | `string` | 否 | 资源 ID |
| `assetSlug` | `string?` | `string / null` | 是 | 资源标识 |
| `assetName` | `string` | `string` | 否 | 资源名称，缺失回退“未知资源” |
| `assetVersionId` | `string` | `string` | 否 | 下载版本 ID |
| `versionName` | `string` | `string` | 否 | 版本名，缺失回退“未知版本” |
| `ipAddress` | `string?` | `string / null` | 是 | 服务端连接的远端 IP，未配置代理头转换 |
| `timeStamp` | `long` | `number (int64)` | 否 | Unix 时间戳，单位秒；不是毫秒，依据见[当前契约边界与对接注意事项](./00-通用约定.md#4-当前契约边界与对接注意事项) |

## 请求与响应示例

以下 ID、令牌、哈希和业务数据均为格式示例，不是实际可用凭据；日期是示例值。示例中的 manifest 内容仅展示 JSON 嵌入方式，不声明统一的清单内部字段。

下载请求使用安装清单的 `downloadUrl`，仍携带 Token：

```http
GET /api/v1/assets/asset-example/download HTTP/1.1
Authorization: Bearer example-payload.example-signature
```

成功响应头包含 `Content-Type: application/zip`、`Content-Disposition: attachment; ...`，响应体直接保存为 ZIP。失败时按状态码和 Content-Type 读取错误，不能把 ProblemDetails 保存成资源包。
