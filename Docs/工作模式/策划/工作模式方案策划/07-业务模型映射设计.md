# 07 - 业务模型映射设计

> 把"老板-总经理-部门-员工"业务模型映射到 AF 框架

## 一、业务模型回顾

```
[老板] ──需求──→ [总经理] ──工作计划──→ [部门] ──子任务──→ [员工]
                    ↑                       │            │
                    │                       │ 自检       │
                    │ 汇总验收 ←─────────────┘            │
                    │                                    │
                    │ 不达标 → 退回重做                    │
                    │ 达标 → 报表                          │
                    ↓                                    │
                  [老板]                                  │
```

## 二、角色到框架的映射

### 2.1 角色对应表

| 业务角色 | 框架对应 | C# 类型 | 关键能力 |
|---------|---------|---------|---------|
| 老板 (User) | 外部输入 | `ChatMessage(Role=User)` | 通过 API/UI 提需求 |
| 总经理 | 主智能体 (Orchestrator) | `ChatClientAgent` + Magentic Manager | 计划/分派/汇总/重做 |
| 部门 | 子工作流 (Sub-Workflow) | `Workflow`（GroupChat/Sequential/WriterCritic） | 接任务/自检/上报 |
| 部门主管 | 部门内 Manager | `GroupChatManager` 实现 | 选择员工/终止判定 |
| 员工 | 原子智能体 / 工具 | `ChatClientAgent`（无下属） 或 `AIFunction` | 执行具体动作 |
| 工作计划 | Plan + Ledger | `MagenticPlan` + `TodoProvider` 状态 | 拆分 + 跟踪 |
| 任务 | Executor 调用 | `Executor.HandleAsync()` | 单次工作 |
| 上报 | AgentResponse | `AgentResponse` / `WorkflowEvent` | 任务结果 |
| 验收 | Critic Agent | `WriterCritic` Critic Executor | 质量判定 |
| 不达标退回 | Conditional Edge | `WorkflowBuilder.AddEdge(condition)` | 循环重做 |
| 报表 | Output Event | `WorkflowOutputEvent` | 最终交付 |

## 三、总经理智能体设计

### 3.1 职责清单（来自业务模型）

1. **与老板探讨需求** — 多轮对话，明确目标、约束、验收标准
2. **将需求转化为工作计划** — Plan 拆分
3. **安排部门** — 决策"用哪几个部门"
4. **收取部门结果** — 接收 `AgentResponse` / 子工作流输出
5. **汇总检验** — 评判是否符合标准
6. **不符合发回重做** — 触发 Replan / 部门重新执行
7. **报表汇报老板** — 最终输出

### 3.2 设计：基于 Magentic + 自定义增强

```csharp
public class GeneralManagerWorkflow
{
    public Workflow Build(IServiceProvider sp)
    {
        var managerAgent = sp.GetRequiredKeyedService<AIAgent>("Manager");

        // 部门智能体（每个部门本身是一个子工作流包装的智能体）
        var techDept = BuildTechDepartmentAsAgent(sp);
        var opsDept = BuildOpsDepartmentAsAgent(sp);
        var hrDept = BuildHrDepartmentAsAgent(sp);

        return new MagenticWorkflowBuilder(managerAgent)
            .AddParticipants([techDept, opsDept, hrDept])
            .WithMaxRounds(20)
            .WithMaxStalls(3)
            .Build();
    }
}
```

### 3.3 总经理的"指令模板"

```text
你是公司的总经理。老板会告诉你要完成的工作。

你的职责：
1. 如果需求不清楚，与老板对话直到明确：目标、约束、验收标准、交付时间。
2. 把需求拆分为一份《工作计划》，明确每个子任务交给哪个部门。
3. 调用部门完成任务（你只能通过工具 dispatch_to_<dept> 调用）。
4. 部门上报后，对照验收标准评估：
   - 达标 → 把结果整合进《报表》
   - 不达标 → 用 send_back_to_<dept> 让部门带反馈意见重做
5. 全部完成 → 用 final_report 工具汇报老板。
6. 如果发现整个计划走不通，用 replan 工具重新规划。

可用部门：{participants}
可用工具：dispatch_to_*, send_back_to_*, final_report, replan, ask_boss
```

### 3.4 关键工具签名

```csharp

{ /* 调用对应子工作流，返回部门初步反馈 */ }

{ /* 让部门重新跑一次 */ }

[Description("询问老板补充信息")]

{ /* 通过 RequestInfoEvent 触发 HITL */ }

[Description("提交最终报表给老板")]

{ /* 触发 WorkflowOutputEvent */ }
```

## 四、部门子工作流设计

### 4.1 部门通用模板

每个部门是一个**子工作流**，对外暴露为单个 `AIAgent`（通过 `Workflow.AsAIAgent()`）。

```
部门接口 (AIAgent)
   │
   └── 内部：Workflow
       ├── 部门主管 Agent      ← 接收任务、决策分工
       ├── 员工 Agents         ← 执行
       ├── Critic Agent        ← 自检
       └── 报告器 Agent        ← 整合输出
```

### 4.2 实现模式 A：GroupChat 部门（适合协作型）

```csharp
public class TechDepartment
{
    public AIAgent Build(IServiceProvider sp)
    {
        var supervisor = sp.GetRequiredKeyedService<AIAgent>("TechSupervisor");
        var coder = sp.GetRequiredKeyedService<AIAgent>("Coder");
        var reviewer = sp.GetRequiredKeyedService<AIAgent>("Reviewer");
        var tester = sp.GetRequiredKeyedService<AIAgent>("Tester");

        var workflow = AgentWorkflowBuilder
            .CreateGroupChatBuilderWith(agents =>
                new SupervisorGroupChatManager(supervisor, agents)
                {
                    MaximumIterationCount = 10
                })
            .AddParticipants(coder, reviewer, tester)
            .Build();

        return workflow.AsAIAgent(
            name: "技术部",
            description: "负责代码生成、审查、测试");
    }
}
```

### 4.3 实现模式 B：WriterCritic 部门（适合内容型）

```csharp
public class OpsDepartment
{
    public AIAgent Build(IServiceProvider sp)
    {
        var writer = sp.GetRequiredKeyedService<AIAgent>("ContentWriter");
        var critic = sp.GetRequiredKeyedService<AIAgent>("ContentCritic");

        var builder = new WorkflowBuilder();
        var writerExec = writer.AsExecutor();
        var criticExec = critic.AsExecutor();
        var outputExec = new OutputExecutor();

        builder.SetStartExecutor(writerExec);
        builder.AddEdge<ChatMessage>(writerExec, criticExec);

        // 达标 → 输出
        builder.AddEdge<ChatMessage>(criticExec, outputExec,
            msg => ParseVerdict(msg) == "PASS");

        // 不达标 → 回 Writer
        builder.AddEdge<ChatMessage>(criticExec, writerExec,
            msg => ParseVerdict(msg) == "FAIL");

        var workflow = builder.Build();
        return workflow.AsAIAgent("运营部", "负责文案生成与审核");
    }
}
```

### 4.4 实现模式 C：Sequential 部门（适合流水线型）

```csharp
public class QcDepartment  // 质检部门
{
    public AIAgent Build(IServiceProvider sp)
    {
        var workflow = AgentWorkflowBuilder.BuildSequential(
            sp.GetRequiredKeyedService<AIAgent>("Inspector"),
            sp.GetRequiredKeyedService<AIAgent>("Annotator"),
            sp.GetRequiredKeyedService<AIAgent>("Reporter"));
        return workflow.AsAIAgent("质检部", "流水线质检");
    }
}
```

### 4.5 实现模式 D：A2A 远端部门（跨进程）

```csharp
public class VisualDepartment
{

    {
```

## 六、Critic（验收员）设计

### 6.1 Critic 是质量门禁的核心

每个层级都可以有 Critic：
- 总经理级：验证最终报表
- 部门级：验证部门交付
- 员工级：自检

### 6.2 Critic Agent 模板

```csharp
var critic = chatClient.AsAIAgent(new ChatClientAgentOptions
{
    Name = "Critic",
    Description = "质量审核员",
    ChatOptions = new ChatOptions
    {
        Instructions = """
            你是质量审核员。你的输入是：
            1. 任务原始要求
            2. 执行结果

            你的输出必须以以下格式开头：
            VERDICT: PASS / FAIL

            如果 FAIL，列出具体不达标的点（每点附改进建议）。
            如果 PASS，简短说明亮点。

            评分标准：
            - 完整性：是否覆盖所有要求
            - 正确性：是否符合事实/规则
            - 质量：是否达到专业水准
            - 风险：是否引入未知风险
            """,
    }
});
```

### 6.3 验收判定函数

```csharp
internal static string ParseVerdict(ChatMessage msg)
{
    var text = msg.Text ?? "";
    if (text.StartsWith("VERDICT: PASS", StringComparison.OrdinalIgnoreCase))
        return "PASS";
    return "FAIL";
}
```

## 七、工作计划与 Ledger

### 7.1 Plan 数据模型

```csharp
public sealed record WorkPlan
{
    public string Id { get; init; } = Guid.NewGuid().ToString();
    public string Goal { get; init; }
    public IReadOnlyList<WorkPlanStep> Steps { get; init; }
    public IReadOnlyList<AcceptanceCriterion> AcceptanceCriteria { get; init; }
    public DateTimeOffset CreatedAt { get; init; }
    public int Version { get; init; }
}

public sealed record WorkPlanStep
{
    public string Id { get; init; }
    public string Description { get; init; }
    public string AssignedDepartment { get; init; }
    public IReadOnlyList<string> DependsOn { get; init; }
    public StepStatus Status { get; init; }
}

public enum StepStatus { Pending, InProgress, Done, Failed, Rejected }
```

### 7.2 Ledger（进度账本）

Magentic 框架内置 Ledger，**我们也可以加强**：

```csharp
public sealed class CortanaLedger
{
    public WorkPlan CurrentPlan { get; private set; }
    public Dictionary<string, StepProgress> Progress { get; }
    public List<RejectionRecord> Rejections { get; }  // 退回记录
    public int ReplanCount { get; private set; }
}

public sealed record StepProgress(
    string StepId,
    StepStatus Status,
    string? Result,
    DateTimeOffset UpdatedAt,
    string? Verdict,        // PASS/FAIL
    string? Feedback);
```

### 7.3 持久化
Plan 和 Ledger 存在 `AgentSessionStateBag` 中，**随会话持久化**（Durable Task 自动保存）。

### 8.1 询问老板（信息补全）

```csharp
[Description("询问老板补充信息（例如交付日期、预算等）")]
async Task<string> AskBoss(string question, CancellationToken ct)
{
    var ctx = AIAgent.CurrentRunContext!;
    var requestId = Guid.NewGuid().ToString();

    // 通过 RequestInfoEvent 通知前端
    await ctx.Workflow.RequestInfoAsync(new BossInquiry
    {
        RequestId = requestId,
        Question = question,
    });

    // 阻塞等待用户响应
    return await WaitForBossAnswerAsync(requestId, ct);
}
```

## 十、关键代码骨架

### 10.1 Cortana 启动代码（草案）

```csharp
public static class CortanaAgentSetup
{
    public static IServiceCollection AddCortanaAgents(this IServiceCollection services)
    {
        // 总经理
        services.AddAIAgent("Manager",
            instructions: ManagerPrompts.Default,
            chatClient: /* high-quality model */);

        // 部门主管 + 员工
        services.AddAIAgent("TechSupervisor", ..., ...);
        services.AddAIAgent("Coder", ..., ...);
        services.AddAIAgent("Reviewer", ..., ...);
        services.AddAIAgent("Tester", ..., ...);

        // Critic
        services.AddAIAgent("Critic", CriticPrompts.Default, ...);

        // 部门工作流
        services.AddSingleton<TechDepartmentFactory>();
        services.AddSingleton<OpsDepartmentFactory>();

        // 检查点
        services.AddSingleton<ICheckpointManager>(sp =>
            new FileSystemCheckpointManager("./checkpoints"));

        return services;
    }

    public static async Task<StreamingRun> StartTaskAsync(
        IServiceProvider sp, string userId, string request)
    {
        var workflow = sp.GetRequiredService<GeneralManagerWorkflow>().Build(sp);
        var checkpoint = sp.GetRequiredService<ICheckpointManager>();

        return await InProcessExecution.RunStreamingAsync(
            workflow,
            new ChatMessage(ChatRole.User, request),
            new RunOptions
            {
                CheckpointManager = checkpoint,
                RunId = $"{userId}-{Guid.NewGuid():N}"
            });
    }
}
```

## 十二、本章总结

1. **总经理** = `ChatClientAgent` + `MagenticWorkflowBuilder`
2. **部门** = 子 `Workflow`（GroupChat / WriterCritic / Sequential / A2A 任选）通过 `AsAIAgent()` 暴露
3. **员工** = `ChatClientAgent`（无下属）或 `AIFunction`
4. **Critic** = 验收员智能体 + `ConditionalEdge`
5. **Plan/Ledger** = 自定义结构 + `AgentSessionStateBag` 持久化
6. **HITL** = `RequestInfoEvent` + Checkpoint 暂停-恢复
7. **跨进程** = A2A
8. **长任务** = DurableTask（生产）/ Checkpoint（自托管）
9. **沙盒** = `ApprovalRequiredAIFunction` + `Hyperlight` + `Tools.Shell` + `FileAccessProvider`
