## 二、端到端示例：完整的"销售月报"任务

### 2.1 用户旅程

```text
[1] 用户在工作模式 Tab 输入：帮我做一份销售月报
[2] 系统识别为新任务，创建 WorkTask，启动总经理 Agent
[3] 总经理：数据来源是 ERP 还是 CRM？
[4] 用户：ERP，按月，给老板看，PDF
[5] 总经理：[整理需求摘要] 这样可以吗？
[6] 用户：可以
[7] 总经理：[展示完整计划 Markdown]
[8] 用户：把第三步改成省份对比
[9] 总经理：[展示修改后的完整计划]

[11] 系统：时间线显示主步骤"拉取 ERP 销售数据" 运行中
       → 工具卡片"调用 erp_connect"
       → 工具卡片"调用 erp_query"
       → 验收 PASS → 主步骤折叠
[12] 系统：主步骤"生成图表" 运行中
```

#### B. 输入路由

```csharp
// WorkModeInputRouter.cs (节选)
public async Task RouteAsync(string userInput, CancellationToken ct)
{
    if (string.IsNullOrWhiteSpace(userInput)) return;

    var sessionId = await _sessionResolver.GetCurrentSessionIdAsync(ct);
    var activeTask = await _taskService.GetActiveTaskAsync(sessionId, ct);

    if (activeTask is not null)
    {
        await _chatHistory.AppendUserMessageAsync(activeTask.SessionId, userInput, ct);

        if (!string.IsNullOrEmpty(activeTask.PendingRequestId))
        {
            // HITL 等待中
            await _executor.ResumeAsync(activeTask.Id, userInput, ct);
        }
        else
        {
            // 任务还活着，但 Workflow 当前轮已结束，需要继续对话
            await _executor.ContinueAsync(activeTask.Id, userInput, ct);
        }
        return;
    }

    var intent = await _intentClassifier.ClassifyAsync(userInput, ct);
    if (intent == UserIntent.NewTask)
    {
        await CreateAndExecuteNewTaskAsync(sessionId, userInput, ct);
    }
    else
    {
        await _chatEngine.SendMessageAsync(userInput, ct);
    }
}
```

> **重要修正**：上一版 13 文档只有 `ExecuteAsync` / `ResumeAsync` / `EnqueueUserInputAsync`，遗漏了"任务活着但 Workflow 当前轮结束（如 AI 输出完追问后等待）"这种场景。这种情况需要 `ContinueAsync`：用现有 RunId 继续会话（把新用户输入注入到主 Agent 的 ChatHistoryProvider，再次调用 RunStreamingAsync）。

实际实现可以基于 AF 的 `AgentSession` 复用：

```csharp
public async Task ContinueAsync(string taskId, string userInput, CancellationToken ct)
{
    // 重新构建 Workflow 和 Manager（提示词、Mentions 仍生效）
    var task = await _taskService.GetByIdAsync(taskId, ct)!;
    var manager = await _agentBuilder.BuildAsync(taskId, task.Provider, task.Model, task.Agent, task.Mentions, ct);
    var workflow = AgentWorkflowBuilder.BuildSequential(manager);

    // 用 RunId Resume（拿到原会话上下文）
    var run = await InProcessExecution.ResumeAsync(
        workflow, task.RunId,
        new RunOptions { CheckpointManager = new CheckpointManager(_checkpointStore) },
        cancellationToken: ct);

    // 注入新的用户消息
    // 实际 API 取决于 AF v1.6 的接口，可能用 run.SendInputAsync 或重启一轮 RunStreamingAsync
    // 这里先按概念写，实施时验证
    await run.SendInputAsync(new ChatMessage(ChatRole.User, userInput), ct);

    await ConsumeEventsAsync(taskId, run, ct);
}
```

> **实施验证项**：阶段 1 开始前必须确认 AF v1.6 是否支持"已结束的 Run 重新接受输入"。
>
> - 如果支持 → 用上面的 `ContinueAsync`
> - 如果不支持 → 每次用户输入都建一个**新** Run，但通过 `ChatHistoryProvider` 共享同一个 SessionId 的对话历史（这正是 Cortana `ChatHistoryDataProvider` 的现有职责）
>
> 推测**第二种方式**更符合 AF 的设计——每次 RunStreamingAsync 都是一次"完整轮"，对话连续性通过 ChatHistoryProvider 保证。这样 `RunId` 字段实际只用于：HITL Resume + 应用重启恢复。普通"继续对话"不需要 RunId。

```csharp
public sealed class GeneralManagerAgentBuilder
{
    public async Task<AIAgent> BuildAsync(
        string taskId,
        AiProviderEntity provider,
        AiModelEntity model,
        AgentEntity baseAgent,
        IReadOnlyList<AgentMention> mentions,
        CancellationToken ct = default)
    {
        var instructions = await _promptProvider.GetPromptAsync("work_mode.general_manager", ct);

        // 把 SourceTaskId 等动态信息渲染进提示词（简单字符串替换，不用模板引擎以保 AOT）
        instructions = instructions.Replace("{tools_summary}", _toolset.GetToolsSummary());
        instructions = instructions.Replace("{session_context}", await BuildSessionContextAsync(taskId, ct));

        var transientAgent = new AgentEntity
        {
            // 复用 baseAgent 的所有配置，仅覆盖 Instructions
            Id = baseAgent.Id,
            Name = "总经理",
            Description = "工作模式主智能体",
            Instructions = instructions,
            Temperature = baseAgent.Temperature,
            TopP = baseAgent.TopP,
            MaxTokens = baseAgent.MaxTokens,
            FrequencyPenalty = baseAgent.FrequencyPenalty,
            PresencePenalty = baseAgent.PresencePenalty,
            MaxHistoryMessages = baseAgent.MaxHistoryMessages,
            EnabledPluginIds = baseAgent.EnabledPluginIds,
            EnabledMcpServerIds = baseAgent.EnabledMcpServerIds,
        };

        var workModeTools = _toolset.BuildTools(taskId);

        if (mentions.Count > 0)
        {
            return _agentFactory.BuildWithSubAgents(
                transientAgent, provider, model,
                [.. mentions],
                _providerService, _modelService,
                additionalTools: workModeTools);
        }
        return _agentFactory.Build(transientAgent, provider, model,
            additionalTools: workModeTools);
    }
}
```

```csharp
public sealed class WorkModeToolset
```

#### E. UI Controller

```csharp
public sealed class WorkModeViewController
{
    private WorkModeView? _view;
    private string? _currentTaskId;
    private TimelineBlock? _currentTimeline;
    private TimelineStepHandle? _currentStep;
    private SubStepCard? _currentSubStep;
    private AiContent? _currentAi;

    private string? _pendingApprovalRequestId;

    private readonly ISubscriber _subscriber;
    private readonly IWorkflowExecutor _executor;
    private readonly Dictionary<string, FoldableCard> _toolCardsByCallId = new();

    private readonly List<IDisposable> _subscriptions = new();

    public void AttachToView(WorkModeView view) => _view = view;

    public void Subscribe()
    {
        _subscriptions.Add(_subscriber.Subscribe<WorkAssistantDeltaArgs>(
            Events.OnWorkAssistantDelta, OnAssistantDelta));
        _subscriptions.Add(_subscriber.Subscribe<WorkPlanUpdatedArgs>(
            Events.OnWorkPlanUpdated, OnPlanUpdated));
        _subscriptions.Add(_subscriber.Subscribe<WorkToolCalledArgs>(
            Events.OnWorkToolCalled, OnToolCalled));
        _subscriptions.Add(_subscriber.Subscribe<WorkToolCompletedArgs>(
            Events.OnWorkToolCompleted, OnToolCompleted));
        _subscriptions.Add(_subscriber.Subscribe<WorkApprovalRequestedArgs>(
            Events.OnWorkApprovalRequested, OnApprovalRequested));
        _subscriptions.Add(_subscriber.Subscribe<WorkTaskCreatedArgs>(
            Events.OnWorkTaskCreated, OnTaskCreated));
        _subscriptions.Add(_subscriber.Subscribe<WorkTaskCompletedArgs>(
            Events.OnWorkTaskCompleted, OnTaskCompleted));

        if (_view is not null)
        {
            _view.ApprovalPopup.DecisionMade += OnApprovalDecision;
            _view.ApprovalPopup.AlternativeSubmitted += OnApprovalAlternative;
        }
    }

    public void Unsubscribe()
    {
        foreach (var s in _subscriptions) s.Dispose();
        _subscriptions.Clear();

        if (_view is not null)
        {
            _view.ApprovalPopup.DecisionMade -= OnApprovalDecision;
            _view.ApprovalPopup.AlternativeSubmitted -= OnApprovalAlternative;
        }
    }

    // ──────── 事件处理（一律 Dispatcher.UIThread.Post 切线程）────────

    private Task<bool> OnTaskCreated(string _, WorkTaskCreatedArgs args)
    {
        _currentTaskId = args.TaskId;
        return Task.FromResult(false);
    }

    private Task<bool> OnAssistantDelta(string _, WorkAssistantDeltaArgs args)
    {
        if (args.TaskId != _currentTaskId || _view is null) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            // 流式累积到当前 AiContent，没有则新建
            _currentAi ??= AppendNewAiContent();
            _currentAi.Markdown = (_currentAi.Markdown ?? "") + args.Delta;
            _view.ScrollToBottom();
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnPlanUpdated(string _, WorkPlanUpdatedArgs args)
    {
        if (args.TaskId != _currentTaskId || _view is null) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            // 计划更新 = 在消息流追加一条专门的 AI 消息（覆盖式，旧计划留在历史）
            var planContent = AppendNewAiContent();
            planContent.Markdown = FormatPlanAsMarkdown(args.Plan);
            _view.ScrollToBottom();

            _currentAi = null; // 切断流式，下一段 AI 输出会建新的 AiContent
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnToolCalled(string _, WorkToolCalledArgs args)
    {
        if (args.TaskId != _currentTaskId || _view is null) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            switch (args.ToolName)
            {
                case "dispatch_step":
                    EnsureTimeline();
                    var stepTitle = ExtractStepTitleFromParams(args.ParamText) ?? "执行步骤";
                    if (_currentStep is not null) _currentStep.SetExpanded(false);
                    _currentStep = _currentTimeline!.AddMainStep(stepTitle, "运行中", expanded: true);
                    _currentSubStep = null;
                    _currentAi = null;
                    break;

                case "verify_step":
                    var card = new FoldableCard
                    {
                        CardTitle = "验收",
                        StatusText = "运行中",
                        IsExpanded = true,
                        CardContent = TextBlockOf(args.ParamText, monospace: false),
                    };
                    AppendDetailToCurrentStep(card);
                    _toolCardsByCallId[args.CallId] = card;
                    break;

                case "set_plan":
                case "get_plan":
                case "check_pending_user_input":
                case "load_plan_from_template":
                case "load_plan_from_chat_history":
                case "ask_user":
                case "final_report":
                    // 这些工具不直接对应 UI 卡片（由专门事件处理）
                    break;

                default:
                    // 普通工具（含子智能体内部工具）→ 当前主步骤的明细
                    var toolCard = new FoldableCard
                    {
                        CardTitle = $"调用工具 {args.ToolName}",
                        StatusText = "运行中",
                        IsExpanded = false,
                        CardContent = TextBlockOf(args.ParamText, monospace: true),
                        Tag = args.CallId,
                    };
                    AppendDetailToCurrentStep(toolCard);
                    _toolCardsByCallId[args.CallId] = toolCard;
                    break;
            }
            _view.ScrollToBottom();
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnToolCompleted(string _, WorkToolCompletedArgs args)
    {
        if (args.TaskId != _currentTaskId || _view is null) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            if (_toolCardsByCallId.TryGetValue(args.CallId, out var card))
            {
                card.StatusText = args.Status == "success" ? "完成" : "失败";
                if (card.CardContent is SelectableTextBlock tb)
                {
                    tb.Text = $"{tb.Text}\n→ {args.Result}";
                }
                _toolCardsByCallId.Remove(args.CallId);
            }
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnApprovalRequested(string _, WorkApprovalRequestedArgs args)
    {
        if (args.TaskId != _currentTaskId || _view is null) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            _pendingApprovalRequestId = args.RequestId;
            _view.ApprovalPopup.Show(args.ToolName, args.ParamText, args.Risk);
        });
        return Task.FromResult(false);
    }

    private Task<bool> OnTaskCompleted(string _, WorkTaskCompletedArgs args)
    {
        if (args.TaskId != _currentTaskId || _view is null) return Task.FromResult(false);

        Dispatcher.UIThread.Post(() =>
        {
            if (_currentStep is not null)
            {
                _currentStep.SetStatus("已完成");
                _currentStep.SetExpanded(false);
            }

            var summary = new SummaryCard { SummaryMarkdown = args.Summary };
            _view.MessageList.Items.Add(summary);

            // 重置当前任务上下文，回到空闲
            _currentTaskId = null;
            _currentTimeline = null;
            _currentStep = null;
            _currentSubStep = null;
            _currentAi = null;
            _toolCardsByCallId.Clear();

            _view.ScrollToBottom();
        });
        return Task.FromResult(false);
    }

    // ──────── 授权浮窗回调 ────────

    private void OnApprovalDecision(object? sender, ApprovalDecision decision)
    {
        if (string.IsNullOrEmpty(_pendingApprovalRequestId)) return;
        if (decision == ApprovalDecision.Alternative) return; // 由 OnApprovalAlternative 处理

        var responseText = decision switch
        {
            ApprovalDecision.ApproveOnce    => "approve_once",
            ApprovalDecision.ApproveSession => "approve_session",
            ApprovalDecision.ApproveAlways  => "approve_always",
            ApprovalDecision.Reject         => "reject",
            _ => "reject",
        };

        var taskId = _currentTaskId;
        _pendingApprovalRequestId = null;

        if (!string.IsNullOrEmpty(taskId))
        {
            _ = _executor.ResumeAsync(taskId, responseText, CancellationToken.None);
        }
    }

    private void OnApprovalAlternative(object? sender, string alternativeText)
    {
        var taskId = _currentTaskId;
        _pendingApprovalRequestId = null;

        if (!string.IsNullOrEmpty(taskId))
        {
            _ = _executor.ResumeAsync(taskId, $"alternative:{alternativeText}", CancellationToken.None);
        }
    }

    // ──────── 辅助 ────────

    private AiContent AppendNewAiContent()
    {
        var ai = new AiContent();
        _view!.MessageList.Items.Add(ai);
        return ai;
    }

    private void EnsureTimeline()
    {
        if (_currentTimeline is not null) return;
        _currentTimeline = new TimelineBlock();
        _view!.MessageList.Items.Add(_currentTimeline);
    }

    private void AppendDetailToCurrentStep(FoldableCard card)
    {
        if (_currentStep is null) return;

        if (_currentSubStep is null)
        {
            _currentSubStep = new SubStepCard
            {
                CardTitle = "执行",
                StatusText = "运行中",
                IsExpanded = true,
            };
            _currentStep.AppendSubStep(_currentSubStep);
        }
        _currentSubStep.AppendDetail(card);
    }

    private static Control TextBlockOf(string text, bool monospace)
    {
        var tb = new SelectableTextBlock
        {
            Text = text,
            FontSize = 12,
            Foreground = Brushes.LightGray,
            TextWrapping = TextWrapping.Wrap,
            Padding = new Thickness(0, 2, 0, 2),
        };
        if (monospace) tb.FontFamily = new FontFamily("Consolas, 'Cascadia Code', monospace");
        return tb;
    }

    private static string? ExtractStepTitleFromParams(string paramText)
    {
        // dispatch_step 的参数 JSON 中提取 stepTitle 字段
        try
        {
            using var doc = JsonDocument.Parse(paramText);
            return doc.RootElement.TryGetProperty("stepTitle", out var t) ? t.GetString() : null;
        }
        catch { return null; }
    }

    private static string FormatPlanAsMarkdown(WorkPlan plan)
    {
        var sb = new StringBuilder();
        sb.AppendLine("**工作计划**");
        sb.AppendLine();
        for (int i = 0; i < plan.MainSteps.Count; i++)
        {
            var s = plan.MainSteps[i];
            sb.AppendLine($"{i + 1}. **{s.Title}**");
            for (int j = 0; j < s.SubSteps.Count; j++)
            {
                sb.AppendLine($"   - {i + 1}.{j + 1} {s.SubSteps[j].Title}");
            }
        }
        return sb.ToString();
    }
}
```

## 三、AOT 安全速查

| 场景 | 错误写法 | 正确写法 |
|------|---------|---------|
| 序列化 | `JsonSerializer.Serialize(obj)` | `JsonSerializer.Serialize(obj, WorkModeJsonContext.Default.MyType)` |
| 反序列化 | `JsonSerializer.Deserialize<T>(json)` | `JsonSerializer.Deserialize(json, WorkModeJsonContext.Default.MyType)` |
| 工具方法 | `AIFunctionFactory.Create(method, options)` 但 method 包含 `object` 参数 | 用强类型签名（`string` / 注册过的 record） |
| UI 数据 | `<TextBlock Text="{Binding Title}" />` | `code-behind`：`titleBlock.Text = title;` |
| UI 列表 | `<ItemsControl ItemsSource="{Binding Items}">` 加 `DataTemplate` | `MessageList.Items.Add(controlInstance)` |
| 字典存储 | `Dictionary<string, object>` 序列化 | 改用具名 record |
