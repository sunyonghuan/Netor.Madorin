# 02 - 核心架构

> 描述 AF 框架的核心抽象、智能体生命周期、会话与上下文管理

## 一、智能体基础抽象 `AIAgent`

### 1.1 类层次

```
AIAgent（abstract）
├── ChatClientAgent（sealed）       — 包装 IChatClient（M.Extensions.AI）
├── A2AAgent（sealed）              — 远程智能体客户端
├── CopilotStudioAgent              — Copilot Studio 集成
├── DurableAIAgent（sealed）        — Azure Durable Task 长任务智能体
└── DelegatingAIAgent（abstract）   — 装饰器基类
    ├── LoggingAgent                 — 日志中间件
    ├── OpenTelemetryAgent           — 遥测中间件
    ├── FunctionInvocationDelegatingAgent — 函数调用拦截
    ├── ToolApprovalAgent            — 工具授权拦截
    └── AnonymousDelegatingAIAgent   — 用户自定义中间件
```

### 1.2 关键 API

```csharp
public abstract class AIAgent
{
    // 标识
    public string Id { get; }
    public string? Name { get; }
    public string? Description { get; }

    // AsyncLocal 上下文（跨 await 流转）
    public static AgentRunContext? CurrentRunContext { get; }

    // 创建会话
    public virtual ValueTask<AgentSession> CreateSessionAsync(
        CancellationToken cancellationToken = default);

    // 执行（非流式）
    public Task<AgentResponse> RunAsync(
        IEnumerable<ChatMessage> messages,
        AgentSession? session = null,
        AgentRunOptions? options = null,
        CancellationToken cancellationToken = default);

    // 执行（流式）
    public IAsyncEnumerable<AgentResponseUpdate> RunStreamingAsync(
        IEnumerable<ChatMessage> messages,
        AgentSession? session = null,
        AgentRunOptions? options = null,
        CancellationToken cancellationToken = default);

    // 持久化
    public ValueTask<JsonElement> SerializeSessionAsync(AgentSession session, ...);
    public ValueTask<AgentSession> DeserializeSessionAsync(JsonElement state, ...);

    // 服务定位（让外层取得内部组件，例如 ChatHistoryProvider）
    public virtual object? GetService(Type serviceType, object? serviceKey = null);
    public TService? GetService<TService>(object? serviceKey = null);
}
```

### 1.3 设计要点

1. **`RunAsync` 是终态方法（不可 override）** — 子类要重写的是内部的 `RunCoreAsync`，框架统一处理 Session 创建、Context 流转、消息追加等。
2. **Session 可空** — 不传 Session 等于"无记忆"调用；传了 Session 会读取/写入历史。
3. **Options 一次性参数** — 每次 Run 都可以传不同的 `AgentRunOptions`（含 `ChatOptions`、Tools、ToolMode 等）。
4. **`GetService<T>` 服务定位** — 装饰器链上每一层都会向内 forward，最终能拿到底层组件（例如外层取得 `IChatClient`）。

## 二、会话 `AgentSession`

### 2.1 职责

会话保持一次"对话"的状态。AF 把状态拆成两类：
- **对话历史**（由 `ChatHistoryProvider` 管理）
- **任意状态**（由 `AgentSessionStateBag` 管理，键值对）

### 2.2 API

```csharp
public abstract class AgentSession
{
    // 任意状态（线程安全）
    public AgentSessionStateBag StateBag { get; protected set; }

    // 服务定位（同 AIAgent）
    public virtual object? GetService(Type serviceType, object? serviceKey = null);
    public TService? GetService<TService>(object? serviceKey = null);
}

public class AgentSessionStateBag
{
    public int Count { get; }
    public bool TryGetValue<T>(string key, out T? value, JsonSerializerOptions? jso = null);
    public T? GetValue<T>(string key, JsonSerializerOptions? jso = null);
    public void SetValue<T>(string key, T? value, JsonSerializerOptions? jso = null);
    public bool TryRemoveValue(string key);

    // 持久化
    public JsonElement Serialize();
    public static AgentSessionStateBag Deserialize(JsonElement jsonElement);
}
```

### 2.3 `ChatClientAgentSession`（默认实现）

```csharp
public sealed class ChatClientAgentSession : AgentSession
{
    // 服务端管理的会话ID（用于 OpenAI Assistants API 等"服务端记忆"模型）
    public string? ConversationId { get; set; }

    // 本地序列化
    public JsonElement Serialize();
    public static ChatClientAgentSession Deserialize(JsonElement element);
}
```

### 2.4 持久化策略

| 策略 | 实现 | 适用 |
|------|------|------|
| 本地内存（默认） | `InMemoryChatHistoryProvider` | 单进程、短任务 |
| 服务端管理 | `ConversationId` + OpenAI Threads/Assistants | OpenAI/AzureOpenAI Assistants |
| 数据库 | 自定义 `ChatHistoryProvider` + `CosmosNoSql` | 生产环境 |
| Durable | `DurableAgentSession`（自动持久到 Entity） | 长任务 |

## 三、运行上下文 `AgentRunContext`

### 3.1 用途

在一次 `RunAsync` 调用期间，把"当前正在执行的智能体""当前会话""请求消息""选项"等信息暴露给：
- 中间件（`DelegatingAIAgent`）
- 工具函数（`AIFunction` 调用时可访问）
- `AIContextProvider`

### 3.2 设计

```csharp
public sealed class AgentRunContext
{
    public AIAgent Agent { get; }
    public AgentSession? Session { get; }
    public IReadOnlyList<ChatMessage> RequestMessages { get; }
    public AgentRunOptions? RunOptions { get; }
}

// 通过 AsyncLocal 流转
public static AgentRunContext? AIAgent.CurrentRunContext { get; }
```

### 3.3 典型用法

```csharp
// 在自定义工具内访问当前会话
[Description("获取当前用户ID")]
static string GetCurrentUserId()
{
    var session = AIAgent.CurrentRunContext?.Session;
    return session?.StateBag.GetValue<string>("userId") ?? "anonymous";
}
```

### 3.4 关键源码
- `src\Microsoft.Agents.AI.Abstractions\AgentRunContext.cs`

## 四、对话历史 `ChatHistoryProvider`

### 4.1 设计

每次 Run 都会经过：
```
RunAsync
  ├── InvokingAsync()    ← 提供历史（合并到请求消息）
  ├── 调用 IChatClient
  └── InvokedAsync()     ← 存储响应
```

### 4.2 API

```csharp
public abstract class ChatHistoryProvider
{
    // 入站 ─ 提供历史
    public ValueTask InvokingAsync(InvokingContext context, CancellationToken ct);
    protected virtual ValueTask ProvideChatHistoryAsync(InvokingContext context, CancellationToken ct);

    // 出站 ─ 存储新消息
    public ValueTask InvokedAsync(InvokedContext context, CancellationToken ct);
    protected virtual ValueTask StoreChatHistoryAsync(InvokedContext context, CancellationToken ct);
}
```

### 4.3 内置实现

- `InMemoryChatHistoryProvider` — 默认；存在 `AgentSessionStateBag` 中
- 自定义实现示例：截断（保留最近 N 条）、压缩（用小模型总结）、归档（写 DB）

### 4.4 关键源码
- `src\Microsoft.Agents.AI.Abstractions\ChatHistoryProvider.cs`
- `src\Microsoft.Agents.AI.Abstractions\InMemoryChatHistoryProvider.cs`

## 五、AI 上下文提供者 `AIContextProvider`

### 5.1 用途
比 `ChatHistoryProvider` 更高层，可以在每次调用前注入：
- 额外的系统指令
- 额外的消息（如检索结果）
- 额外的工具

并在调用后从响应中"学习"（更新自己的状态）。

### 5.2 API

```csharp
public abstract class AIContextProvider
{
    // 暴露使用的状态键，便于序列化
    public virtual IReadOnlyList<string> StateKeys => [this.GetType().Name];

    // 入站：注入上下文
    public ValueTask<AIContext> InvokingAsync(InvokingContext context, CancellationToken ct);
    protected virtual ValueTask<AIContext> ProvideAIContextAsync(InvokingContext context, CancellationToken ct);

    // 出站：从响应中学习
    public ValueTask InvokedAsync(InvokedContext context, CancellationToken ct);
    protected virtual ValueTask StoreAIContextAsync(InvokedContext context, CancellationToken ct);
}

public sealed class AIContext
{
    public string? Instructions { get; init; }     // 额外系统提示
    public IList<ChatMessage>? Messages { get; init; } // 额外消息
    public IList<AITool>? Tools { get; init; }      // 额外工具
}
```

### 5.3 内置 Provider（位于 `Microsoft.Agents.AI\Harness\`）

| Provider | 用途 |
|----------|------|
| `BackgroundAgentsProvider` | 启动后台子智能体并把任务 ID/结果暴露给主智能体（**长任务关键**） |
| `AgentModeProvider` | 切换智能体行为模式（如 Plan 模式 / Execute 模式） |
| `FileAccessProvider` | 文件系统访问门禁 |
| `FileMemoryProvider` | 文件型记忆 |
| `TodoProvider` | 任务清单管理（**Plan 拆分关键**） |

## 六、智能体构建器 `AIAgentBuilder`

### 6.1 用途
把"原始智能体"包装成"中间件管道"，类似 ASP.NET Core 的 `IApplicationBuilder`。

### 6.2 API

```csharp
public sealed class AIAgentBuilder
{
    public AIAgentBuilder(AIAgent innerAgent);
    public AIAgentBuilder(Func<IServiceProvider, AIAgent> factory);

    // 添加装饰器（中间件）
    public AIAgentBuilder Use(Func<AIAgent, AIAgent> agentFactory);
    public AIAgentBuilder Use(Func<AIAgent, IServiceProvider, AIAgent> agentFactory);

    // 添加自定义 Run 逻辑（更细粒度）
    public AIAgentBuilder Use(
        Func<...> runFunc,
        Func<...> runStreamingFunc);

    public AIAgent Build(IServiceProvider? services = null);
}
```

### 6.3 应用顺序
**先 Add 的在外层**（最先看到调用）。

```csharp
var agent = new AIAgentBuilder(coreAgent)
    .Use(inner => new LoggingAgent(inner))          // 最外层
    .Use(inner => new OpenTelemetryAgent(inner))    // 中层
    .Use(inner => new ToolApprovalAgent(inner))     // 内层
    .Build(serviceProvider);

// 调用顺序：Logging -> OpenTelemetry -> ToolApproval -> coreAgent
```

## 十、安全注意事项（框架文档明确指出）

| 风险 | 框架立场 | 我们需要做 |
|------|---------|----------|
| Prompt Injection（用户消息） | 框架**不做过滤** | 业务层做内容审查 |
| 不可信 LLM 响应 | 框架不验证 | 工具调用前过 `ToolApprovalAgent` |
| 系统消息篡改 | 必须由开发者控制 | 系统提示模板化，禁止用户消息拼接 |
| 序列化会话含敏感数据 | 框架不加密 | 存储层加密 + 访问控制 |
| 反序列化不可信会话 | 风险自负 | 不要从客户端反序列化会话 |
