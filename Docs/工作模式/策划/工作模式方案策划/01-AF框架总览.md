## 二、能力矩阵（针对我们的需求）

| 需求 | AF 能力 | 包 | 成熟度 |
|------|--------|----|-------|
| 主智能体创建子智能体 | `Magentic` 模式 + DI 容器动态解析 | `Workflows` + `Hosting` | 高 |
| 长任务（无状态/超时安全） | `DurableAIAgent` + Checkpoint + Event 流 | `DurableTask` + `Workflows` | 高（生产可用） |
| 任务验证 + 重做循环 | `WriterCritic` 模式 / `Magentic` 自动重规划 / `IAgentEvaluator` | `Workflows` + Evaluation | 中-高 |
| 详细执行过程 | `MagenticPlan`（Ledger）+ ConditionalEdge | `Workflows.Specialized.Magentic` | 中 |
| 工具授权 | `ApprovalRequiredAIFunction` + `ToolApprovalAgent` | `Microsoft.Agents.AI` (Harness) | 高 |
| 沙盒执行 | `Hyperlight`（虚拟化级别）+ `Tools.Shell`（命令隔离） | 独立包 | 中（Hyperlight 较新） |
| 跨进程协作 | A2A 协议 | `A2A` 系列 | 高 |
| 流式响应 | `IRunEventStream` + `Channels` | `Workflows` | 高 |
| 状态持久化 | `AgentSessionStateBag` + `ICheckpointManager` | `Abstractions` + `Workflows` | 高 |

## 三、技术选型建议（针对 Cortana）

### 3.1 必选包

```xml
<PackageReference Include="Microsoft.Agents.AI" />
<PackageReference Include="Microsoft.Agents.AI.Workflows" />
<PackageReference Include="Microsoft.Agents.AI.Hosting" />
```

### 3.2 强烈推荐（处理长任务/重启续作）

```xml
<PackageReference Include="Microsoft.Agents.AI.DurableTask" />
<!-- 如果在 Azure Functions 部署 -->
<PackageReference Include="Microsoft.Agents.AI.Hosting.AzureFunctions" />
<!-- 检查点存储（任选其一） -->
<PackageReference Include="Microsoft.Agents.AI.CosmosNoSql" />
```

### 3.3 工具沙盒（关键安全）

```xml
<PackageReference Include="Microsoft.Agents.AI.Tools.Shell" />
<!-- 高安全场景 -->
<PackageReference Include="Microsoft.Agents.AI.Hyperlight" />
```

### 3.4 跨进程通讯（与现有 Cortana 服务集成）

```xml
<PackageReference Include="Microsoft.Agents.AI.A2A" />
<PackageReference Include="Microsoft.Agents.AI.Hosting.A2A.AspNetCore" />
```
