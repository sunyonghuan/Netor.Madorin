# Madorin 文档中心

`Docs` 用于保存 Madorin 项目的产品策划、架构设计、执行计划、验收记录和历史资料。
文档按业务主题组织；除 `总策划` 和 `未来策划` 外，各主题目录统一使用以下三层结构：

- `策划`：方案设计、需求分析、架构决策、实施路线和相关设计资料。
- `执行`：已经进入开发或落地阶段的执行计划、阶段任务和问题修复计划。
- `备档`：已完成、已验收、已替代或仅用于历史追溯的资料。

## 文档归类规则

1. 新增功能先放入对应主题的 `策划` 目录；方案稳定并开始实施后，将执行计划放入 `执行` 目录。
2. 一个专题包含多个文件时，使用专题目录集中保存，并在专题目录内提供 `README.md` 说明范围和阅读顺序。
3. 阶段完成、方案替代或问题关闭后，将不再作为当前执行依据的资料移动到对应主题的 `备档` 目录。
4. 项目级、跨主题的架构决策和总体产品规划统一放入 `总策划`，避免散落在具体功能目录中。
5. 发布说明与修复报告统一归入 `发布归档`；每次代码、构建或配置更新都在 `更新日志` 中按日期新增记录。

## 命名约定

- 方案类文档使用能够表达主题和范围的中文名称。
- 阶段性文档使用数字前缀，例如 `01-需求分析.md`，以保持阅读顺序稳定。
- 执行计划使用 `执行计划` 或明确的阶段名称，并在文档中记录当前状态、完成条件和验收结果。
- 已归档文档原则上保留原文件名，必要时在文件名中增加版本或日期。
