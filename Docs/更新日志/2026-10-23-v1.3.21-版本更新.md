## 更新概述

v1.3.21 是 v1.3.19 之后的正式补丁版本。安装包内的用户可见变化是文件树顶部工具栏：常用文件操作靠左，折叠工作台单独靠右，折叠图标改为面板收拢样式。

一句话：**文件树工具栏左右分开，折叠工作台不再挤在文件操作按钮旁边。**

本版本不改对话协议，不改数据库结构，不要求迁移配置。从 v1.3.19 覆盖解压即可。v1.3.20 只写进了源码项目文件，没有单独发布安装包。

## 用户可见变化

- 关于窗口、文件属性中的版本号为 `1.3.21`。上一份 GitHub 安装包是 `1.3.19`。
- 文件树顶部左侧依次是：打开文件夹、新建文件、刷新、全部折叠。
- 折叠工作台按钮移到工具栏右侧，不再跟文件操作挤在一起。
- 折叠工作台图标改为面板框加左箭头，不再使用旋转后的 `up.png`。
- 四个文件操作的点击行为没有变，工作目录名称仍由文件树根节点显示。

## 变更明细

### 功能与界面

`Src/Netor.Cortana.UI/Controls/Shared/WorkspaceExplorer.axaml`：

- 工具栏由「左侧留空、按钮全部靠右」改为「左侧文件操作、右侧折叠工作台」。
- 折叠按钮不再使用 `/Assets/up.png` 旋转 270 度，改为界面内绘制的收拢图标。
- 本次没有改文件树的数据、选择、拖放或展开逻辑。

- 本次安装包由已发布的 `Realases/Madorin` 目录打包，主程序文件版本为 `1.3.21.0`。
- 标签 `v1.3.21` 指向 `c3f55af`。该提交里的项目文件版本仍是 `1.3.20`；`1.3.21` 是发布时自动递增后打进安装包的版本，这次补说明时尚未提交回源码。
