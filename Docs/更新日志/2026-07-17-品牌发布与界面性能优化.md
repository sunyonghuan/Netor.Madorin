# 更新记录：品牌发布与界面性能优化

- 更新日期：2026-07-17
- 版本号：v1.3.11
- 关联提交：本文件所在 Git 提交

## 更新概述

本次更新完善多品牌发布目录和打包流程，同时修复高频 PowerShell 输出导致的 UI 调度队列堆积问题，并补充 Native AOT 场景下文件工具的 JSON 序列化配置。

## 变更明细

### 品牌发布与构建

- 将品牌配置、图标和 Logo 按品牌 ID 分目录管理。
- 增加统一的品牌发布入口和品牌资源说明。
- 更新默认品牌资源路径，桌面端和 NativeHost 使用统一的品牌图标。
- 打包时排除源目录中已有的 `.zip` 和 `.sha256` 文件，避免重复打包历史产物。
- 将桌面端版本更新为 `1.3.11`。

### 工具与插件链路

- 为文件工具注册补充源生成 JSON 序列化选项，降低 Native AOT/裁剪场景下的反射依赖。

### PowerShell 输出与界面性能

- 使用有界 Channel 接收 PowerShell 输出，并按时间或行数批量合并后推送。
- 将实时过程事件投递到后台调度优先级，避免高频输出阻塞用户输入。
- 对运行中过程卡片的自动滚动增加节流，减少重复布局和滚动操作。

## 兼容性与迁移

- 直接调用品牌发布脚本时，品牌配置路径需要使用 `Build/brands/{brand}/{brand}.json`。
- 推荐使用 `Build/brands/publish.ps1 -Brand {brand}` 作为品牌发布入口。
- 新增品牌时，应同时提供 `{brand}.json`、`brand.ico` 和 `brand.png`。
