# 运营总览与列表页重构执行计划 : 100%

## 背景修正

前序实现把列表页统计当作压缩卡片处理，方向不够准确。本轮按业务语义重做：

- 运营总览是后台首页，应承载图表、业务统计、数据统计、服务器运行信息和快捷功能入口。
- 列表页不是运营总览，顶部统计应改成服务当前表格的状态摘要和快捷筛选。
- 筛选表单保留当前多列排列方式，只调整 label 与输入框/下拉框的组合样式，使每个筛选条件成为一个紧凑控件。
- 表格继续使用 LayUI table、LayUI 原生分页、工具栏、筛选列、导出和打印能力。
