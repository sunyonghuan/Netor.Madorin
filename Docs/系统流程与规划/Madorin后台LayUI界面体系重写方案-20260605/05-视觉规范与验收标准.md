# 05. 视觉规范与验收标准

## 视觉方向

Madorin 后台是资源市场运营工具，应当安静、清晰、适合反复处理数据。避免营销页、装饰性大卡片和过度单色主题。

## 布局规范

1. 左侧导航宽度遵循 LayUI 默认 200px，折叠后使用 60px 图标模式。
2. 顶部高度保持 LayUI 默认 60px。
3. 内容区使用稳定间距，不把页面主体嵌套进多层卡片。
4. 列表页优先让筛选和表格可扫描，避免过大的标题区。
5. 工作台快捷入口是工具条，不是宣传横幅。

## 颜色规范

1. 导航和顶部栏优先使用 LayUI 标准深色体系，不做自定义白色侧栏。
2. 状态颜色使用 LayUI 标准按钮、徽标和提示色，不另造导航色系。
3. 表格、筛选、抽屉背景保持 LayUI 标准白色或浅灰，提高数据密度。
4. 文字对比度满足后台长时间使用要求。

## 组件规范

1. 按钮使用 LayUI `layui-btn` 系列。
2. 表单使用 LayUI `layui-form`、`layui-form-pane`。
3. 图标使用 LayUI 自带 icon，不手写 SVG。
4. 表格使用 LayUI table，不再手写静态分页。
5. 抽屉使用 `layer.open(type: 2)`，通过公共 `adminDrawer` 调用。

## 状态提示规范

1. 左侧菜单待办数字来自数据库。
2. 工作台快捷入口可显示数量或金额。
3. 数据为 0 时不隐藏入口，但弱化显示。
4. 危险操作必须出现确认。

## 验收标准

1. 保持 LayUI 标准深色侧栏和 `layui-nav-tree` 行为，差异体现在菜单信息架构和业务入口，而不是改掉 LayUI 颜色。
2. 首屏能看到真实业务工作台，而不是空泛欢迎页。
3. 菜单、快捷入口、筛选和表格数据请求形成闭环。
4. 不混入 Bootstrap 表格、表单、弹窗作为新增 UI。
5. 桌面、窄屏、移动端不出现明显横向溢出。
6. 构建通过只是基础验收，还需要 HTTP 页面和 JSON 端点验证。
