# Madorin 后台 LayUI 界面与功能体系改造方案

> 日期：2026-06-05  
> 范围：`Src/Netor.Cortana.Platform/Netor.Cortana.Platform.Admin`  
> 说明：本文件只做入口索引，详细方案已拆分到同名目录，避免单个文档过大影响后续执行效率。

## 核心约束

1. 不使用 `Netor.Operates.LayuiHelpers` 作为界面改造依赖。
2. 所有界面、表单、控件都采用 Razor `.cshtml` 编写。
3. Razor 输出 LayUI 标准结构、class、属性和模板。
4. 表格统一使用 LayUI 官方 `table.render()` 对接后端数据。
5. 所有新增、修改、查看都在右侧抽屉完成。
6. 用户交易记录等关联明细从底部抽屉打开。
7. 筛选设计必须基于当前项目控制器、数据库字段、枚举和关联表。
8. LayUI 2.x 官方文档地址：<https://layui.dev/docs/2/>
