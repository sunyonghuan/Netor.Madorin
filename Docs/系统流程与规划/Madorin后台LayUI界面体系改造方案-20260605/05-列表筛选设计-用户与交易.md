# 05. 列表筛选设计：用户与交易

## 用户账户 `Accounts`

主表字段：

```text
ID, No, LoginUserName, NickName, RealName, Phone, Email,
Status, AccountType, PhoneConfirmed, EmailConfirmed,
LoginTimes, LastLoginTime, LoginIP, RegestorIP, Refer,
Sex, SingleLoginEnabled, TimeStamp
```

表格列建议：

```text
复选框, 编号, 登录名, 昵称/实名, 手机, 邮箱, 状态,
账户类型, 钱包余额, 订单数, 订阅数, 下载数,
登录次数, 最后登录时间, 注册时间, 操作
```

筛选项：

| 筛选 | 来源 |
|---|---|
| 关键词 | 登录名、昵称、实名、手机号、邮箱、编号 |
| 用户编号范围 | `No` |
| 状态 | `Status` |
| 账户类型 | `AccountType` |
| 手机认证 | `PhoneConfirmed` |
| 邮箱认证 | `EmailConfirmed` |
| 性别 | `Sex` |
| 单点登录 | `SingleLoginEnabled` |
| 注册时间范围 | `TimeStamp` |
| 最后登录时间范围 | `LastLoginTime` |
| 登录次数范围 | `LoginTimes` |
| 登录 IP | `LoginIP` |
| 注册 IP | `RegestorIP` |
| 来源 | `Refer` |
| 钱包余额范围 | `AccountWallets.Money` |
| 订单数范围 | `Orders` 聚合 |
| 订阅数范围 | `Subscriptions` 聚合 |
| 下载数范围 | `DownloadRecords` 聚合 |
| 是否创作者 | `CreatorProfiles` 是否存在 |
| 创作者状态 | `CreatorProfiles.Status` |

行操作：

```text
查看, 编辑, 状态, 充值, 修改密码, 交易记录, 订单记录, 订阅记录, 下载记录
```

操作规则：

- `查看`、`编辑`、`充值`、`修改密码` 在右侧抽屉打开。
- `交易记录`、`订单记录`、`订阅记录`、`下载记录` 在底部抽屉打开。

## 用户交易记录底部抽屉

入口：

```text
Accounts/TransactionsForAccount?accountId={id}
```

数据来源：

```text
Transactions
Orders
Assets
PricingPlans
Accounts
```

表格列建议：

```text
交易号, 订单号, 第三方流水号, 标题, 资源, 价格计划,
交易金额, 实付金额, 类型, 支付状态, 支付方式,
订单状态, 支付时间, 创建时间, 操作
```

筛选项：

| 筛选 | 来源 |
|---|---|
| 关键词 | 交易号、订单号、第三方流水号、标题、内容 |
| 交易号 | `Transactions.No` |
| 订单号 | `Transactions.OrderNo`、`Orders.No` |
| 第三方流水号 | `ThirdNo` |
| 支付状态 | `PayStatus` |
| 支付方式 | `PayMethod` |
| 交易类型 | `Type` |
| 金额范围 | `Money` |
| 实付金额范围 | `RealMoney` |
| 支付时间范围 | `PayTime` |
| 创建时间范围 | `TimeStamp` |
| 订单状态 | `Orders.Status` |
| 订单支付状态 | `Orders.PayStatus` |
| 资源类型 | `Assets.Type` |
| 资源状态 | `Assets.Status` |
| 价格计划 | `PricingPlans.PlanType` |
| 异常交易 | 未支付、金额不一致、缺少订单、缺少第三方流水号等组合条件 |

底部抽屉能力：

- 刷新。
- 导出当前筛选结果。
- 点击订单号打开订单右侧详情抽屉。
- 点击资源打开资源右侧详情抽屉。
