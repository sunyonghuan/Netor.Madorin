# 08. 控制台首页与整体验收

## 控制台首页指标

首页应使用当前真实数据：

```text
资源总数
待审核资源
用户总数
有效订阅
今日订单
今日收入
待结算金额
热门资源排行
最新订单
审核队列
```

## 任务

1. 重做 `Home/Index.cshtml`。
2. 指标从当前数据库和服务查询。
3. 快捷入口指向真实后台模块。
4. 首页列表或排行使用 LayUI 标准样式。
5. 完成所有模块后做统一验收。

## 整体验收

1. 所有列表页使用 LayUI table。
2. 所有新增、修改、查看都在右侧抽屉完成。
3. 关联明细从底部抽屉打开。
4. 所有界面、表单、控件由 Razor 编写。
5. 页面不依赖 `Netor.Operates.LayuiHelpers`。
6. 筛选覆盖数据库字段和关键关联数据。
7. 现有业务能力不丢失。
