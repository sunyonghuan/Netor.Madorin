```text
Controllers/AssetsController.cs

```

## 任务

1. 资源列表改成 LayUI table。
2. 上传创建资源在右侧抽屉完成。
3. 资源详情右侧抽屉展示版本、价格、审核摘要。
4. 版本、价格计划、审核记录、下载记录从底部抽屉打开。
5. 审核列表改成 LayUI table。
6. 审核通过、拒绝、撤销保留原有业务校验。

## 验收

1. 资源筛选覆盖类型、状态、分类、推荐、版本、价格、审核、包信息。
2. 审核筛选覆盖状态、资源类型、提交人、审核人、时间范围、风险信息。
3. 资源和审核操作不丢失。
