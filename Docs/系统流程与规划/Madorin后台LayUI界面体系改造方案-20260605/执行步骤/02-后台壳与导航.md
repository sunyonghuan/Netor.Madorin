# 02. 后台壳与导航

## 文件

```text
Views/Shared/_Layout.cshtml
Views/Shared/_NavPartial.cshtml
Views/Shared/_WorkspacePartial.cshtml
Views/Shared/_ContentHeader.cshtml
wwwroot/css/site.css
wwwroot/js/site.js
```

## 任务

1. 保留并完善 `layui-layout-admin`。
2. 重做左侧菜单分组。
3. 顶部加入折叠、刷新、全屏、用户菜单。
4. 清理 Bootstrap 依赖样式。
5. 统一内容区容器。
6. 加入移动端侧栏遮罩和折叠行为。
7. 菜单不能只停留在传统模块名，应按当前数据库和后台操作链路暴露待办、用户钱包、资源市场、订单流水、订阅下载、创作者结算、系统运维等业务入口。
8. 常用新增、待审、待支付、待结算等入口应作为工作台快捷操作进入对应页面、筛选或右侧抽屉。

## 验收

1. 所有后台页面使用统一布局。
2. 菜单分组清晰，当前项高亮正确。
3. 顶部操作可用。
4. 页面无明显 JS 错误。
5. 不影响现有控制器路由。
6. 用户进入后台后能明显感知新的运营工作台外壳，而不是旧版 LayUI 默认侧栏。
7. 带 query 参数的菜单入口能自动填充筛选表单，并驱动 LayUI table 按该筛选加载。
