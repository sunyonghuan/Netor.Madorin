# 06. 列表筛选设计：业务模块

## 资源管理 `Assets`

表格列：

```text
复选框, 图标, 名称, Slug, 类型, 状态, 分类, 开发者,
拥有者, 推荐, 下载量, 当前版本, 价格计划, 发布时间, 操作
```

筛选：

```text
关键词, 类型, 状态, 分类, 是否推荐, 拥有者, 开发者,
发布时间范围, 下载量范围, 是否有当前版本, 版本号,
包存储, 包大小范围, 是否有包文件, 价格类型,
价格范围, 是否启用价格计划, 审核状态, 是否有待审
```

行操作：

```text
查看, 编辑, 发布, 下架, 隐藏, 草稿, 推荐/取消推荐,
版本, 价格计划, 审核记录, 下载记录
```

## 审核管理 `Reviews`

筛选：

```text
关键词, 审核状态, 资源类型, 资源状态, 分类, 提交人,
审核人, 提交时间范围, 审核时间范围, 是否有备注,
包存储方式, 版本号, 是否存在风险/完整性问题
```

右侧抽屉：

```text
审核详情, 通过审核, 拒绝审核, 撤销审核
```

## 分类管理 `Categories`

筛选：

```text
关键词, Slug, 是否可见, 排序范围, 创建时间范围,
资源数量范围, 已发布资源数量范围
```

右侧抽屉：

```text
新增分类, 编辑分类, 查看分类及资源统计
```

## 创作者管理 `Creators`

筛选：

```text
关键词, 显示名, 用户关键词, 状态, 通过时间范围,
创建时间范围, 资产数量范围, 待结算金额范围,
已结算金额范围, 是否有待审核资源
```

底部抽屉：

```text
名下资源, 收益订单, 结算记录
```

## 订阅管理 `Subscriptions`

筛选：

```text
关键词, 用户关键词, 资源关键词, 价格计划, 订阅状态,
开始时间范围, 到期时间范围, 取消时间范围, 即将到期,
已过期, 是否有关联订单, 下载次数范围, 资源类型, 资源状态
```

底部抽屉：

```text
订阅下载记录, 关联订单
```

## 下载记录 `Downloads`

筛选：

```text
关键词, 用户关键词, 资源关键词, 版本号, IP 地址,
UserAgent 关键词, 下载时间范围, 订阅状态,
资源类型, 资源状态, 存储方式
```

## 订单管理 `Orders`

筛选：

```text
关键词, 订单号, 标题, 内容, 用户关键词, 资源关键词,
订单状态, 支付状态, 支付方式, 金额范围, 数量范围,
支付时间范围, 创建时间范围, 分类, 价格计划,
是否有交易流水, 是否已生成结算
```

行操作：

```text
查看, 交易流水, 用户详情, 资源详情
```

## 交易流水 `Transactions`

筛选：

```text
关键词, 交易号, 订单号, 第三方流水号, 用户关键词,
标题, 支付状态, 支付方式, 交易类型, 金额范围,
实付金额范围, 支付时间范围, 创建时间范围,
订单状态, 资源类型, 价格计划, 异常交易
```

## 收益结算 `Settlements`

筛选：

```text
关键词, 创作者关键词, 资源关键词, 订单号, 状态,
币种, 总金额范围, 平台费用范围, 净额范围,
创建时间范围, 结算时间范围, 是否有备注
```

右侧抽屉：

```text
查看结算, 结算处理, 冻结, 拒绝
```

## 系统设置 `Settings`

筛选：

```text
关键词, Key 前缀, 分组, 类型, 是否保护,
是否为空值, 显示名, 配置名
```

右侧抽屉：

```text
新增设置, 编辑设置, 查看设置
```

批量能力：

```text
批量保存当前页可编辑值, 测试包存储配置,
重置, 删除非保护配置
```
