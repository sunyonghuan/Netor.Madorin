# 发布安装与调试

## 一、发布 Process 插件

```powershell
dotnet publish Your.Process.Plugin.csproj -c Release -o publish/Your.Process.Plugin
```

发布目录应包含：

```text
plugin.json
Your.Process.Plugin.exe
Your.Process.Plugin.dll
Your.Process.Plugin.deps.json
models/
templates/
```

仓库内插件优先使用插件项目根目录的专用发布脚本，例如：

```powershell
.\Plugins\Src\Cortana.Plugins.Voice.Tts.Melo\publish-voice-tts-melo.ps1
```

脚本会同步项目版本、插件清单版本，执行发布并生成 `Plugins\Releases\{PluginName}.v{Version}.zip`。只检查版本递增和目标产物路径时使用 `-DryRun`；需要复用当前版本重新打包时使用 `-SkipVersionBump`。

## 二、发布 Native 插件

```powershell
dotnet publish Your.Native.Plugin.csproj -c Release -o publish/Your.Native.Plugin
```

发布目录通常只需要：

```text
plugin.json
Your.Native.Plugin.dll
```

## 三、安装

运行时安装不要手工复制零散文件。请使用仓库内安装脚本或对应 zip 安装流程，把整个发布目录作为一个插件包处理。

## 四、更新

已加载插件更新的推荐顺序：

1. `sys_list_loaded_plugins`
2. `sys_unload_plugin(dirName)`
3. 安装脚本覆盖安装
4. `sys_reload_plugin(dirName)`

## 五、检查清单

```powershell
Get-Content publish/Your.Plugin/plugin.json
Get-ChildItem publish/Your.Plugin
```

重点确认：

| 文件 | 用途 |
|---|---|
| `plugin.json` | 插件清单 |
| `.exe` | Process 插件入口 |
| `.dll` | Native 插件库或 Process 依赖 |
| `.deps.json` | Process 依赖描述 |
| `models/` | 模型目录 |
| `templates/` | 模板目录 |

## 六、本地构建验证

```powershell
dotnet build Your.Plugin.csproj
```

构建后检查 `bin/.../plugin.json` 是否生成，Process 插件还要确认 `Program.g.cs` 和 `{PluginClass}Debugger.g.cs` 是否生成。

## 七、Process 自测

Process 插件的推荐模式是：

```csharp
if (args.Contains("--self-test", StringComparer.OrdinalIgnoreCase))
{
#if DEBUG
    return await SelfTest.RunAsync().ConfigureAwait(false);
#else
    return 2;
#endif
}

await Startup.RunPluginAsync().ConfigureAwait(false);
return 0;
```

自测应在插件项目内完成，并且先 `InitAsync()`，再逐个调用每个工具。

## 八、Native 调试

使用 Native Debugger 项目加载输出 DLL：

```powershell
dotnet run --project Src/Plugins/Netor.Cortana.Plugin.Native.Debuger/Netor.Cortana.Plugin.Native.Debugger.csproj -- publish/Your.Native.Plugin/Your.Native.Plugin.dll
```

## 九、AOT 发布

```xml
<PublishAot>true</PublishAot>
<JsonSerializerIsReflectionEnabledByDefault>false</JsonSerializerIsReflectionEnabledByDefault>
```

自定义返回类型要进 `JsonSerializerContext`，不要依赖运行时反射。
