# 工具声明与参数规范

宿主通过 `get_info.tools` 发现工具，再使用完整工具名执行 `invoke`。工具协议约束的是公开名称、参数 schema 和字符串结果，与插件内部如何组织代码无关。

发布清单 `plugin.json` 现在也包含 `tools` 数组，并带上插件级分类属性（`category`、`riskLevel`、`tags`、`searchHints`、`idempotent`）。工具可覆盖其中个别字段。详细规则见 [插件与工具分类属性.md](插件与工具分类属性.md)。

## 一、工具元数据

```json
{
  "name": "file_plugin_search_files",
  "shortName": "search_files",
  "description": "按关键词搜索文件。",
  "parameters": [
    {
      "name": "keyword",
      "type": "string",
      "description": "搜索关键词。",
      "required": true
    }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 宿主调用使用的完整工具名 |
| `shortName` | string? | 插件内短名称，不含插件 ID 前缀 |
| `description` | string | 面向模型和用户的用途说明 |
| `parameters` | object[]? | 参数列表；无参数时可为空或省略 |

完整工具名通常为 `{plugin_id}_{short_name}`。名称使用小写字母、数字和下划线，并在插件内保持唯一。

## 二、参数

当前工具参数 schema 支持：

| JSON 类型 | 常见语言类型 |
| --- | --- |
| `string` | string |
| `integer` | 32 位或 64 位整数 |
| `number` | 浮点数或十进制定点数 |
| `boolean` | bool |

复杂输入应拆为多个基础字段。参数名称必须与 `invoke.args` 内层 JSON 对象的属性名一致。

Process 调用示例：

```json
{"method":"invoke","toolName":"file_plugin_search_files","args":"{\"keyword\":\"report\"}"}
```

Native 调用对应 `cortana_plugin_invoke("file_plugin_search_files", "{\"keyword\":\"report\"}")`。

## 三、返回值

Process 响应的 `data` 和 Native `invoke` 返回值都是字符串：

- 文本结果直接返回文本。
- 数值和布尔值返回其字符串表示。
- 结构化结果返回 JSON 字符串。
- 失败应返回通道可识别的错误；不要把异常堆栈当作业务结果。

结构化结果示例：

```json
{"ok":true,"message":"查询完成","items":["a.txt","b.txt"]}
```

## 四、C# 示例（使用官方 SDK）

```csharp
[Tool]
public sealed class FileTools(FileIndex index)
{
    [Tool(Name = "search_files", Description = "按关键词搜索文件。")]
    public SearchResult SearchFiles(
        [Parameter(Name = "keyword", Description = "搜索关键词。")] string keyword,
        [Parameter(Name = "limit", Description = "最大结果数。", Required = false)] int? limit)
    {
        return index.Search(keyword, limit ?? 20);
    }
}
```

Generator 会把短名称 `search_files` 转成完整名称 `{plugin_id}_search_files`。如果 `Name` 已包含当前插件 ID 前缀，Generator 不会重复添加。

C# SDK 支持的参数类型为：

- `string`
- `int` / `long`
- `double` / `float` / `decimal`
- `bool`
- 上述类型的 nullable 形式

当前 Generator 不把 `CancellationToken` 识别为特殊工具参数，因此不要把它直接放进 `[Tool]` 方法签名。取消与长任务生命周期应在插件内部服务中处理。

## 五、C# 异步返回

工具方法可以返回同步值、`Task`、`Task<T>`、`ValueTask` 或 `ValueTask<T>`。例如：

```csharp
[Tool(Name = "run_job", Description = "运行任务。")]
public async Task<JobResult> RunJob(
    [Parameter(Name = "name", Description = "任务名称。")] string name)
{
    return await runner.RunAsync(name);
}
```

基础类型数组由 Generator 直接转成 JSON 数组。自定义对象、自定义对象数组和其他复杂返回类型必须注册到插件自己的 `PluginJsonContext`：

```csharp
[JsonSerializable(typeof(SearchResult))]
[JsonSerializable(typeof(JobResult))]
internal partial class PluginJsonContext : JsonSerializerContext;
```

## 六、实现约束

- 工具描述应说明行为和边界，不写内部类名或实现步骤。
- 可选参数必须有可预测的缺省行为。
- 不返回密钥、令牌、完整内部路径或异常堆栈。
- 长任务应快速返回任务标识或状态，避免无限占用一次工具调用。
- PluginBus 事件和模型请求不是普通工具参数，应通过各自协议发送。
