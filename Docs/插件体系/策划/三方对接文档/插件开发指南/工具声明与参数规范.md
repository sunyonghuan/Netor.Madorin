# 工具声明与参数规范

## 一、工具类

工具类加 `[Tool]`，并通过构造函数注入依赖：

```csharp
[Tool]
public sealed class FileTools(FileIndex index, ILogger<FileTools> logger)
{
}
```

服务在 `Startup.Configure(IServiceCollection services)` 注册。

## 二、工具方法

工具方法加 `[Tool]`：

```csharp
[Tool(Name = "search_files", Description = "按关键词搜索文件。")]
public string SearchFiles(
    [Parameter(Name = "keyword", Description = "搜索关键词。")] string keyword)
{
    return $"keyword={keyword}";
}
```

工具名应使用小写下划线。若未显式命名，Generator 会把方法名转成 snake_case，并再加上插件 ID 前缀作为完整工具名。

## 三、参数类型

当前支持的参数类型：

- `string`
- `int`
- `long`
- `double`
- `float`
- `decimal`
- `bool`

Process / Native 的工具参数不要写复杂对象；复杂输入请拆成多个基础字段。

## 四、异步和取消

支持 `Task<T>` / `ValueTask<T>`，也支持 `CancellationToken`：

```csharp
[Tool(Name = "run_job", Description = "运行任务。")]
public async Task<string> RunJob(
    [Parameter(Name = "name", Description = "任务名称。")] string name,
    CancellationToken cancellationToken)
{
    await runner.RunAsync(name, cancellationToken);
    return "任务完成。";
}
```

## 五、返回值

工具可以直接返回字符串、数值、布尔值、数组，或者经 `PluginJsonContext` 注册的自定义对象。

简单文本：

```csharp
return "已创建提醒。";
```

结构化对象：

```csharp
return JsonSerializer.Serialize(new ToolResult(true, "ok", "查询完成。", items), PluginJsonContext.Default.ToolResult);
```

如果返回自定义类型但没有对应的 `JsonSerializerContext`，生成器会报错。

## 六、命名建议

| 领域 | 前缀 |
|---|---|
| 窗口 | `window_` |
| Word | `word_` |
| Excel | `excel_` |
| PPT | `ppt_` |
| 语音 TTS | `voice_tts_` |
| 语音 STT | `voice_stt_` |
| 语音 KWS | `voice_kws_` |

## 七、LLM 相关工具

如果工具需要调用宿主授权的大模型，不要把模型调用逻辑伪装成普通字符串拼接。请先在入口类声明 `[RequiredHostCapability(Id = "host.llm.invoke.v1", ...)]`，再在工具内部通过宿主注入的 PluginBus 客户端调用 `model.capability.request`。示例见 [宿主LLM模型能力调用.md](宿主LLM模型能力调用.md)。
