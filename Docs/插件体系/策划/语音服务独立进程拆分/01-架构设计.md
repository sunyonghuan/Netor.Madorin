## 主程序职责

| 组件 | 状态 | 职责 |
| --- | --- | --- |
| `VoiceCapabilityRegistry` | DONE | 从已加载插件中按 `capabilities` 字段或兼容 `tags: ["voice", "stt"]` 发现 `voice.kws` / `voice.stt` / `voice.tts` 能力，并按设置项选择当前插件 |
| `VoiceOrchestrator` | NEW | 编排唤醒→打断→问候→识别→AI→合成→续杯流程；持有"当前轮次"状态机 |
| `PluginBusVoiceEventDispatcher` | DONE | 复用 PluginBus 消息入口，将插件上报的 `voice.kws/stt/tts.*` 事件映射为现有 EventHub 事件 |
| `KwsPluginAdapter` | NEW | 封装 KWS 插件控制命令；负责发起 `voice_kws_pause` / `voice_kws_resume` |
| `SttPluginAdapter` | NEW | 封装 STT 插件控制命令 |
| `TtsPluginAdapter` | DONE | 封装 TTS 插件控制命令；按 `shortName` 调用插件工具，并读取 `Voice.Tts.*` / `Tts.*` 设置 |
| `SttPluginInputChannel` | NEW | 实现 `IAiInputChannel`；订阅 `Events.OnSttFinal` 后调用 `IAiChatEngine.SendMessageAsync` |
| `TtsPluginOutputChannel` | DONE | 实现 `IAiOutputChannel`；AI token 断句后调用 TTS 插件 `enqueue`/`finish`；`IsActive` 仍由 `IWindowController.IsMainWindowVisible()` 决定（保留会议互斥语义），插件不可用时不朗读 |
| `VoiceCoordinator` | EXISTING，改造 | 用户取消时统一停止 KWS/STT/TTS 与当前 AI 任务；接口签名建议增加异步重载，详见 [07-接口与命名变更.md](07-接口与命名变更.md) |

主程序不再直接引用具体语音模型，不再直接创建 STT/TTS/KWS 引擎实例（落地后将删除 [WakeWordService.cs](Src/Netor.Cortana.Voice/WakeWordService.cs) / [SpeechRecognitionService.cs](Src/Netor.Cortana.Voice/SpeechRecognitionService.cs) / [TextToSpeechService.cs](Src/Netor.Cortana.Voice/TextToSpeechService.cs) 三大类，并从 [Netor.Cortana.Voice.csproj:17](Src/Netor.Cortana.Voice/Netor.Cortana.Voice.csproj#L17) 移除 `org.k2fsa.sherpa.onnx` 引用）。

## 语音插件职责

### KWS 插件

| 项 | 职责 |
| --- | --- |
| 麦克风监听 | 独立进程内长期监听麦克风 |
| 唤醒词检测 | 使用插件自带模型检测关键词 |
| 麦克风让渡 | 收到 `voice_kws_pause` 时立即关闭 `waveIn`，让 STT 插件能在同一物理设备上录音；收到 `voice_kws_resume` 时再次打开 |
| 事件上报 | 检测成功后通过宿主事件通道发送 `voice.kws.detected` |
| 模型管理 | 从插件目录 `models/KWS/` 加载模型 |

### STT 插件

| 项 | 职责 |
| --- | --- |
| 录音 | 独立进程内录制用户语音；start 前等待 `kws.paused` 状态 |
| 语音识别 | 输出 partial/final 识别结果 |
| 事件上报 | 发送 `voice.stt.partial` / `voice.stt.final` / `voice.stt.stopped` |
| 模型管理 | 从插件目录 `models/STT/` 加载模型 |

### TTS 插件

| 项 | 职责 |
| --- | --- |
| 文本合成 | 接收文本并合成为音频 |
| 音频播放 | 独立进程内播放音频 |
| 字幕同步 | 播放时发送 `voice.tts.subtitle` |
| 问候语缓存 | 插件内部缓存欢迎语音频；问候语**文本**仍由主程序通过 `voice_tts_greeting_regen` 下发，插件只持有合成产物 |
| 模型管理 | 从插件目录 `models/TTS/` 加载模型 |

当前落地状态：`Cortana.Plugins.Voice.Tts.Melo` 已通过 Process 插件 `init` 的 `pluginDirectory` 将默认模型目录解析为插件包内 `models/TTS`，并允许 `voice_tts_configure.model_directory` 用相对路径或绝对路径覆盖；插件状态会报告必需模型文件是否齐全以及缺失清单。AOT 播放器、分段音频提供器、Sherpa `OfflineTts` 模型加载、欢迎语真实音频缓存、单次播放与流式双 Channel 合成/播放流水线已迁入插件项目；插件进程已使用 `Src/sherpa_models/TTS` 完成真实模型短返回与后台状态归零验证，主程序全流程 PluginBus 事件、字幕广播和人工听感仍待验证。

## 插件能力声明

**当前实现状态**：[PluginManifest.cs](Src/Netor.Cortana.Plugin/Core/PluginManifest.cs) 已支持 `capabilities` 与 `tags` 字段；`VoiceCapabilityRegistry` 优先识别 `capabilities: ["voice.tts"]`，同时兼容 `tags: ["voice", "tts"]`。


| 能力 | capability |
| --- | --- |
| 关键词唤醒 | `voice.kws` |

| 文字转语音 | `voice.tts` |

## 编排流程

```text
KWS 插件检测到唤醒词
  │
  ├─ 插件上报 voice.kws.detected
  ├─ KwsPluginAdapter → EventHub: OnWakeWordDetected
  ├─ VoiceOrchestrator 收到唤醒事件
  ├─ 打断旧轮次：
  │     - 若上一轮 TTS 仍在播 → 调 TTS 插件 voice_tts_stop
  │     - 若上一轮 AI 任务未结束 → IAiChatEngine.CancelCurrentTask()
  │     - 若上一轮 STT 仍在识别 → 调 STT 插件 voice_stt_cancel
  ├─ 调 KWS 插件 voice_kws_pause（释放麦克风）
  ├─ 等待 KWS 上报 voice.kws.stopped 或 status=paused
  ├─ 调用 TTS 插件 voice_tts_greeting_play，播放问候语
  ├─ 等待 TTS 插件上报 voice.tts.completed
  ├─ 调用 STT 插件 voice_stt_start，开始识别
  ├─ STT 插件上报 voice.stt.partial → EventHub: OnSttPartial
  ├─ STT 插件上报 voice.stt.final → IAiChatEngine.SendMessageAsync
  ├─ AI token → TtsPluginOutputChannel → TTS 插件 voice_tts_enqueue
  ├─ AI done → TTS 插件 voice_tts_finish
  ├─ TTS 插件上报 voice.tts.subtitle → EventHub: OnTtsSubtitle
  ├─ TTS 插件上报 voice.tts.completed → EventHub: OnTtsCompleted
  ├─ VoiceOrchestrator 判断是否续杯
  │     - 续杯：再次发起 voice_stt_start（保持 KWS 仍 paused）
  │     - 结束：调 STT 插件 voice_stt_cancel + KWS 插件 voice_kws_resume
  └─ 返回 idle 等待下次唤醒
```

> 与原稿相比修正了两处：
>
> 1. 唤醒后第一步是**打断 TTS / 取消 AI**，而不是"取消旧 STT 识别"——唤醒发生时 STT 通常未启动，原稿动作目标错位。
> 2. 显式插入 `voice_kws_pause` / `voice_kws_resume`，避免 KWS 与 STT 同时争抢 `waveIn`。

## 用户主动取消

```text
MainWindow 调 IVoiceCoordinator.CancelEverythingAsync()
  │
  ├─ VoiceCoordinator → STT 插件 voice_stt_cancel
  ├─ VoiceCoordinator → TTS 插件 voice_tts_stop
  ├─ VoiceCoordinator → IAiChatEngine.CancelCurrentTask()
  ├─ VoiceCoordinator → KWS 插件 voice_kws_resume（恢复唤醒监听）
  ├─ VoiceCoordinator → publish OnSttStopped（兜底气泡收尾）
  └─ VoiceOrchestrator 重置当前轮次状态
```

> 旧 `IVoiceCoordinator.CancelEverything()` 是同步阻塞的（[IVoiceCoordinator.cs:18](Src/Netor.Cortana.Voice/IVoiceCoordinator.cs#L18)）。拆分后取消会涉及 3 次 WS 往返，建议新增异步重载，详见 [07-接口与命名变更.md](07-接口与命名变更.md)。
