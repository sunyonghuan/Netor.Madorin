# 验收清单

## 一、单元测试

`Tests/Netor.Cortana.Entitys.Tests/Realtime/NonExpertProcessScopeTests.cs`：

```csharp
[Fact]
public void Enter_ActivatesScope()
{
    Assert.False(NonExpertProcessScope.Active);
    using var _ = NonExpertProcessScope.Enter();
    Assert.True(NonExpertProcessScope.Active);
}

[Fact]
public void Dispose_RestoresPrevious()
{
    using (NonExpertProcessScope.Enter())
    {
        Assert.True(NonExpertProcessScope.Active);
    }
    Assert.False(NonExpertProcessScope.Active);
}

[Fact]
public void Enter_NestedRestoresPrevious()
{
    using (NonExpertProcessScope.Enter())
    {
        using (NonExpertProcessScope.Enter())
        {
            Assert.True(NonExpertProcessScope.Active);
        }
        Assert.True(NonExpertProcessScope.Active);
    }
    Assert.False(NonExpertProcessScope.Active);
}

[Fact]
public async Task Enter_FlowsThroughTaskRun()
{
    using var _ = NonExpertProcessScope.Enter();
    var observed = await Task.Run(() => NonExpertProcessScope.Active);
    Assert.True(observed);
}

[Fact]
public async Task Enter_DoesNotLeakAcrossParallelTasks()
{
    var t1 = Task.Run(async () =>
    {
        using var _ = NonExpertProcessScope.Enter();
        await Task.Delay(50);
        return NonExpertProcessScope.Active;
    });
    var t2 = Task.Run(async () =>
    {
        await Task.Delay(50);
        return NonExpertProcessScope.Active;
    });
    var results = await Task.WhenAll(t1, t2);
    Assert.True(results[0]);
    Assert.False(results[1]);
}
```

## 二、手动验证

| 场景 | 操作 | 通过条件 |
| --- | --- | --- |
| 专家 PowerShell | 专家模式让 AI 执行 `Get-Process \| Select -First 5` | 专家 ChatTab 出现 PowerShell 卡片 |
| 工作 PowerShell | 工作模式提交需要 PowerShell 的任务 | 专家 ChatTab 不出现 PowerShell 卡片；工作 timeline 自身 `work.tool.call` 卡片正常显示 |
| 工作模式普通工具 | 工作模式执行 `read_file` 等非 PowerShell 工具 | 工作 timeline 工具卡片正常；专家 ChatTab 无变化 |
| 专家 → 工作 handoff | 专家模式说"按这个方案开始执行"，AI 调 `start_work_task` | 切换到工作模式后，专家 ChatTab 不再追加工作任务工具卡片 |
| 会议 → 工作 handoff | 会议主持人调 `start_work_task` | 会议 / 专家 UI 都不出现工作任务工具卡片 |
| 取消工作任务 | 工作模式执行中点取消 | 取消后立即在专家模式开新对话，PowerShell 卡片正常显示在专家 ChatTab |
| 三模式并行 | 工作任务后台执行同时打开专家模式发送消息 | 工作任务工具事件不进入专家 ChatTab；专家自身工具事件正常显示 |
