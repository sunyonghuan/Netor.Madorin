- [√] `db migrate` 复用全局 `--workspace` 与 `--data-dir`，目标参数统一为 `--to <version>`，缺省迁移到当前 Runtime 支持的最新 Schema。

- [√] 当前版本已等于目标时返回 `up-to-date`，不建立无意义恢复点；缺失数据目录或数据库时不创建空数据。
- [√] CLI 只调用 Server 高层维护服务；Runtime 启动迁移与手动命令复用 `SqliteSchema` 迁移引擎，不由 CLI 直接打开 SQLite。
