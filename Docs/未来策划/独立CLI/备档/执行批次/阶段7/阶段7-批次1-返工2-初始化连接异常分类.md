# 阶段 7 批次 1 返工 2：初始化连接异常分类

## 背景

阶段 7 Client 生命周期改动将初始化阶段的所有失败统一包装为
`RuntimeClientProtocolException`。完整 E2E 回归中，SampleHost 重连遇到控制通道在
initialize 响应前关闭，底层抛出 `EndOfStreamException`，因此原有可重试连接竞态被
错误分类为不可重试协议错误。

验证证据：

- `RuntimeClientLifecycleStage7Tests`：7 / 7 通过。
- 完整 EndToEnd 项目：117 / 118 通过。
- 失败用例：`MultiInstanceProcessTests.TwoHostsWithTwoRuntimes_IsolatedAndCrossConnectionsFail`。
- 失败链：`EndOfStreamException -> RuntimeClientProtocolException`。

## 返工要求

- 初始化阶段由连接关闭、I/O 或连接超时导致的失败必须映射为
  `RuntimeClientConnectionException`，并设置 `IsRetryable = true`。
- 载荷、协议语义、能力或版本不兼容仍保持协议/健康/版本异常，不得扩大可重试范围。
- 调用方取消必须原样传播 `OperationCanceledException`。
- 增加最小测试，锁定初始化连接失败的稳定异常分类；不得修改既有测试来规避失败。
- 保持 `RuntimeClientException` 公共层级和现有启动策略兼容。
