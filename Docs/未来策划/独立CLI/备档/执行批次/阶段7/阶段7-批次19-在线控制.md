# 阶段 7 批次 19：在线控制 : 100%

## 目标与冻结边界

- [√] `ctl status/sessions/runs/cancel/credential update` 只通过已认证的 Client 控制通道访问正在运行的 Runtime，不直接打开 SQLite、Canonical JSONL 或 Blob 文件。
- [√] CLI 从全局 `--workspace` 与 `--data-dir` 定位唯一的 `runtime.pid`；`--instance` 用于匹配实例 ID，PID、实例 ID、控制 Pipe 和事件 Pipe 必须在连接与初始化阶段再次校验。
- [√] 自动发现仅接受目标数据目录中的 `runtime.pid` 和 `madorin.ai.runtime` 正式 Pipe 品牌；缺失、损坏、过期或品牌不匹配均返回连接失败，不扫描或终止其他实例。
- [√] Runtime 握手 secret 只从 `MADORIN_AI_RUNTIME_SECRET` 读取；缺失或空值返回退出码 3，secret 不进入参数、stdout、stderr、JSON 或日志。
- [√] 新增 `runtime.status` 与 `run.list` 公开请求/响应，并注册 `RuntimeJsonContext`；状态包含实例、版本、协议、工作区、PID、启动时间、活动 Run 和已连接宿主数量。
- [√] `run.list` 仅返回当前 Runtime 的活动 Run，可按 `--session` 精确筛选，并携带 Run ID、Session ID、状态和启动时间。
- [√] `ctl sessions` 复用 Client `ListSessionsAsync`，默认返回活动 Session；CLI 不复制 Server 查询逻辑。
- [√] `ctl cancel <runId> --reason` 发送协议命令，输出显式区分 `cancelAccepted` 与最终 `cancelled`；拒绝取消不得伪装为成功接受。
- [√] `ctl credential update` 要求 `--run`、`--provider` 与 `--api-key-env`，支持 `--profile` 和带时区的 `--expires-at`；API Key 只从指定环境变量读取。
- [√] 人类输出与 JSON 输出保持 stdout 可独立解析；参数错误 2、认证失败 3、连接/实例不匹配 5、Runtime 业务拒绝 1。
