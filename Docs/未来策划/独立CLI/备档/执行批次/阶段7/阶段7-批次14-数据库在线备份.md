# 阶段 7 批次 14：数据库在线备份 : 100%

## 目标与冻结边界

- [√] `db backup` 使用 SQLite 在线备份 API，不复制活动 `state.db`/WAL 文件拼接快照。
- [√] 默认输出为数据目录 `backups/` 下的唯一 `.db` 文件；`--output` 可指定目标数据库文件。
- [√] `--include-messages` 生成同名 `.messages.zip`，只包含 `messages/` 下的文件及相对路径。
- [√] 仅备份 SQLite 时不获取工作区写锁；包含消息时先获取排他锁，保证 SQLite 与 JSONL 一致性。
- [√] CLI 只调用 Server 高层维护服务，不直接打开 SQLite 或枚举消息目录。

## 原子性与错误边界

- [√] 数据库与消息归档均先写同目录唯一临时文件，flush 后原子发布。
- [√] 显式输出已存在时拒绝覆盖；失败不得损坏或替换已有文件。
- [√] 消息归档失败时删除本次尚未发布的数据库备份，避免返回不完整备份集。
- [√] 缺失数据目录、缺失 `state.db`、目标目录不可写和锁冲突返回稳定退出码及 JSON 错误。
- [√] 输出路径、消息文件名和内容中的中文、空格及特殊字符无损保留。
