## 1. 目标

为 CLI 和宿主启动的 Agent 提供最小化记忆能力。记忆只由两个 UTF-8 Markdown 文件组成：一个属于当前系统用户，一个属于当前工作区。Agent 每次启动时自动读取并注入这两个文件，用于表达编码规范、工作规范、项目约束和用户习惯。

记忆不是会话历史、Agent Prompt、配置文件或恢复检查点。V1 不实现向量数据库、Embedding、自动记忆提取、语义检索、复杂知识库或后台记忆整理任务。

## 2. 作用域与文件位置

文件名统一为 `memory.md`，不添加 `global`、`project` 等前缀：

```text
全局记忆：~/.madorin/memory.md
项目记忆：<workspace>/.madorin/memory.md
```

路径规则：

1. Windows 全局路径为 `%USERPROFILE%\.madorin\memory.md`；macOS/Linux 为 `~/.madorin/memory.md`。
2. 独立执行 `madorin` 时，项目工作区默认为 CLI 启动时的当前目录，也可以由已有 `--workspace` 参数显式指定。
3. 宿主启动 Runtime 时，项目工作区只使用宿主明确传入的 `workspaceRoot`，不得从 Runtime 进程当前目录猜测。
4. 全局记忆跟随 Runtime 进程所属的系统用户；项目记忆跟随当前绑定工作区。
5. 如果全局路径与项目路径解析为同一个文件，只读取和注入一次，并按全局记忆显示。
6. 文件不存在表示该作用域暂无记忆，不构成启动错误。

## 3. 内容规范

记忆使用简洁的自然语言和 Markdown 列表，不定义 YAML Front Matter、记录 ID、时间线或数据库 Schema。

全局记忆示例：

```markdown
# Memory

- 默认使用中文沟通和编写 Git 提交说明。
- C# 项目优先采用清晰分层、依赖倒置和可维护命名。
- 修改文件前先检查所在目录的 README.md。
- 用户偏好直接给出结论和可执行步骤。
```

项目记忆示例：

```markdown
# Memory

- 本项目使用 .NET 10 和中央包管理。
- 项目、程序集和命名空间统一使用 Madorin.AI.Runtime.*。
- 工作区 .madorin 是 Runtime 保留目录，普通文件工具不得访问。
- 新增公共协议字段时必须同步 JSON 快照测试。
```

内容要求：

1. 每条记忆只表达一个稳定规则、事实或偏好，使用短句和列表。
2. 全局记忆保存跨项目通用的编码规范、工作规范和用户习惯。
3. 项目记忆保存当前项目特有的架构、命名、构建、测试和业务约束。
4. 项目记忆与全局记忆冲突时，以更具体的项目记忆为准。
5. 记忆不得包含 API Key、Token、密码、私钥或用户不希望发送给模型的敏感内容。
6. 单个文件 V1 最大 32 KiB；超过限制时明确报错，不自动截断、摘要或拆分。

## 4. CLI 操作命令 : 0%

提供以下最小命令：

```text
madorin memory init <global|project>
madorin memory show <global|project|effective>
madorin memory add <global|project>
madorin memory edit <global|project>
madorin memory clear <global|project>
```

命令行为：

- [×] `init` 创建包含标题和简短示例的 `memory.md`，已有文件时不覆盖。
- [×] `show global|project` 显示指定文件和实际路径；`show effective` 按全局、项目顺序显示最终注入内容。
- [×] `add` 提示用户输入一条简洁记忆，并以 Markdown 列表项追加。
- [×] `edit` 优先打开用户配置的文本编辑器；没有可用编辑器时进入 CLI 多行编辑。
- [×] `clear` 在明确确认后清空正文但保留文件；非交互模式必须显式传入已有的统一确认参数。
- [×] 所有写操作先取得对应记忆文件的跨进程写锁并重新读取最新正文，再使用临时文件和原子替换；失败时保留原文件，并发追加不得丢失已提交条目。
- [×] 项目作用域没有可用工作区时直接报错，不回退到全局文件。

交互 CLI 同时提供：

```text
/memory [global|project|effective]   查看记忆
/remember <global|project>          交互追加一条记忆
```

`/remember` 只处理用户当前明确输入的内容，不分析对话并自动生成记忆。

## 5. CLI 内置记忆工具契约 : 0%

在现有 CLI/Runtime 服务中实现一个小型 Memory File Service，不新增独立项目。文件服务放在 `Madorin.AI.Runtime.Services`；本阶段同时冻结 `Madorin.AI.Runtime.Tools.Builtin` 中的模型工具契约，实际 Tool Catalog 注册和网关执行在阶段 5 完成。文件服务只负责：

```text
ResolveGlobalPath
ResolveProjectPath
Read
Initialize
Append
Replace
Clear
```

阶段 5 完成后，CLI 启动时把最小的 `builtin.memory` 工具注册到当前 Tool Catalog，并随 Provider 请求直接提供给 LLM：

```text
builtin.memory.read      读取 global、project 或 effective 记忆
builtin.memory.append    向指定作用域追加一条记忆
```

模型调用链固定为：

```text
LLM 发起 builtin.memory.read/append
-> Runtime Tool Gateway 验证参数和权限
-> 当前进程调用 Memory File Service
-> 返回内容或新文件哈希给 LLM
-> Agent 继续本轮推理
```

工具边界：

- [×] `builtin.memory.read/append` 是模型可直接调用的 CLI 内置工具，不是仅供命令实现使用的内部 API。
- [×] 两个工具在当前 `madorin` 进程执行，不启动子进程，也不经过宿主或 MCP 反向 RPC。
- [×] CLI 的 `memory` 命令、REPL 命令、Agent 启动注入和模型工具共用同一个 Memory File Service。
- [×] `builtin.memory.read` 返回当前 Invocation 已固定的 global、project 或 effective 记忆及对应哈希。
- [×] `builtin.memory.append` 必须经过用户明确审批；成功后返回新文件哈希，并明确标记从下一次 AgentInvocation 开始自动注入。
- [×] `Replace` 和 `Clear` 只开放给用户执行的 CLI 命令，不作为模型可调用工具发布。
- [×] Runtime 不在对话结束、摘要生成或 Agent 完成时自动调用 `append`。
- [×] 普通 `builtin.fs` 仍然拒绝访问 `.madorin`；只有 Memory File Service 可以访问两个固定的 `memory.md` 路径。
- [×] 工具不扫描仓库文件、不解析 Git 历史，也不从 CanonicalHistory 推断记忆。

## 6. Agent 启动自动注入 : 0%

每个 `AgentInvocation` 创建 Agent 时执行：

```text
读取 Agent systemPrompt
-> 读取 ~/.madorin/memory.md
-> 读取 <workspace>/.madorin/memory.md
-> 按 Global Memory、Project Memory 分段组合
-> 添加 Session/Run 指令和当前 ContextProjection
-> 创建本次 Agent
```

注入规则：

- [×] Expert、Meeting、Work 的所有 Agent 都使用同一个注入流程，不在各模式重复实现。
- [×] 全局记忆先注入，项目记忆后注入；同类规则冲突时项目记忆优先。
- [×] 记忆只能补充工作规范和上下文，不能覆盖 Runtime 安全规则、宿主明确策略、工具 Grant 或用户当前指令。
- [×] 文件缺失或正文为空时跳过对应段落，不注入空占位内容。
- [×] 每次 Invocation 启动时读取一次并固定；文件修改只影响下一次 Invocation。
- [×] 记忆正文不复制到 CanonicalHistory，也不进入 AgentSnapshot 明文字段。
- [×] `InvocationSnapshot` 记录可空的 `globalMemoryHash` 和 `projectMemoryHash`，用于诊断实际注入版本。
- [×] 读取或编码失败时在调用 Provider 前返回明确错误，不使用半截内容继续执行。

## 10. 风险与禁止事项

- 不得把 CanonicalHistory、摘要、Checkpoint 或 Agent Prompt 重新命名为记忆。
- 不得创建 `global-memory.md`、`project-memory.md` 或其他带作用域前缀的文件。
- 不得让模型在没有用户审批时写入、修改或清空记忆。
- 不得自动从对话、项目文件、Git 提交或工具结果提取记忆。
- 不得在 V1 引入向量数据库、Embedding、语义检索、标签系统、记忆评分、过期策略或后台整理任务。
- 不得允许记忆内容扩大工具权限或覆盖 Runtime/宿主安全策略。
