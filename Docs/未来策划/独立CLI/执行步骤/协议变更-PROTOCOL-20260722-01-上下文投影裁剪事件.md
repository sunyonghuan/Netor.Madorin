## 变更表面

- DTO / 字段：新增 `ContextProjectionAdjustedEvent`，字段为 invocationId、droppedMessageCount、includedMessageCount、estimatedTokens、estimateSource、strategy。
- 消息类型 / JSON-RPC 方法：新增可选事件 `context.projection.adjusted`；无新增 JSON-RPC 方法。
- 枚举 / discriminator：无。
- 能力 / 限制：无新增能力；事件只报告投影裁剪，不改变模型窗口协商值。
- 错误码：无。
- GSN / 幂等 / 确认 / 终态影响：事件按普通持久化 Runtime 事件占用 GSN；不改变确认、幂等或 Run 终态语义。
- 安全与敏感数据影响：不包含 Prompt、消息正文、工具参数或凭据。

## 兼容性判断

- 最旧兼容协议版本：`1.0`。
- 新 Host -> 旧 Runtime：支持；旧 Runtime 不发送该可选事件。

- 未知字段处理：接收方忽略未知可选字段。

- 是否需要提升协议主版本：否；属于可安全忽略的新增可选事件。
- 是否需要保留旧字段/消息：无替换或删除。
