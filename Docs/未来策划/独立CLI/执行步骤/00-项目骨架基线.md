## 5. 当前能力边界

- `serve`、`run` 等命令目前只有参数和帮助表面，没有绑定 Runtime 执行处理器。
- `RuntimeServerOptions` 中的 `InstanceId`、`PipePrefix` 和 `MaxConcurrentRuns` 只是配置模型，不构成多实例或并发 Run 实现。
- 当前 `RuntimeEventEnvelope` 没有 `runtimeInstanceId`，`IRuntimeClient` 也没有实例绑定身份；宿主合并多个 Runtime 事件流时尚无可靠的实例归属契约。
- Named Pipe、实例锁、工作区写锁、Run Registry、并发限制器和真实持久化尚未实现。
- CLI 项目的 `AssemblyName` 当前仍是 `ai-runtime`；正式产物名 `madorin`/`madorin.exe` 由阶段 7 和阶段 8 的现有未完成项负责修正与验收。
- 本阶段完成不提高阶段 1 至阶段 8 的业务实现进度。
