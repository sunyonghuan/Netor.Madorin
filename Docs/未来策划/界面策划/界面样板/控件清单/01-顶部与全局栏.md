# 01 · 顶部与全局栏

覆盖始终可见的框架级控件：顶部两条栏、左侧活动栏、底部状态栏、以及底部可折叠的 Agent 监控条。

---

## 1. 标题栏 `#titlebar`

- **位置** — 最顶部，整宽，高 `36px`
- **风格** — 背景 `--s0`，底部 1px 分隔线，禁止选中文本
- **功能布局**（从左到右）：
  - `.wsbrand` — 品牌符号 `◈`，天蓝 `--ac`，字号 15px
  - `.wsname` — 品牌名文本"Madorin Workbench"，次要灰 12px（不再拼接工作区名）
  - `.winbtns` — 靠右的窗口控制组，含 3 个 `.wb` 按钮：最小化 `─`、最大化 `□`、关闭 `✕`
- **交互** — `.wb` 悬停变 `--s2` 底；关闭按钮额外加 `.cls`，悬停变红底白字

---

## 2. 顶部工具栏 `#headerbar`

- **位置** — 标题栏下方，整宽，高 `44px`
- **风格** — 背景 `--s0`，底部分隔线，横向 flex、间距 8px
- **功能布局**（从左到右）：

| 控件 | 类/属性 | 说明 |
|------|---------|------|
| 新建任务 | `.hbtn.pri` | **主按钮**，强调色底黑字加粗，点 `openNewDialog()` |
| 命令面板 | `.hbtn` | command 图标，点 `openCmdPalette()` |
| （弹性占位） | `.hsep` | `flex:1` 把右侧内容推到最右 |
| 运行中芯片 | `.hchip.hc-run` | 绿底"● 3 运行中"，点跳总览 |
| 审批芯片 | `.hchip.hc-appr` | 黄底"⚠ 2 审批"，点跳审批面板 |
| Token 芯片 | `.hchip.hc-tok` | 灰底"124k tokens"，只读展示 |
| 设置 | `.hbtn` | 点 `switchNav('settings')` |
| 主题切换 | `#theme-btn`（内 `#theme-ico`） | 点 `toggleTheme()`，图标在 sun/moon 间切换 |

- **`.hbtn` 通用风格** — 高 28px，`--s1` 底 + `--bd` 边，圆角 4px；悬停 `--s2`
- **`.hchip` 通用风格** — 高 24px，胶囊圆角 12px，字号 12px；三种语义底色对应运行/审批/Token

---

## 3. 左侧活动栏 `#activity`

主导航，切换左侧边面板的内容。

- **位置** — `#center` 最左列，默认宽 `48px`，可展开到 `200px`
- **风格** — 背景 `--s0`，右侧分隔线，纵向排列图标按钮，`transition:width .18s`
- **功能布局** — 一列 `.abt` 导航按钮：

| 按钮 id | 图标 | 导航目标 | 说明 |
|---------|------|---------|------|
| `#abt-overview` | layout-dashboard | `switchNav('overview')` | 总览 |
| `#abt-projects` | folder-kanban | `switchNav('projects')` | 项目管理，小字"所有工作项目"（默认选中 `.on`） |
| `#abt-plugins` | cpu | `switchNav('plugins')` | 功能管理，小字"所有已安装插件" |
| `#abt-skills` | triangle-alert | `switchNav('skills')` | 技能管理，小字"所有已安装技能" |
| `#abt-store` | store | `switchNav('store')` | 应用商店，小字"发现并安装插件与技能" |
| `.abt-sep` 分隔线 | | | |
| `#abt-settings` | settings（`.abt-bot` 推到底部） | `switchNav('settings')` | 设置，小字"系统偏好设置" |
| `#act-expand-btn` | chevrons-right | `toggleActivityBar()` | 展开/收起导航栏 |

- **`.abt` 风格** — 36×36 圆角按钮，图标色 `--txm`；悬停 `--s1`；选中 `.on` 时变 `--s2` 底 + `--ac` 图标，左侧有 3px 竖条高亮（`.abt.on::before`）
- **展开态** `#activity.expanded` — 宽 200px，每个按钮变成「图标 + 标题 + 描述」横向行：`.abt-text` 显现，含 `.abt-name` 主名与 `.abt-desc` 描述；选中态改为左侧竖条 + `--acd` 底
- **交互** — `toggleActivityBar()` 切换 `.expanded` 类，同时翻转展开图标和文字标签

## 4. 底部状态栏 `#statusbar`

- **位置** — 最底部，整宽，高 `24px`
- **风格** — 蓝底 `#007acc`（亮色主题为 `#0550ae`），白色半透明文字
- **功能布局**：
  - 左侧 `.sb` 项："3 任务执行中"、"5 Agent 工作中"、黄色"2 项等待确认"
  - `.sbsep` — 竖分隔线
  - 右侧 `.sbr`：存储信息"SQLite 索引 / JSONL 正文"、时钟 `#clock`（`updateClock()` 每秒刷新）

## 5. Agent 监控条 `#agentstrip`

横跨底部、位于状态栏之上的**可折叠**面板，实时监控所有运行中的 Agent 实例。

- **位置** — `#center` 与 `#statusbar` 之间，整宽
- **风格** — 背景 `--s0`，顶部分隔线
- **两段结构**：

### 5.1 头部 `.strip-hdr`（高 28px，点击 `toggleStrip()` 切换展开）

- `.strip-lbl` — 标题"Agent 监控"
- **收起态**显示 `#strip-mini` 迷你列表：多个 `.smini`，每项一个 `.smdot` 状态圆点（绿=运行/黄=等待）+ 简短文本，如"Claude: 生成代码中"
- **展开态**显示 `#strip-summary` 汇总计数："进行中 4 / 等待 1 / 共 5 个实例"
- `.strip-toggle`（`#strip-btn`）— 右侧"▲ 展开 / ▼ 收起"提示

### 5.2 卡片区 `#strip-cards`（展开时显示，高 136px，横向滚动）

一排 `.acard` Agent 卡片，每张宽 195–210px：

- `.ac-h` 头行 — `.ac-d` 状态圆点（`.acd-r` 绿呼吸/`.acd-w` 黄/`.acd-o` 灰）+ `.ac-n` Agent 名 + `.ac-m` 模型名
- `.ac-task` — 所属任务（带 pin 图标）
- `.ac-step` — 当前步骤文本（如"▶ 生成 auth.cs 认证逻辑..."），部分卡片由 JS 动画滚动更新
- `.ac-tbar` / `.ac-tfill` — Token 用量细进度条（填充色随模式变化）
- `.ac-meta` — 元信息"8.2k / 64k · 步骤 3/8 · 12m34s"

> 样板里放了 5 张卡片：Claude-3.7、GPT-4o、会议主持、评审员A（等待态黄色）、评审员B。

- **交互** —
  - 点击整张 `.acard`（`cursor:pointer`）触发 `focusAgentCard(taskId)`：打开该 Agent 所属任务的选项卡，并激活其**总界面选项卡**（该任务面板内首个 `.wt`）
  - `toggleStrip()` 用变量 `stripOpen` 切换卡片区/迷你列表/汇总的显隐，并重渲染图标
