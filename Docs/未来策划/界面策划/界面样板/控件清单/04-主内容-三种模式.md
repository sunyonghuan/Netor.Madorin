# 04 · 主内容 · 三种任务模式

Madorin 有三种任务模式，各占一个 `.pane`，主题色区分：
**工作=橙(wk)、会议=紫(mt)、专家=绿(ex)**。三者共用一套顶栏和输入区结构。

## 公共控件

### 模式顶栏 `.mode-topbar`
- 高度自适应，`--s0` 底 + 底部分隔线，横向 flex
- 左侧：`.mbadge` 模式徽章 + `.mode-title` 任务名 + 状态徽章/说明
- 右侧 `.mode-actions`：`.mab` 操作按钮（暂停/停止等），`.mab.danger` 为红色危险操作

### 状态徽章
- `.stbadge` — `.st-run` 绿"运行中" / `.st-wait` 黄"等待" / `.st-done` 灰"完成"

### 消息区 `.msg-scroll`
- 可滚动，纵向 flex，间距 14px，内边距 14×18px
- `.bubble-user` — 用户气泡，右对齐，`--acd` 底 + `--ac` 边，左下角切角
- `.bubble-ai` — AI 气泡，左对齐：`.ai-sender`（发送者名，用模式色）+ `.ai-body`（`--s1` 底内容）
- `.tool-card` — 工具调用卡：`.tc-head`（"工具调用 · read_file"）+ `.tc-code`（等宽绿字参数/结果）

## 1. 工作模式 `#pane-work1`（橙 wk）

最复杂的模式，顶栏下有 5 个内部子标签 `.wtabs` > `.wt`（选中 `.on` 变橙 + 底部橙线），
每个对应一个 `.wtpane`（`.on` 显示）。切换函数 `workTab(btn, tabId)`。

### 顶栏
- `.mbadge.mb-wk`"⚡ 工作" + 标题"登录模块重写" + `.stbadge.st-run`"● 运行中 · 步骤 3/8"
- 右侧：`.mab`"⏸ 暂停"（`pauseTask()`）、`.mab.danger`"✕ 停止"（`stopTask()`）

### 子标签 1 · 计划与进度 `#wtp-plan`（默认）

- **审批条** `.appr-bar` — 顶部高亮告警条，橙底橙边：
  - 警告图标 + `.appr-txt`（"高风险审批：..." + `.appr-code` 等宽操作签名）
  - `.appr-acts` 三按钮 `.aa`：`.aa-y`"✓ 允许本次"、`.aa-yt`"✓ 允许本任务"、`.aa-n`"✕ 拒绝"，点 `handleAppr()`
- **时间线** `.timeline` — 一列 `.step` 步骤：
  - `.step-ico` 圆形状态图标：`.si-done`（绿✓）/ `.si-run`（橙+呼吸动画）/ `.si-wait`（灰序号）
  - `.step-body`：`.step-title` 步骤名 + `.step-sub` 说明；进行中的标题 id 为 `#wk-step-title`、副文本 `#wk-step-sub`（JS 动画更新）

### 子标签 2 · Agent 泳道 `#wtp-swim`

- `.swimlane` 容器 > `.swim-row` 每个 Agent 一行：
  - `.swim-head` — 状态圆点 + `.swim-name` 名字 + `.swim-model`（模型 · token）
  - `.swim-steps` — 一排 `.swstep` 步骤标签：`.done`（绿）/ `.run`（橙呼吸）/ 默认（灰待执行）

### 子标签 3 · 活动流 `#wtp-log`

- 纯文本日志流，每行"时间戳（绿/黄）+ [来源] + 动作"，等宽风格
- 时间戳绿色=正常、黄色=等待审批

### 子标签 4 · 对话 `#wtp-chat`

- `.msg-scroll` 消息区（用户气泡 + AI 气泡 + 工具卡）
- 底部是通用输入区 `.ia-wrap`（详见 05 文档），发送按钮为橙色

### 子标签 5 · 产物 `#wtp-art`

- `.artifact-list` > `.art-item` 产物条目：
  - `.art-icon` 文件图标 + `.art-info`（`.art-name` 文件名 + `.art-meta` 说明）+ `.art-badge` 状态标签
  - 状态标签：`.ab-new` 绿"新建" / `.ab-mod` 橙"修改中" / `.ab-del` 红"删除" / 灰"待生成"

## 2. 会议模式 `#pane-meeting1`（紫 mt）

多 Agent 圆桌讨论，有议程进度 + 参会成员 + 发言气泡流。

### 顶栏
- `.mbadge.mb-mt`"会议" + 标题"架构评审会" + 当前议题说明
- 右侧：进行时长 + `.mab.danger`"✕ 结束会议"

### 议程条 `.agenda-bar`
- "议程："标签 + `.agenda-prog`（一排 `.agst` 进度段）+ 当前议题名（紫色）
- `.agst` 段：默认灰 / `.done` 绿（已完成）/ `.run` 紫呼吸（当前）
- 样板 4 段：开场介绍✓、微服务拆分策略(当前)、数据迁移方案、总结行动项

### 参会成员 `.meet-members`
- "参会："标签 + 多个 `.mchip` 成员芯片：
  - `.mc-host` 紫底"主持人"（带 mic 图标）
  - `.mc-speak` 紫边呼吸=正在发言（`#speaking-chip`，JS `speakers` 轮换）
  - `.mc-idle` 灰=空闲

### 发言流 `.msg-scroll`
- `.meet-bub` 发言气泡（横向：头像 + 内容）：
  - `.mavatar` — 28px 圆形头像（紫底，主持人用 mic 图标，评审员用字母 A/B）
  - `.msender` — 发言人名（紫色）+ 括号内模型名
  - `.mtext` — 发言正文（`--s1` 底气泡）
  - `.mthink` — 可选的"思考过程"斜体小卡（带 brain-circuit 图标），展示 Agent 的分析
- 底部通用输入区 `.ia-wrap`，发送键紫色；会议模式输入区顶部多一行 `.ia-agents` 参会 Agent 芯片管理（`.ia-agent-chip` + `.ia-add-agent` 添加，函数 `addMeetingAgent()`）

## 3. 专家模式 `#pane-expert1`（绿 ex）

最轻量：单 Agent 一对一对话，无子标签、无泳道。

### 顶栏
- `.mbadge.mb-ex`"专家" + 标题"代码优化讨论" + "GPT-4o · 12k tokens"
- 右侧：`.mab`"转为工作任务"（shuffle 图标，保留会话作上下文）、`.mab.danger`"■ 停止"

### 对话区 `.msg-scroll`
- 用户气泡 + AI 气泡（绿色发送者名）+ 工具卡交替
- AI 正文里可嵌行内代码（等宽 + `--s2` 底小块）
- 生成中提示：底部一行 `.dot.d-ex.pulse` 绿呼吸点 + "GPT-4o 正在生成..."
- 底部通用输入区 `.ia-wrap`，发送键绿色

## 三模式对照速查

| | 工作 wk | 会议 mt | 专家 ex |
|---|---|---|---|
| 主题色 | 橙 | 紫 | 绿 |
| 徽章 | `.mb-wk` | `.mb-mt` | `.mb-ex` |
| 面板 id | `#pane-work1` | `#pane-meeting1` | `#pane-expert1` |
| 子标签 | 5 个(计划/泳道/日志/对话/产物) | 无(议程条) | 无 |
| 特色控件 | 时间线 `.timeline`、审批条 `.appr-bar`、泳道 `.swimlane` | 议程条 `.agenda-bar`、参会芯片 `.meet-members` | 转任务按钮 |
| 参与 | 单/多 Agent 编排 | 多 Agent 圆桌 | 单 Agent |
