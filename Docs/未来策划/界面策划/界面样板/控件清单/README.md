# Madorin Workbench 控件清单

本目录把 `../index.html`（单文件 UI 样板）里的所有界面与控件逐一梳理出来。
目的：当你想改某个控件时，可以直接引用它的**定位标识**（CSS 类名 / DOM id），
我就能精确定位到 `index.html` 里的对应代码，不用来回描述"就是那个按钮"。

## 怎么用这份清单

每个控件条目统一按下面格式描述：

- **定位标识** — CSS 类名（`.xxx`）或 DOM id（`#xxx`），这是你告诉我"改哪个"的钥匙
- **位置** — 它在界面的哪个区域
- **风格样式** — 尺寸、颜色、圆角、字号等视觉规则
- **功能布局** — 内部结构、排列方式
- **交互** — 点击/悬停/输入触发的行为（绑定的 JS 函数）

举例：你可以说"把 `01` 文档里活动栏 `.abt` 的图标改大一点"，
或"`04` 里工作模式的审批条 `.appr-bar` 背景色太刺眼"，我就能直接定位。

## 设计规范（全局约定）

### 颜色变量（`:root` CSS 变量，暗色为默认）

所有颜色都用变量，不写死。改主题色只需改 `:root` 里的变量值。

| 变量 | 暗色值 | 含义 |
|------|--------|------|
| `--bg` | `#1e1e1e` | 页面最底背景 |
| `--s0` `--s1` `--s2` `--s3` | `#252526`→`#4a4a4a` | 由深到浅的 4 级面板 / 悬浮层背景 |
| `--bd` `--bd0` | `#3c3c3c` `#2d2d2d` | 边框（常规 / 更淡） |
| `--tx` `--txm` `--txf` | `#cccccc` `#858585` `#5a5a5a` | 文字（正文 / 次要 / 最弱） |
| `--ac` `--acd` | `#4fc3f7` 天蓝 | **强调色**（主按钮、选中、链接）/ 其深色底 |
| `--ex` `--exd` | `#56c6a0` 绿 | **专家模式**主题色 / 深色底 |
| `--wk` `--wkd` | `#ff8c00` 橙 | **工作模式**主题色 / 深色底 |
| `--mt` `--mtd` | `#a78bdd` 紫 | **会议模式**主题色 / 深色底 |
| `--ok` `--warn` `--err` | 绿 / 黄 / 红 | 状态语义色：成功 / 警告 / 错误 |

> 三种任务模式各有专属色：**专家=绿(ex)、工作=橙(wk)、会议=紫(mt)**。
> 这套色贯穿全局——徽章、圆点、进度条、发送按钮都跟着模式走。

### 字体

- `--font` 正文：`Segoe UI / 微软雅黑 / PingFang SC`，基准 `13px`，行高 `1.5`
- `--mono` 等宽：`Cascadia Code / Consolas`，用于代码、工具调用参数、文件路径

### 图标体系

- 用 **Lucide** 图标库（CDN 引入），写法 `<i data-lucide="图标名" class="ico">`
- 尺寸类：`.ico`(16px) · `.ico-xs`(12px) · `.ico-sm`(14px) · `.ico-lg`(18px) · `.ico-xl`(22px)
- 每次动态插入 DOM 后需调用 `lucide.createIcons()` 重新渲染图标

### 明暗主题

- `<html data-theme="light">` 切到亮色；不设或 `dark` 为暗色
- 亮色主题在 `:root[data-theme="light"]` 里**覆盖同名变量**，并对少数控件（状态栏、主按钮、卡片阴影）做专门覆盖
- 切换函数 `toggleTheme()`，绑定在顶部工具栏的主题按钮 `#theme-btn`

### 通用状态圆点 `.dot`

7px 圆点，加模式色类：`.d-ex`(绿) `.d-wk`(橙) `.d-mt`(紫) `.d-off`(灰=空闲)。
加 `.pulse` 类会呼吸闪烁（`@keyframes pu`，透明度 1↔0.3 循环），表示"运行中"。

### 通用动效

- `pu` — 呼吸（运行中的圆点、图标、进度块）
- `marquee` — 跑马灯（输入区顶部的生成进度线 `.cp-marquee-fill`）
- 滚动条统一细化为 5px（`::-webkit-scrollbar`），滑块用 `--s2`
