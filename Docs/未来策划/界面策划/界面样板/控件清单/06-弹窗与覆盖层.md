# 06 · 弹窗与覆盖层

浮在所有内容之上的临时控件。共用覆盖层遮罩 `.overlay`
（`position:fixed; inset:0`，半透明黑底 `rgba(0,0,0,.6)`，`z-index:100`，flex 居中）。
点遮罩空白处关闭。

---

## 1. 新建任务对话框 `#new-dialog`

- **触发** — `openNewDialog()`（顶部"新建任务"按钮、标签栏"＋"、常用操作卡等多处）
- **关闭** — `closeNewDialog()`（点 ✕、取消、遮罩、Esc）
- **风格** — `.dialog` 弹窗盒，宽 480px，`--s0` 底 + 边框圆角 6px，overflow 隐藏
- **结构**：
  - `.dlg-head` — `.dlg-title`"新建任务" + `.dlg-close` 关闭叉
  - `.dlg-body` — 主体：
    - `.dlg-tabs` > `.dtab` — 三个模式标签（专家会话 / 工作任务 / 会议），选中 `.on` 变强调边 + `--acd` 底，点 `dlgTab()`
    - 三个表单区，随标签切换显隐：
      - `#dlg-expert` — 会话标题、选择 Agent、初始消息
      - `#dlg-work` — 任务标题、目标描述、总经理 Agent、编排策略（下拉：自动/Magentic 编排/并行分析）
      - `#dlg-meeting` — 会议主题、议程（每行一条）、参会 Agent（多选）
    - 表单控件：`.fld` 字段组（`label` 大写小标 + `.finput` 输入框 / `.ftextarea` 文本域，聚焦变强调边）
  - `.dlg-foot` — 底部：`.dbtn`"取消" + `.dbtn.pri`"▶ 开始"（点 `createTask()`，关窗弹 Toast）

## 2. 命令面板 `#cmd-palette`

- **触发** — `openCmdPalette()`（顶部"命令面板"按钮，或快捷键 **Ctrl/Cmd + K**）
- **关闭** — `closeCmdPalette()`（Esc 或点遮罩）
- **风格** — 复用 `.dialog`，但靠上对齐（`margin-top:80px`）
- **结构**：
  - 顶部 `#cmd-input` 大搜索框（自动聚焦），`oninput="filterCmd()"` 实时过滤
  - `#cmd-results` 结果区 — 一列 `.ti` 命令项：总览、打开各任务、查看待审批、历史记录、展开 Agent 监控、新建任务
  - `filterCmd(val)` 按文本包含关系显隐结果项

---

## 3. Toast 提示

- **不是静态 DOM**，由 `showToast(msg, type)` 动态创建、2.5s 后淡出移除
- **位置** — 固定右下角（`bottom:36px; right:14px`），`z-index:200`，不拦截鼠标
- **风格** — 按 `type` 变色：`ok` 绿系（`--exd` 底 + `--ok` 边/字）、`err` 红系、其它中性灰
- **触发场景** — 审批处理、暂停/停止任务、创建任务、选择 Provider/Model/Agent 等几乎所有反馈

---

## 全局快捷键（`document` keydown 监听）

| 键 | 行为 |
|----|------|
| `Ctrl/Cmd + K` | 打开命令面板 |
| `Esc` | 关闭命令面板 + 新建对话框 + 输入区补全浮层 |
| `Enter`（输入区内） | 发送消息 |
| `Shift + Enter`（输入区内） | 换行 |
