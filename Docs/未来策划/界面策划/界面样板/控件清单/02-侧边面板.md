# 02 · 侧边面板 `#sidepanel`

活动栏右侧的第二列，宽 `220px`，背景 `--s0`。内容随活动栏导航切换——
每个导航对应一个 `.sp-panel`，通过 `switchNav()` 加 `.on` 类显示（其余 `display:none`）。

> 当前活动栏一级导航：**总览 · 项目管理 · 功能管理 · 技能管理 · 应用商店 · 设置**。
> 旧版的智能体 / 审批 / 历史 / 工作区面板已不再是一级导航（说明见文末）。

## 公共结构

### 顶部搜索区 `.sp-head`

横向 flex（`gap:6px`），从左到右：搜索框 + （应用商店专用）类型下拉 + 上下文添加按钮。

- **搜索框** `.sp-search` — 高 24px 输入框，占位"搜索..."，`oninput="spSearch()"` 过滤列表项，聚焦时边框变 `--ac`
- **上下文添加按钮** `.sp-add`（`#sp-add-btn`）— 24×24px 圆角按钮，居中 plus 图标，色 `--ac`，悬停 `--s2`。点 `spAdd()`，**功能随当前导航变化**：

| 当前导航 | 显示 | 按钮功能 |
|---------|------|---------|
| 总览 `overview` | ✅ | 新建任务 `openNewDialog()` |
| 项目管理 `projects` | ✅ | 新建项目 |
| 功能管理 `plugins` | ✅ | 打开插件安装目录 |
| 技能管理 `skills` | ✅ | 选择技能压缩包所在目录 |
| 应用商店 `store` | ❌ 隐藏 | —（改用搜索 + 类型下拉） |
| 设置 `settings` | ❌ 隐藏 | — |

- **应用商店** `store` 导航无 `.sp-add`、无筛选按钮 —— 分类走侧栏分类树，卡片在主区选项卡显示。详见第 5 节
- **驱动逻辑** — `switchNav()` 读 `navAddConfig[nav]` 决定 `.sp-add` 的显隐与 `title`；`currentNav` 记录当前导航供 `spAdd()` 取对应动作

### 其他公共控件

- **筛选子标签** `.sp-ftabs` > `.sft` — 选中 `.on` 变强调色 + 底部 2px 高亮线，点 `spftab()`
- **列表体** `.sp-body` — 可滚动区
- **分组标题** `.sph` — 11px 大写弱色小标题，如"运行中 (3)"
- **列表项** `.ti` — 通用条目：左侧 3px 透明竖条（选中 `.on` 变 `--ac`），悬停 `--s1`；含 `.ti-row`（主行，带 `.dot`）+ `.ti-sub`（次要说明）

## 1. 总览面板 `#sp-overview`

展示全局任务运行概况（**只显示任务，不混智能体**），按状态分组。

- **筛选子标签** — **运行中 / 待处理 / 全部**
- **`.oni` 条目结构** — `.oni-ico`（圆形图标，语义色 err/run/ok/warn）+ `.oni-body`（`.oni-title` + `.oni-sub`）+ `.oni-tag`（右侧状态标签）
- **左边条** — `.oni.urgent`（红）/ `.oni.running`（橙）/ `.oni.done`（灰+半透明）

三组内容：
- **需要处理 (N)** — 红色标题：写入文件审批、执行查询审批（点跳 `switchNav('approval')`）、Agent 心跳延迟（点跳 plugins）
- **运行中 (N)** — 各任务带模式色圆点（工作橙/会议紫/专家绿），点 `openTask()` 打开对应任务
- **今日完成 (N)** — 灰色打勾，显示完成时间与 token

## 2. 项目面板 `#sp-projects`（默认选中 · 方案A 项目卡片视图）

对标旧软件的"工作区域"——**一个工作区 = 一个项目**。每个项目聚合多个任务、Agent 实例与项目级配置。

- **筛选子标签** — 活跃 / 全部 / 已归档
- **项目卡片** `.pcard`（选中 `.on` 边框变 `--ac`，悬停边框 `--s3`）：
  - `.pc-top` — `.pc-name`（folder-kanban 图标 + 项目名）+ `.pc-badge`（右上角运行状态胶囊：`3 运行中` / `.idle` 灰"空闲"）
  - `.pc-sub` — 任务数、Agent 数（横向 flex 分列）
  - `.pc-meta` — 最后活动时间
- **分组** — 活跃项目 (N) / 空闲项目 (N)
- **交互** — 点卡片进入项目（当前样板 `openTask()` 占位；真实实现应切换项目上下文并暴露该项目的**项目技能**管理入口）

> **项目技能联动**：项目专属技能（原"工作技能"）在此面板进入项目详情后管理，不出现在全局技能面板。详见技能面板说明。

## 3. 功能管理面板 `#sp-plugins`（导航树 + 主区卡片，与应用商店同构）

与应用商店一样：**侧栏做导航树，卡片在主区选项卡显示**。区别是商店是"安装"，这里是对已装插件做**管理**（启用/停用/设置/卸载）。

### 侧栏：导航树（由 `renderPluginTree()` 动态生成）

侧栏容器 `#plugins-tree` 为空壳，整棵树由 JS 渲染——因为**分类来自数据库，是动态的**，不能写死在 HTML 里。

- **状态大项**（固定，来自枚举）`.stree-top`：全部插件 / 已启用 / 已停用
  - 计数**动态计算**：`全部 = PLUGIN_DATA.length`、`已启用 = 过滤 on`、`已停用 = 总数 - 已启用`
- **按能力分类**（动态，来自 DB）`.stree-cats`：
  - 分类列表来自 `PLUGIN_CATEGORIES`（样板用数组模拟一次接口返回；真实 `GET /plugins/categories`）
  - **只渲染有插件的分类**（`count > 0`），每项带该分类的插件数
  - 分类 filter 用 `cat:<id>` 传入 `openPlugins()`，卡片渲染按 `p.catId === id` 过滤
- **交互** — 点任意项 `openPlugins(filter, label)`：主区打开/激活"功能管理"选项卡并渲染卡片

> **动态化要点**：分类增删、改名、插件重新归类后，只需数据变、调用 `renderPluginTree()` 重渲染，UI 自动同步，无需改 HTML。

### 主区："功能管理"选项卡 `#pane-plugins`

由 `ensureMgmtTab('plugins',…)` / `buildMgmtPane()` 动态创建。三段：

1. **工具栏** `.store-toolbar` — 搜索框（`filterMgmtSearch`）+ 刷新 + **"打开插件目录"主按钮**（`spAddFor('plugins')`）
2. **面包屑条** — `#plugins-crumb` 当前筛选 + "去应用商店"快捷
3. **卡片网格** `.store-grid` — **插件卡** `.mcard`（停用加 `.off` 半透明）：
   - `.mcard-hd` — plug 图标 + 插件名 + **开关** `.mswitch`（`togglePlugin()` 一键启停）
   - `.mcard-desc` — 描述
   - `.mcard-caps` — 能力芯片 `.mcard-cap`（最多显 4 个，超出显 `+N`）
   - `.mcard-meta` × 2 — **功能总数** + **版本号**
   - `.mcard-acts` — 设置 / 卸载（卸载为 `.danger` 悬停红）
- **数据** `PLUGIN_DATA`（样板示例，真实来自插件注册表）：name / on / version / caps[] / desc

## 4. 技能管理面板 `#sp-skills`（仅全局技能 · 导航树 + 主区卡片）

**技能分两层**：

| 层级 | 位置 | 说明 |
|------|------|------|
| 全局技能 | 本面板 | 对所有项目可用，全局安装 |
| 项目技能（原"工作技能"） | 项目管理内部子面板 | 针对单个项目启用，**不在全局显示** |

结构与功能管理同构（侧栏树 + 主区卡片），**本面板只显示全局技能**。

### 侧栏：导航树（由 `renderSkillTree()` 动态生成）

同功能管理——`#skills-tree` 空壳，JS 渲染。

- **来源大项**（固定枚举）`.stree-top`：全部技能 / 内置 / 社区，计数动态
- **按能力分类**（动态，来自 DB）`.stree-cats`：来自 `SKILL_CATEGORIES`（真实 `GET /skills/categories`），只渲染有技能的分类，带计数；filter 用 `cat:<id>`
- 底部保留提示条：项目专属技能在项目管理内部管理
- **交互** — 点项 `openSkills(filter, label)` 在主区渲染

### 主区："技能管理"选项卡 `#pane-skills`

复用 `ensureMgmtTab('skills',…)`。三段：

1. **工具栏** — 搜索框 + 刷新 + **"导入技能包"主按钮**（`spAddFor('skills')` → 选择技能压缩包目录）
2. **面包屑条** — `#skills-crumb` + "去应用商店"
3. **卡片网格** — **技能卡** `.mcard`：
   - `.mcard-hd` — sparkles 图标 + 技能名 + **来源徽章** `.src-badge`（内置蓝 `src-builtin` / 社区绿 `src-community` / 项目橙 `src-project`）
   - `.mcard-desc` — 描述；`.mcard-meta` — 版本
   - `.mcard-acts` — **应用到项目** / 移除（呼应项目技能联动：全局技能可下发到某项目）
- **数据** `SKILL_DATA`：name / src / version / cap / desc

## 5. 应用商店面板 `#sp-store`（分类树 + 主区卡片选项卡）

参考旧软件的应用商店布局。侧边栏 220px 太窄放不下卡片，因此**侧栏只做分类导航树**，卡片网格放到**主内容区选项卡**里显示（类似打开一个任务标签页）。

### 侧栏：分类树

- **无搜索框特殊处理、无 `.sp-add`、无筛选按钮** —— 分类直接在树里点
- **两级结构**：
  - **大项** `.stree-top` —— 全部资源 / **更新** / 插件 / 技能 / 智能体 / 方案（对应 `AssetType` + 更新视图）。右侧 `.stree-count` 显示数量
  - **系统分类** `.stree-cat` —— 大项下挂的系统配置分类（来自 Categories 表），如插件下的 Linux / Windows / 便捷工具 / 编程开发；技能下的办公效率 / 编程开发 / 便捷工具 等

### 更新视图（`openStore('update',…)`）

侧栏"更新"节点，`#store-update-count` 用**警告色徽章**显示待更新数量（醒目）。点击进入更新视图，主区**只列出有可用更新的资源**。

- **有更新的判定** —— `installedVer && installedVer !== ver`（已安装 且 本地版本 ≠ 商店最新版本）
- **更新卡** —— 版本行显示 `旧版本 → 新版本`（新版本绿色），按钮为"更新到 x.y.z"；点 `doUpdate()` 把本地版本追平并刷新徽章
- **工具栏"全部更新"** —— `#store-update-all`（仅更新视图显示），`updateAll()` 一键更新所有
- **空态** —— 无更新时显示"所有资源均为最新版本"
- **数据字段** —— 每个资产除 `ver`（商店最新）外增加 `installedVer`（本地已安装，null=未安装）；卡片按钮据此三态：未装→安装、已装最新→已安装(禁用)、有更新→更新
- **交互**：
  - 点大项左侧 caret（`.stree-caret`）用 `toggleTree()` 展开/收起其系统分类（`.stree-cats` 用 `max-height` 过渡）
  - "全部资源"无子分类，点击直接 `openStore('all','','全部资源')`
  - 点任意大项或系统分类 → `openStore(type, cat, label)`：在主区打开/激活"应用商店"选项卡，渲染筛选后的卡片

> 分类数据（Linux/Windows/办公效率…）在样板里是示例，真实实现从平台 Categories 接口拉取，按 `SortOrder` 排序。

### 主区："应用商店"选项卡 `#pane-store`

由 `ensureStoreTab()` / `buildStorePane()` 动态创建，可像任务页一样关闭。三段结构：

1. **工具栏** `.store-toolbar`：
   - 搜索框 `.store-tb-search` —— 名称/开发者/能力关键词，`filterStoreSearch()` 本地过滤卡片
   - 排序下拉 `.store-tb-sel` —— 最新 / 热门优先 / 下载量
   - `刷新` 按钮、`登录` 主按钮（对标旧软件右上角）
2. **类型条 + 面包屑** `.store-typebar`：
   - 左侧面包屑 `#store-crumb` 显示当前筛选（如"插件 · Linux"）
   - 右侧类型快切芯片 `.store-typechip` —— 全部 / 插件 / 技能 / 智能体 / 方案，与侧栏树联动高亮
3. **卡片网格** `.store-grid`（`repeat(auto-fill,minmax(230px,1fr))` 自适应列）：
   - **资产卡** `.scard`：
     - `.scard-hd` —— 资产名 + 类型徽章 `.scard-type`（按类型着色：插件紫 `st-plugin` / 技能绿 `st-skill` / 智能体橙 `st-agent` / 方案蓝 `st-solution`）
     - `.scard-desc` —— 简短描述
     - `.scard-meta` × 3 —— 当前版本 / 开发者 / 价格（免费显示绿色 `.free`）
     - `.scard-install` —— 安装按钮，悬停变强调色
   - 底部 `.store-foot` —— "已加载全部 N 个资源"

- **渲染逻辑** `renderStoreCards(type, cat, sort)` —— 从 `STORE_ASSETS`（样板示例数据，真实来自 Market 接口）按类型 + 分类过滤后生成卡片
- **数据字段**（对应旧平台 Asset 实体）：name / type / category / version / developer / price / free / description；完整实现还含 ★评分、下载量、图标、标签、`IsFeatured`
- **交互** —— 点卡片打开详情页；安装后同步到功能管理 / 技能管理面板

## 6. 设置面板 `#sp-settings`

快速入口列表，每项 `.ti`：Provider 配置、Model 管理、Agent 定义、插件管理、MCP 服务器、存储健康检查、代理设置。当前为 `alert()` 占位。

## 已废弃 / 降级的旧面板

以下面板不再是活动栏一级导航，`switchNav()` 仍可跳转到部分作为目标：

- **智能体面板 `#sp-agents`** — 运行实例并入总览 + 底部 Agent 监控条
- **审批面板 `#sp-approval`** — 仍存在为跳转目标（总览的"需要处理"点击跳入），非一级导航
- **历史面板 `#sp-history`** — 降级为总览"今日完成" + 总览页快速入口
- **工作区面板 `#sp-workspace`** — 文件树移入项目详情
