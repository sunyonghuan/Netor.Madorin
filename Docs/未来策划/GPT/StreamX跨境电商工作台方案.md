# Stream X 跨境电商工作台方案

> 状态：行业参考方案 v0.2  
> 日期：2026-07-20  
> 发布标识：`stream-x`  
> 行业包：`cross-border-commerce`  
> 依赖方案：`可配置行业AI工作台架构方案.md`

## 0. 产品定位

`Stream X` 是基于 Madorin Workbench Kernel 发布的跨境电商 AI 工作台。

它不要求用户学习如何编写 Prompt，也不首先展示 Agent、模型和工作流。用户在熟悉的站点、渠道、商品、营销、订单、客服和结算场景中点击业务操作，系统在后台选择专家、工作任务、会议、技能和工具完成执行。

主要目标用户：

- 独立站经营者
- Amazon、eBay、AliExpress 等平台卖家
- TikTok Shop 和社交电商经营者
- 同时经营独立站与平台店铺的多渠道团队
- 单人或小团队跨境品牌

首版重点服务“一个品牌、多个渠道、一个主要经营者”的使用方式，不在首版构建大型 ERP 全部能力。

## 2. 跨境电商业务模型

### 2.1 项目

`Stream X` 使用以下项目类型：

| 项目类型 | 示例 |
| --- | --- |
| 品牌项目 | AuroraTrail 品牌 |
| 市场项目 | 欧洲市场、北美市场 |
| 独立站项目 | auroratrail.eu |
| 渠道项目 | Amazon DE、TikTok Shop UK |
| 营销活动 | 夏季户外产品推广 |

用户可以在一个品牌工作区中管理多个市场、站点和渠道项目。

### 2.2 业务资产

| 资产类别 | 主要内容 |
| --- | --- |
| 基础设施 | 云服务器、域名、DNS、证书、企业邮箱 |
| 站点 | 独立站、主题、页面、菜单、像素、分析配置 |
| 渠道 | Shopify、Amazon、eBay、TikTok Shop、社交账号 |
| 商品 | SPU、SKU、变体、图片、价格、库存、翻译和刊登内容 |
| 内容 | 商品页、博客、短视频脚本、广告文案、社交帖子 |
| 订单 | 订单、退款、异常、物流和客户请求 |
| 营销 | 活动、受众、素材、投放计划和营销日历 |
| 财务 | 平台结算、费用、税费、利润和对账报告 |
| 产物 | 报告、页面文件、文案、计划、发布记录和会议纪要 |

### 2.3 任务

任务必须使用业务名称，而不是内部技术名称：

- 注册品牌域名
- 购买云服务器
- 新建欧洲独立站
- 导入并清洗商品
- 翻译德语商品页
- 优化 Amazon 标题和关键词
- 批量发布商品
- 生成社交媒体内容计划
- 分发本周社交内容
- 处理异常订单
- 生成客服回复
- 核对平台结算差异

### 2.4 项目本地目录

每个经营项目配置一个唯一 `ProjectRootPath`，例如：

```text
E:\StreamX\NorthstarLiving\Germany-Site
├── documents/     方案、合规、品牌与会议文档
├── resources/     商品图片、视频、原始表格与外部素材
├── inputs/        已选择商品、市场规则与任务输入快照
└── outputs/       工作产出、发布记录、报告与会议纪要
```

目录名称是建议契约，最终是否固定由产品决策确定；行业包可以在受控范围内增加业务目录。项目文件树属于项目，不属于某个任务或 Agent。一个项目中的多个工作和多个 Agent 通过相对路径引用同一目录，产出按 `WorkSessionId` 保留来源关系。

## 3. 首次初始化

`Stream X` 已经锁定跨境电商行业，因此首次进入不再询问泛行业，只确认经营方式和工作内容。

### 3.1 经营模式

允许选择一个主要模式和多个辅助模式：

- 独立站
- 平台店铺
- TikTok Shop / 社交电商
- 多渠道经营

### 3.2 目标市场

- 欧洲
- 北美
- 英国
- 东南亚
- 中东
- 拉美
- 其他自定义市场

市场选择影响默认语言、货币、税务提醒、渠道和内容任务。

### 3.3 工作现状

- 还没有域名和站点
- 已有域名，需要建设站点
- 已有站点，需要商品和营销运营
- 已有平台店铺，需要多渠道管理
- 正在迁移现有商品和订单

### 3.4 日常工作内容

用户选择希望出现在工作台的模块：

- 服务器与域名
- 独立站建设
- 渠道连接
- 商品管理
- 内容与翻译
- 社交媒体分发
- 订单与客服
- 库存与履约
- 结算与经营分析

### 3.5 工作习惯

- 任务完成前始终确认
- 仅高风险操作确认
- 允许低风险任务自动继续
- 优先使用按钮和表单
- 优先通过专家对话分析
- 默认在后台运行长任务

### 3.6 初始化结果

初始化结束后创建：

1. 品牌工作区。
2. 首个市场或渠道项目。
3. 根据选择启用的业务模块。
4. 6 到 10 个常用操作。
5. 专家、工作、会议三模式的跨境电商预设。
6. 审批、通知和后台并行默认值。

## 4. 信息架构

### 4.1 一级导航

| 入口 | Stream X 内容 |
| --- | --- |
| 工作台 | 当前经营项目、继续工作、常用操作和任务 |
| 项目 | 品牌、市场、独立站、渠道和营销活动 |
| 任务 | 活跃、等待、定时和已完成业务任务 |
| 业务资产 | 基础设施、站点、渠道、商品、内容、订单和财务 |
| 对话 | 专家、工作、会议和文件化历史记录 |
| 应用 | 电商平台、社交渠道、支付、物流和业务功能 |
| 执行中心 | 后台任务、Agent、审批、异常和资源 |
| 设置 | 工作台、初始化、连接、审批、模型和存储 |

### 4.2 默认工作台结构

```text
当前上下文
  品牌工作区 / 市场项目 / 站点与渠道

继续工作
  正在执行、等待确认和最近暂停的业务任务

常用操作
  用户初始化和设置选择的高频按钮

业务模块
  站点与渠道 / 商品与内容 / 营销与分发 / 订单与经营

当前任务
  使用业务步骤展示，不在首页展示 Agent 运行矩阵

业务快照
  站点、商品、渠道、订单和等待事项
```

### 4.3 两级左侧导航

```text
一级图标轨
  工作台 / 经营项目 / 业务任务 / 业务资产 / 对话 / 应用 / 执行中心 / 设置
  桌面端可展开为“图标 + 名称 + 数量”，可收起为纯图标并记忆用户选择

二级上下文栏
  跟随当前一级入口切换标题、搜索、筛选、列表和目录内容
  只在经营项目、业务任务、业务资产上下文显示项目文件树
```

| 一级入口 | Stream X 二级内容 |
| --- | --- |
| 工作台 | 工作台视图、继续工作、项目运行摘要 |
| 经营项目 | 项目搜索、全部经营项目、当前项目目录树 |
| 业务任务 | 工作搜索、并行工作列表、所属项目与目录树 |
| 业务资产 | 项目选择、项目文件、资源和产出目录 |
| 对话记录 | 专家 / 工作 / 会议筛选、最近对话 |
| 应用与连接 | 跨境电商行业模块、已连接平台 |
| 执行中心 | Agent 状态筛选、运行实例 |
| 设置 | 工作台、项目文件、对话与存储设置 |

项目不使用顶部全局下拉框，但也不在所有二级页面常驻。用户进入“经营项目”即可同时浏览多个项目；进入具体 `WorkSession` 时一级导航定位到“业务任务”，二级栏显示该工作所属项目及唯一目录树。切换项目或工作不会停止其他项目的任务和 Agent。

桌面端展开一级导航时，二级栏宽度保持稳定，主工作区整体后移；收起后恢复紧凑图标轨。移动端一级与二级导航合并进入侧边抽屉，避免在窄屏中长期占用内容宽度。

### 4.4 工作标签与对话显示时机

- “全部项目”是默认首页标签，不加载 AI 对话。
- 每项已经明确目标的专家咨询、工作任务或会议使用独立工作标签。
- 进入工作标签后，中间显示真实 AI 对话，右侧显示步骤、产出和参与者。
- 工作标签保存所属项目、对话线程、输入草稿、文件引用和视图状态。
- 新建业务操作先确认所属项目和协作模式，再创建工作标签。

## 5. 默认业务模块

### 5.1 服务器与域名

主要资产：服务器、域名、DNS、证书和企业邮箱。

常用操作：

- 购买云服务器
- 注册域名
- 配置 DNS
- 配置 HTTPS
- 创建企业邮箱
- 检查域名和证书状态

涉及购买、续费和 DNS 变更时必须确认作用域。

### 5.2 独立站与渠道

主要资产：独立站、主题、页面、Shopify/Amazon/TikTok Shop 等渠道连接。

常用操作：

- 新建独立站
- 生成站点结构
- 创建首页与政策页面
- 连接平台店铺
- 同步渠道配置
- 发布站点
- 检查站点 SEO 和性能

### 5.3 商品与内容

主要资产：商品、SKU、图片、价格、库存、商品页和多语言内容。

常用操作：

- 导入商品
- 清洗商品数据
- 生成商品标题与卖点
- 翻译商品页
- 优化 SEO 和平台关键词
- 处理商品图片
- 批量发布商品
- 检查渠道刊登差异

### 5.4 营销与社交分发

主要资产：营销活动、内容计划、社交帖子、短视频脚本和广告素材。

常用操作：

- 新建营销活动
- 生成内容日历
- 创建社交帖子
- 生成短视频脚本
- 处理广告素材
- 分发社交媒体内容
- 汇总渠道表现

外部发布必须显示目标账号、内容数量和发布时间并由用户确认。

### 5.5 订单、客服与履约

主要资产：订单、退款、物流、库存和客户请求。

常用操作：

- 检查异常订单
- 生成客服回复
- 处理退款请求
- 检查库存风险
- 生成补货建议
- 跟踪物流异常

涉及退款、取消和客户外发消息时必须保留审计。

### 5.6 结算与经营分析

主要资产：结算单、平台费用、广告费用、税费、成本和利润报告。

常用操作：

- 导入平台结算
- 核对结算差异
- 计算商品利润
- 分析渠道表现
- 生成经营周报
- 召开经营复盘会议

## 7. 三种对话模式的行业预设

### 7.1 专家模式

默认专家能力：

- 跨境经营诊断
- 市场与渠道分析
- 商品内容与 SEO 诊断
- 广告与社交内容分析
- 订单、客服和结算异常分析

专家模式自动获得当前品牌、市场、站点、渠道、商品和任务上下文，但用户可以明确取消某项资产引用。

### 7.2 工作模式

工作模式是大多数业务按钮的默认执行入口。

任务详情只显示业务步骤，例如：

```text
检查站点现状
准备商品数据
生成页面内容
配置支付与物流
执行发布前检查
等待发布确认
发布并生成记录
```

Agent、工具和 Prompt 放在“执行详情”中，不混入普通业务步骤。

任务执行期间，工作对话始终可输入。用户可以直接要求：

- 修改站点方案
- 增加德语合规页面
- 调整商品发布顺序
- 暂停社交媒体发布
- 重新编制后续步骤
- 使用新的商品或素材作为输入

AI 在对话中说明变更影响，并同步更新任务的业务步骤、等待项和预期产物。

### 7.3 会议模式

默认会议角色可以包括：

- 主持人
- 市场策略专家
- 站点与技术专家
- 商品运营专家
- 营销内容专家
- 财务风控专家

典型会议：

- 新市场进入评审
- 独立站上线评审
- 商品发布评审
- 营销活动复盘
- 周经营复盘

行动项直接创建工作任务并保留来源会议 ID。

### 7.4 三模式对话界面

三种模式不是工作台右侧固定选项卡，而是创建 `WorkSession` 时选择的协作方式：

- 专家工作页：显示真实专家消息、项目文件引用、分析步骤和结论产出。
- 工作任务页：显示当前任务消息、计划变更、业务步骤、产出和参与 Agent。
- 会议工作页：显示多角色发言、用户插话、议题、决议和行动项。

默认首页不显示 AI 对话。用户点击继续工作、进入项目任务或完成新建工作后，才打开对应工作标签和真实对话。多个标签各自保存消息历史和输入草稿；窄屏中使用“对话 / 详情”切换，项目目录通过左侧抽屉访问。

### 7.5 Agent 监控栏

底部收起态使用紧凑状态条，至少显示：

- 当前执行工作数
- 工作中 Agent 数
- 等待用户确认数
- SQLite 索引、JSONL 正文状态和当前时间

展开后标题只显示 `Agent 监控`、全部/运行中/需处理统计和收起操作。Agent 卡片横向滚动，显示名称、所属项目与工作、当前活动、进度、ETA 和需处理状态；点击卡片定位所属工作标签。项目文件和 Agent 监控保持独立投影，不能把资源归属到 Agent。

## 8. 关键业务流程

### 8.1 新建独立站

```text
选择市场与品牌
  -> 检查域名和基础设施
  -> 选择站点平台
  -> 生成站点结构
  -> 创建品牌与政策页面
  -> 接入商品、支付和物流
  -> SEO、性能和合规检查
  -> 用户确认发布
  -> 生成站点资产和运营待办
```

### 8.2 商品多语言发布

```text
选择商品和目标渠道
  -> 数据清洗
  -> 目标市场规则检查
  -> 翻译标题、卖点和详情
  -> 关键词与 SEO 优化
  -> 图片和变体检查
  -> 用户审核
  -> 批量发布
  -> 保存发布结果和失败清单
```

### 8.3 社交媒体分发

```text
选择营销活动和商品
  -> 生成渠道内容版本
  -> 检查链接、标签和素材
  -> 选择账号和发布时间
  -> 用户确认外部发布
  -> 分发内容
  -> 汇总发布结果
```

### 8.4 经营复盘

```text
汇总站点、渠道、订单和费用
  -> 专家生成经营诊断
  -> 会议模式多角色复盘
  -> 记录决议与风险
  -> 批量生成下一周期工作任务
```

## 9. 工作台设置

普通用户可以配置：

- 显示哪些业务模块
- 业务模块顺序
- 常用按钮和顺序
- 默认项目和市场
- 默认对话模式
- 后台任务和通知
- 自动化与审批偏好
- 列表密度和筛选
- 重新运行初始化
- 恢复 Stream X 默认工作台

用户在设置中只选择业务功能，例如“翻译商品页”和“分发社交内容”，不显示其内部是技能、任务模板还是对话预设。

## 11. 首版验收标准

1. 新用户可以通过 3 到 5 个初始化步骤生成不同模块和常用操作的跨境电商工作台。
2. 首页首先呈现项目、业务资产、继续工作和业务按钮，不呈现 Agent 运行矩阵。
3. “服务器购买、域名注册、独立站建设、商品管理、社交分发”都有直接入口。
4. 任一按钮能够只询问缺失业务信息，并明确输出和外部影响。
5. 专家、工作、会议三种模式均可创建真实工作页，但默认首页不显示空白 AI 对话。
6. 用户可以在设置中调整模块和常用操作，界面不暴露内部绑定类型。
7. 长任务可以后台并行，切换页面或对话不停止运行。
8. 一级导航可展开、收起并记忆状态；二级栏跟随一级入口变化，全部项目集中在经营项目上下文浏览，项目切换不依赖顶部下拉框。
9. 每个项目只有一个本地目录树，同项目多个工作和 Agent 共享文件索引与产出投影。
10. 底部紧凑状态条可展开为跨项目 Agent 横向监控栏，并从卡片定位回具体工作。
11. 任务产物进入项目和业务资产，不只保存在聊天正文。
12. 工作台配置升级后保留用户个性化，失败时回退上一有效版本。

## 12. 结论

`Stream X` 的价值不在于提供另一个跨境电商数据后台，而在于把用户已经理解的经营动作转化为可靠的 AI 任务入口。行业项目和资产负责组织工作，业务按钮降低命令门槛，三种对话模式承载分析、执行和决策，多任务与多智能体在后台完成复杂过程并保持可观察、可审批和可恢复。
