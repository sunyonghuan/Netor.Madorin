# Stream X 跨境电商 AI 工作台界面样板

打开 [index.html](./index.html) 即可查看，不依赖本地开发服务器。

## 当前界面契约

- 默认首页同时展示多个经营项目、继续工作和业务操作，不显示 AI 对话。
- 左侧采用可展开/收起的一级导航轨加动态二级上下文栏；一级状态会记忆，二级内容跟随一级入口切换。
- 项目目录只在经营项目、业务任务和业务资产上下文出现；`WorkSession` 工作页归属业务任务。
- 项目拥有 `ProjectRootPath`、文档、资源、任务输入和产出；工作与 Agent 只引用项目文件。
- 点击继续工作、新建工作或 Agent 卡片后，打开独立 `WorkSession` 标签和真实 AI 对话。
- 专家、工作、会议是 `WorkSession` 的三种协作模式，不是首页常驻的三个空对话标签。
- 工作页中间用于持续对话，右侧显示步骤、产出和参与者；对话修改会同步业务步骤。
- 底部收起态是 26px 级状态条；展开后显示紧凑的 Agent 监控标题和跨项目横向卡片。
- 窄屏通过统一导航抽屉访问一级入口及对应二级内容，通过“对话 / 详情”切换当前工作区域。

## 可验证交互

- 展开和收起一级导航，刷新页面后确认用户选择仍然保留。
- 依次切换八个一级入口，确认二级标题、搜索、筛选和列表按入口变化。
- 在经营项目中切换德国独立站、Amazon DE 和 Summer Table 2026，目录树与项目上下文同步切换。
- 打开“德国站新品上线”，选择项目文件并引用到对话。
- 在工作对话输入“增加德语合规页面”，右侧业务步骤同步增加。
- 在步骤、产出、参与者之间切换。
- 展开 Agent 监控，筛选全部、运行中和需处理实例，并点击卡片定位对应工作。
- 新建工作时选择所属项目，以及专家、工作或会议模式。
- 在设置中调整工作台模块、密度和首次初始化结果。

## 文件结构

- `index.html`：可展开一级导航、动态二级导航、多项目首页、工作页、Agent 监控、初始化和新建工作结构。
- `styles.css`：一级展开态、桌面、平板、窄屏布局，项目目录树、对话、详情和监控栏状态。
- `stream-x.workbench.config.js`：发布信息、项目及其文件树、WorkSession、AgentRun、行业模块和业务动作样板数据。
- `app.js`：配置渲染、一级状态持久化、二级上下文路由、项目切换、工作标签、文件引用、对话、计划同步和 Agent 定位交互。
- `验收截图/`：包含导航折叠、导航展开、任务上下文和移动端导航的当前验收图，以及旧版对照图。

业务按钮只显示用户理解的业务名称，其 `mode` 和 `prompt` 仅用于模拟后台动作绑定，不在界面中暴露技能、Prompt、工作流或 Agent 编排类型。

本目录不代表最终 Avalonia 组件实现。界面中的项目、文件、任务、Agent 和对话均为样板数据；浏览器本地存储用于模拟主题、工作标签、目录选择、对话草稿和工作台设置持久化。

图标使用本地固定版本的 Lucide 浏览器包，许可证见 `assets/lucide.LICENSE`，因此离线打开也能正常显示图标和执行交互。
