## 记录

### 设计决策
- 会议长期记忆采用“summary-only”策略：阶段性 summary 与最终 summary 入库，普通发言不入库。
- 阶段性 summary 使用 `meeting_summary_{MessageId}` 作为 ObservationRecord.Id，支持同一会议多条阶段成果。
- 最终 summary 使用 `meeting_final_{MeetingId}` 作为 ObservationRecord.Id，代表会议正式结论。
- 未结束会议通过阶段性 summary 进入长期记忆，解决“会议未结束时记忆为空”的问题。
