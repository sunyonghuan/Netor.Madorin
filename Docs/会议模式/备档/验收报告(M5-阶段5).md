- `MeetingCompactionService` 无新增 AOT 警告。

当前 Native AOT 发布仍保留第三方程序集级别警告：

- `NAudio.Core`：`IL2104`
- `OllamaSharp`：`IL2104`、`IL3053`

这些警告来自第三方包本体，未阻止本次发布产物生成。后续若要求“零警告”发布，需要评估包升级、替换、隔离运行或针对具体成员增加保留配置。

## 备注

首次直接执行 `dotnet publish ... --no-restore` 曾因缺少 `net10.0/win-x64` assets 失败；执行一次带 restore 的 publish 后解决。NativeAOT 链接需要 VS x64 开发环境，并需要 `C:\Program Files (x86)\Microsoft Visual Studio\Installer` 在 PATH 中，否则会出现 `vswhere.exe` 环境问题。
