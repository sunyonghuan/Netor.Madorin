# Unix peer credential 原型验证记录

## 验收口径

- 必须由两个真实进程通过 Unix domain socket 通信。
- peer PID 必须来自内核接口并等于实际子进程 PID。
- peer UID 必须等于执行用户有效 UID。
- socket 文件权限必须为所有者读写（`0600`）。
- 正式 `NamedPipeTransport` 必须在服务端和客户端分别拒绝不同有效 UID 的 peer。
- 原生接口不可用或结果不一致时必须失败，不得静默跳过。

## 2026-07-22 Ubuntu 24.04 / WSL2

环境：WSL2 kernel `6.6.87.2-microsoft-standard-WSL2`、`linux-x64`、Ubuntu 用户 UID/GID `1000/1000`、.NET SDK `10.0.301`。

| 项目 | 结果 | 证据 |
| --- | --- | --- |
| Debug 构建 | 通过 | 原型及正式传输依赖构建成功，0 警告、0 错误 |
| 同用户双进程凭据 | 通过 | `PASS platform=linux peerPid=6142 uid=1000 gid=1000 socketMode=600` |
| 正式传输错误用户客户端拒绝 | 通过 | `nobody` UID `65534` 拒绝 root UID `0`：`wrong-user-client-rejected` |
| 正式传输错误用户服务端拒绝 | 通过 | root UID `0` 拒绝 `nobody` UID `65534`：`wrong-user-server-rejected` |
| Unix 监听就绪竞态回归 | 通过 | 客户端先连接、监听端后启动：1/1 测试通过 |
| 认证安全用例 | 通过 | MAC 篡改、帧重放、旧 timestamp、重放 nonce：4/4 测试通过 |
| 四 Runtime 多实例与错误绑定 | 通过 | 两宿主各两 Runtime、错误 secret、交换端点/实例/PID：1/1 测试通过 |
| Linux x64 Native AOT 发布 | 通过 | `clang 18.1.3`，生成 ELF x86-64 原生制品，0 条 trimming/AOT 警告 |
| Linux x64 Native AOT 运行 | 通过 | `PASS platform=linux peerPid=6554 uid=1000 gid=1000 socketMode=600` |

本轮同时修复 Unix 客户端早于监听 Socket 创建时立即报 `AddressNotAvailable` 的启动竞态。客户端只重试 `AddressNotAvailable` 和 `ConnectionRefused`，权限错误与其他 Socket 错误仍立即失败。

结论：`linux-x64` 的 peer PID/UID、`0600` 权限、错误用户双端拒绝、认证负向用例、多实例隔离和 Native AOT 实机验证均已闭合。当前机器不能提供 macOS 与 Linux ARM64 实机证据，相关行继续保持未完成。
