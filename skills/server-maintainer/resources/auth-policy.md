# Auth Policy

## 强约束

- 检测到 id_rsa 时，必须优先使用密钥认证。
- 未检测到 id_rsa 时，先提示走密钥初始化，不直接假设用户愿意输密码。
- 只有用户明确要求首次接入或重新配置密钥时，才进入密码流程。
- 密码不落盘、不回显、不作为命令行参数保存。
- 远程认证验证必须使用 SSH 插件 `ssh_connect` / `ssh_run_once`，不要通过 PowerShell 启动 `ssh`。

## 失败处理

- 密钥存在但失败：先检查权限、路径、端口和用户名。
- 权限问题优先执行本地 ACL 修复流程；修复后用 SSH 插件 `ssh_connect` 验证。
- 连续失败后，再提示用户确认是否重新生成密钥。
